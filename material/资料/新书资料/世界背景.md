# 第一部分：世界综述

## 一、三重世界结构

蓝星的现实并非单一存在，而是由三层世界嵌套构成：

```
┌─────────────────────────────────────────────────────────────┐
│                      外世界（The Outer World）               │
│  ┌─────────────────────────────────────────────────────┐   │
│  │    B幻想的“没有陨石的世界”                           │   │
│  │    - A生活的世界                                     │   │
│  │    - 由“世界之种”（七彩水晶）锚定                     │   │
│  │    - 正在缓慢崩塌                                    │   │
│  └─────────────────────────────────────────────────────┘   │
│                          ↕ 第四面墙（HDM-010）               │
│  ┌─────────────────────────────────────────────────────┐   │
│  │    里世界（The Inner World）—— 蓝星                  │   │
│  │    - B肉身沉睡的世界                                 │   │
│  │    - 陨石降临后的千年文明                            │   │
│  │    - 幻梦界与现实层交织                              │   │
│  └─────────────────────────────────────────────────────┘   │
│                          ↕ 认知滤网                         │
│  ┌─────────────────────────────────────────────────────┐   │
│  │    幻梦界（The Dream World）                         │   │
│  │    - 幻梦生物的栖息层                                │   │
│  │    - B的潜意识投射                                   │   │
│  │    - 认知锚点决定具现程度                            │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

### 1.1 外世界（A的世界）
- **本质**：B使用“幻想家”异能创造的平行世界，是一个“没有陨石降临”的蓝星
- **锚定物**：七彩水晶（B从自己体内的陨石剥离出的“世界之种”）
- **居民**：所有居民都是B幻想的产物，但拥有完整的人格和记忆
- **主角A**：B幻想的“更好的我”，被赋予了完整的人生和家庭
- **当前状态**：因世界之种能量流逝，正在缓慢崩塌（表现为物理定律异常、NPC化路人、建筑自发老化等）

### 1.2 里世界（蓝星）
- **本质**：B肉身沉睡的现实世界，陨石降临后的千年文明
- **面积**：陨石降临后扩张了10倍以上，已知区域约等于原蓝星面积的12倍
- **居民**：约1200万人类（八邦十九镇），凶兽与变异植物数量无法统计
- **特殊**：B的肉身封印在衡都地下3000米的“永眠层”

### 1.3 幻梦界
- **本质**：B的潜意识空间，与里世界现实层重叠但不同维
- **生物**：HDM-001至HDM-099等幻梦生物栖息于此
- **显现条件**：认知锚点越高，生物越能从幻梦界“具现”到现实层
- **特殊区域**：雾沼镇、镜湖、极地冰层深处等“认知薄弱点”是幻梦界与现实层的交界处

## 二、世界名称与术语

| 术语 | 定义 |
|------|------|
| **蓝星** | 陨石降临后的人类对地球的称呼（因从太空看呈现幽蓝色光环） |
| **陨石降临日** | 新历元年1月1日，直径十公里陨石被击碎后撞击蓝星的日子 |
| **大湮灭** | 陨石降临后三年内，人类数量从80亿锐减至不足3亿的灾难时期 |
| **异能觉醒时代** | 陨石降临后50-200年，异能者开始系统化修炼的时期 |
| **新历** | 从陨石降临日开始计算的纪年方式，当前为新历1043年 |
| **幻元粒子** | 陨石碎片释放的能量粒子，是异能和幻梦生物的能量来源 |
| **认知锚点** | 人类对某一事物的认知深度，决定幻梦生物的具现程度 |

# 第四部分：生态体系

## 一、三大生命形态

蓝星现存三大生命形态，构成复杂的生态关系：

### 1.1 人类
- **数量**：约1200万
- **分布**：八大城邦、十九镇、无数村落
- **特征**：拥有异能，是唯一能系统性修炼的种族
- **地位**：曾经的霸主，现在与其他生命形态争夺生存空间

### 1.2 凶兽
- **数量**：无法统计，估计数亿以上
- **分布**：全蓝星，除城邦和部分城镇外均为凶兽领地
- **分类**：
  - 低阶凶兽（F-D级战力）：如变异狼、巨型昆虫
  - 中阶凶兽（C-B级战力）：如狮鹫、岩甲龙
  - 高阶凶兽（A-S级战力）：如领主级凶兽、远古种
  - 王级凶兽（SS级以上）：已诞生智慧，如凶兽王庭成员
- **特征**：身体畸变，部分凶兽体内蕴含“兽核”（可提炼幻元粒子）
- **与人类关系**：敌对，但蔓城与部分凶兽建立了共存关系

### 1.3 变异植物
- **数量**：覆盖蓝星约40%的陆地面积
- **分布**：南部丛林、中央平原边缘、沼泽地带
- **特征**：
  - 巨型化：树木可达数百米高
  - 诡异化：部分植物具有捕食能力、释放毒素、操控生物
  - 共生：部分植物与凶兽/人类建立共生关系
- **价值**：产出药材、木材、特殊材料

# 第七部分：世界真相与伏笔

## 一、B与A的关系

### 1.1 已知事实
- B是里世界的“原初人类”，在陨石降临前100年捡到原初陨石，觉醒X级异能“幻想家”
- B在精神疾病发作期间幻想出“外世界”，并剥离“世界之种”（七彩水晶）作为锚点
- A是B幻想的“更好的我”，被赋予了完整的人生和人格
- A穿越里世界后，本质上是“幻想照进现实”——B的幻想产物回到了真实世界

### 1.2 未解之谜
- B为何会幻想“外世界”？是对现实的逃避，还是对“更好世界”的渴望？
- A的“自我意识”是B赋予的，还是独立产生的？
- 如果B醒来，A会消失吗？

---

## 二、陨石降临的真相

### 2.1 时间线矛盾
- B捡到陨石：陨石降临前100年
- 陨石降临：B沉睡后约80年（新历元年）
- 矛盾：如果B的陨石是“原初陨石”，那“天外陨石”是什么？

### 2.2 推测真相
- “天外陨石”是B的幻想家异能“自动投射”的结果
- B幻想“没有陨石的世界”，反而导致陨石在百年后“降临”
- 陨石的本质是B对“灾难”的恐惧的具象化
- B的陨石（拳头大小）是“原初碎片”，而“天外陨石”是B的异能制造的“复制品”

---

## 三、外世界的崩塌

### 3.1 崩塌表现
- 物理定律异常：重力偶尔失效、时间流速不一致
- NPC化路人：部分居民开始重复同一句话、同一动作
- 建筑自发老化：房屋在没有外力作用下快速腐朽
- 记忆缺失：A发现自己的部分记忆变得模糊

### 3.2 崩塌原因
- 七彩水晶（世界之种）能量耗尽
- 水晶在A穿越时碎裂，能量开始流逝
- 外世界失去锚点，正在被里世界“吸收”

### 3.3 A的抉择
- **选择一**：唤醒B，让B重新稳定外世界 → 里世界失去B的封印，幻梦生物完全具现
- **选择二**：永远封印B，保护里世界 → 外世界彻底崩塌，A的家人和朋友消失
- **第三条路**：A成为新的“幻想家”，用自己的认知重构世界规则

---

## 四、水晶石的真相

### 4.1 水晶的身份
- 七彩水晶 = 世界之种 = 外世界的锚点
- B从自己体内的陨石剥离出的“核心碎片”
- 水晶中储存着B对“外世界”的全部幻想设定

### 4.2 A穿越的真相
- A触碰水晶不是“穿越”，而是“回归”
- A的本质是外世界的“幻想人格”，回到里世界等于“幻想照进现实”
- 水晶在A穿越时碎裂，能量回流到A体内，使A获得“认知者”能力

### 4.3 水晶碎裂的后果
- 外世界开始崩塌
- A获得部分“幻想家”能力（但需通过“认知锚点”实现）
- B的封印出现松动（因为水晶与B的陨石同源）
