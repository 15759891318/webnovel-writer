# 第一卷：幻兽的本质——概念即存在

## 一、幻兽不是生物

### 1.1 幻兽的定义
**幻兽是“概念”的具象化存在**。

它们不是生物，不是能量体，不是异次元生命。它们是**人类认知中某个概念的“肉身”**。

- 饕餮遗胎 = “饥饿”这个概念
- 无面判官 = “审判”这个概念
- 记忆裁缝 = “死亡与遗忘”这个概念
- 织雾者 = “迷失”这个概念
- 第四面墙 = “真实与虚幻的边界”这个概念

### 1.2 幻兽的核心法则

**法则一：概念不死**
> 只要“饥饿”存在，饕餮遗胎就不会真正死亡。你可以封印它、遗忘它、压制它，但你无法杀死“饥饿”。

**法则二：锚点即血肉**
> 幻兽的“力量”来源于认知锚点。越多人类相信/恐惧/崇拜某个概念，对应的幻兽就越强大。

**法则三：形态即认知**
> 幻兽的形态取决于人类对概念的“想象”。不同文明对“审判”的想象不同，因此无面判官的形态融合了阎王、阿努比斯、弥诺斯等多种特征。

**法则四：好恶即投射**
> 幻兽的“性格”是人类对概念的投射。“死亡”可以恐怖（带来恐惧），也可以温柔（带来解脱）。因此，同一幻兽可能表现出不同的“面孔”。

# 第二卷：幻兽等级体系（锚点-存在度模型）

## 一、核心维度

幻兽的等级由**两个维度**共同决定：

### 维度一：锚点深度
- **定义**：人类对幻兽对应“概念”的认知深度
- **范围**：Lv.0（无人知晓）→ Lv.5（全民信仰）
- **决定**：幻兽的**力量**和**具现程度**

### 维度二：概念广度
- **定义**：幻兽对应“概念”在人类认知中的普遍性
- **范围**：窄（如“粮仓镇的丰收”）→ 广（如“死亡”“饥饿”“审判”）
- **决定**：幻兽的**存在稳定性**和**不死性**

## 三、各阶详解

### 零阶·沉睡概念——未醒的梦

> *“它们在B的幻想清单里，但从未被人类认知。它们沉睡在幻梦界最深处，等待被‘想起’。”*

**本质**：
- B曾经幻想过，但从未被任何人类（包括B自己）认真思考过的概念
- 相当于“未使用的草稿”

**特征**：
- 锚点深度：Lv.0（无人知晓）
- 概念广度：无
- 具现程度：0%
- 存在状态：仅存在于幻梦界最深处，与现实层无任何交集

**与现实的交互**：
- 无。它们甚至不知道自己“存在”。

**举例**：
- B在幻想“外世界”时废弃的人物设定
- B在日记中写下但从未完善的幻想
- 部分HDM档案中“未确认”的生物（如HDM-090“幻想残留”）

**收容方式**：
- 无需收容。只要没人“想起”它们，它们就永远不会醒来。
- **镇梦司最高禁令：禁止翻阅B的完整幻想清单**——因为你一读，它们就“存在”了。

**特殊风险**：
- A是最大的威胁。A博览群书，脑中储存了大量神话传说。如果A“认出”某个沉睡概念，它会直接跃升至一阶甚至二阶。

### 一阶·概念胚芽——刚刚被想起

> *“有人听说，有人讨论，但无人当真。它们像晨雾，太阳一出就散。”*

**本质**：
- 某个概念刚刚进入人类认知，但尚未被“认真对待”
- 相当于“流言”或“都市传说”

**特征**：
- 锚点深度：Lv.1（耳闻）
- 概念广度：极窄（仅限一个小群体）
- 具现程度：1-10%
- 存在状态：偶尔被感知（余光、梦、幻觉），无法稳定存在

**与现实的交互**：
- 极弱。可能让人做噩梦、产生幻觉，但无法造成物理伤害。
- 偶尔在镜子的角落、深夜里、迷雾中出现一瞬。

**行为倾向**：
- 大部分无害，只是“存在”而已
- 少数会“恶作剧”（藏东西、制造声响、吓人）

**举例**：
- 某个村落的“水鬼传说”（只有那个村的人知道）
- 某个猎人的“山神见闻”（只有他自己相信）
- 某个孩子的“床底怪物”（只有那个孩子恐惧）

**收容方式**：
- 认知管控：禁止传播相关信息
- 概念耗子（HDM-027）吞噬相关概念
- 等待自然遗忘（3-5代人就忘了）

**特殊规则**：
- 如果概念在50年内未被再次提及，会自然消亡（退回零阶）
- 如果概念被广泛传播，可能升级

### 二阶·概念映像——被人看见

> *“有人见过。它们开始在现实中留下痕迹——一个脚印、一声低语、一道影子。”*

**本质**：
- 某个概念已被一定数量的人类“目击”或“记录”
- 相当于“地方传说”或“未被证实的目击报告”

**特征**：
- 锚点深度：Lv.1-2（耳闻→目击）
- 概念广度：窄（一个地区、一个行业）
- 具现程度：10-30%
- 存在状态：可短暂具现（数秒到数分钟），具现后消失

**与现实的交互**：
- 有限。可以留下物理痕迹（爪印、黏液、温度变化）。
- 可能造成轻伤（抓伤、冻伤、烧伤）。
- 无法杀死人类（但可能吓死人）。

**行为倾向**：
- 大部分“中立”，只是按照自己的“概念本性”行动
- 少数“恶”，会主动惊吓人类（以获取锚点）
- 极少数“善”，会帮助人类（如指引迷路者）

**举例**：
- **HDM-034回声鸟**（中立）：只会重复声音，无害
- **HDM-015热浪行者**（恶）：会追逐移动物体，但伤害有限
- **某地“山神”**（善）：指引迷路猎人回家

**收容方式**：
- 认知干扰塔压制锚点
- 精神系异能者进行“认知清扫”
- 可物理封印（消耗资源中等）

**特殊规则**：
- 二阶幻兽可以被“杀死”（具现体被摧毁），但概念不灭
- 杀死后，需要10-50年才能重新具现
- 如果概念在100年内未被加强，会退回一阶

### 三阶·概念投影——稳定存在

> *“它们不再一闪而过。它们有了自己的‘地盘’，自己的‘规律’。你可以在特定的时间、特定的地点，见到特定的它们。”*

**本质**：
- 某个概念已被稳定记录和认知
- 相当于“公认的传说”或“未被解释的现象”

**特征**：
- 锚点深度：Lv.2-3（目击→记录）
- 概念广度：中（一个城邦、一个行业）
- 具现程度：30-60%
- 存在状态：可稳定具现于特定地点/时间，具现后可持续数小时到数天

**与现实的交互**：
- 强。可以造成物理伤害（相当于兵级-将级凶兽）。
- 可杀死人类（但通常有“规律”——比如只在满月出现、只攻击闯入者）。
- 部分三阶幻兽拥有“领地意识”，会守护特定区域。

**行为倾向**：
- 按照“规律”行动。只要不触发规律，它们不会主动攻击。
- 部分“善”：守护人类（如守护农田的稻草人）
- 部分“恶”：捕食人类（如织雾者）
- 部分“中立”：只是存在（如回声鸟）

**举例**：
- **HDM-023稻草人**（善）：守护农田，驱逐凶兽
- **HDM-001织雾者**（恶）：吞噬迷失者
- **HDM-006镜中行者**（中立）：只想“替换”，无善恶概念

**收容方式**：
- 封印阵法（需要法相境异能者主持）
- 认知清洗（降低锚点至二阶）
- 定期“投喂”（满足其概念需求，如织雾者需要“迷失感”）

**特殊规则**：
- 三阶幻兽很难被“杀死”。摧毁具现体后，1-5年内就会重新凝聚。
- 只有将认知锚点降至二阶以下，才能真正“封印”它们。
- 部分三阶幻兽可以与人类“共存”（如稻草人）。

### 四阶·概念化身——我就是这个概念

> *“它们不再‘代表’饥饿。它们，就是饥饿本身。”*

**本质**：
- 某个概念已被广泛认知，幻兽成为该概念的“唯一化身”
- 相当于“文化符号”或“普世传说”

**特征**：
- 锚点深度：Lv.3-4（记录→共识）
- 概念广度：广（多个城邦、多个种族）
- 具现程度：60-90%
- 存在状态：永久具现（可被封印，但封印消耗极大）

**与现实的交互**：
- 极强。可大范围影响现实（数十公里）。
- 可改变地形、影响气候、扭曲规则。
- 可杀死大量人类（相当于领主级凶兽）。

**行为倾向**：
- 完全按照“概念本性”行动，无法“商量”。
- 饕餮遗胎（饥饿）→ 永远在吃
- 永饥花园（归家的渴望）→ 永远在吸引
- 骨钟塔（死亡倒计时）→ 永远在敲钟
- 部分四阶幻兽有“智慧”，但智慧服务于概念（如饕餮遗胎会“思考”如何吃到更多）

**举例**：
- **HDM-002饕餮遗胎**（恶）：永远饥饿，吞噬一切
- **HDM-009永饥花园**（中立/恶）：永远吸引，吞噬接近者
- **HDM-007骨钟塔**（恶）：永远敲钟，带来死亡
- **HDM-005深渊水母·伊戈拉斯**（中立）：永远巡游，收割梦境

**收容方式**：
- 无法消灭。只能**封印**（需要归一境以上异能者+大型封印阵法）。
- 封印后需定期维护（否则封印会松动）。
- 封印的本质是“压制概念”——让人类“忘记”这个概念。

**特殊规则**：
- 四阶幻兽是镇梦司的**主要收容对象**。
- 目前有12只四阶幻兽被封印，5只在逃。
- 封印一只四阶幻兽需要消耗一个城邦10年的幻元晶产量。

### 五阶·概念神明——被信仰的存在

> *“它们不再是‘概念’。它们是‘神’。有人为它们建庙，有人向它们祈祷，有人为它们献祭。”*

**本质**：
- 某个概念已被**信仰化**，幻兽获得了“神性”
- 相当于“宗教信仰”或“民族神话”

**特征**：
- 锚点深度：Lv.4-5（共识→信仰）
- 概念广度：极广（全蓝星、多个种族）
- 具现程度：90-100%
- 存在状态：永久具现，不可封印（封印阵法无法压制信仰）

**与现实的交互**：
- 概念级。可影响世界规则。
- 可创造“神迹”（复活、诅咒、祝福）。
- 可赐予信徒力量（部分信徒的异能来自幻兽）。

**行为倾向**：
- 拥有独立“人格”和“意志”。
- 不再是“概念的木偶”，而是“概念的主人”。
- 可以选择帮助人类、无视人类、或毁灭人类。

**举例**：

| 幻兽 | 概念 | 倾向 | 信仰体系 | 与人类关系 |
|------|------|------|----------|------------|
| **HDM-003无面判官** | 审判 | 秩序·中立 | 幻觉教会（部分） | 不主动进入城邦，巡游审判 |
| **HDM-028知识之蛇** | 知识 | 中立 | 镜湖城学者（部分） | 赐予知识，也诅咒求知者 |
| **HDM-029记忆裁缝** | 死亡与记忆 | 善 | 部分临终关怀组织 | 帮助临终者，被视为“慈悲之神” |
| **HDM-030概率之轮** | 命运与概率 | 混沌·中立 | 赌徒、冒险者 | 交易运气，不主动干涉 |
| **HDM-061九尾狐** | 智慧与幻术 | 善 | 龙国后裔（部分） | 偶尔帮助人类，被视为“守护神” |
| **HDM-065凤凰** | 重生与净化 | 善 | 焚寂城（官方象征） | 焚寂城的象征，被视为“希望” |

**收容方式**：
- **无法收容**。你无法封印“信仰”。
- 只能“共存”或“协商”。
- 镇梦司与部分五阶幻兽有“协议”：
  - 无面判官：不进入人类城邦
  - 记忆裁缝：不干涉人类死亡
  - 九尾狐：不主动显露真身

**特殊规则**：
- 五阶幻兽的“性格”取决于人类对概念的“投射”。
- 如果人类将“死亡”投射为“恐怖”，死亡之神就是恐怖的。
- 如果人类将“死亡”投射为“解脱”，死亡之神就是慈悲的。
- 同一概念可能同时存在“恐怖”和“慈悲”两个面孔（如记忆裁缝）。

### 六阶·概念之源——万物起源

> *“它们不是某个概念。它们是‘所有概念的源头’。它们是世界运行的根本法则。”*

**本质**：
- 构成世界基石的**根本概念**
- 相当于“物理法则”或“哲学范畴”

**特征**：
- 锚点深度：Lv.5+（信仰+）
- 概念广度：普世（所有智慧生命）
- 具现程度：100%+
- 存在状态：超越“具现”与“不具现”的二元对立

**与现实的交互**：
- 世界级。它们本身就是世界的一部分。
- 它们“行动” = 世界规则“变化”

**已知/推测的六阶幻兽**：

| 名称 | 对应的概念 | 状态 | 描述 |
|------|------------|------|------|
| **世界树·扶桑** | 生命与连接 | 苏醒 | 南部丛林的意识主体，所有植物的“源头”。它不是被幻想的，它是B对“生命”的理解的具象化。 |
| **第四面墙·HDM-010** | 真实与虚幻的边界 | 存在 | 不是生物，是“边界”本身。两个世界之间的墙。 |
| **蓝星意志**（未确认） | 蓝星本身 | 沉睡？ | 如果蓝星有“意志”，它就是六阶。部分精神系异能者报告“听到蓝星的声音”。 |

**收容方式**：
- **不可接触，不可理解，不可讨论**。
- 镇梦司最高机密：关于六阶幻兽的研究资料被分散存储，任何单一个体不得掌握超过10%的信息。

**特殊规则**：
- 六阶幻兽不是“被幻想出来的”，而是B的“幻想家”异能**触及**了它们。
- 它们在B幻想之前就“存在”（作为世界规则），B只是让它们“被看见”。

### 根源·幻想家——一切幻想的起点

> *“它不是幻兽。它是幻兽的创造者。它不是概念。它是概念的源头。”*

**本质**：
- **B本人**
- 唯一X级异能“幻想家”的持有者
- 幻梦界的创造者，外世界的创造者

**B的状态**：

# 第三卷：幻兽的善恶——不是非黑即白

## 一、幻兽的“性格”来源

幻兽的“性格”取决于**人类对概念的投射**：

- 如果人类将“死亡”投射为“恐怖”→ 死亡幻兽是恐怖的
- 如果人类将“死亡”投射为“解脱”→ 死亡幻兽是慈悲的
- 如果人类将“饥饿”投射为“惩罚”→ 饥饿幻兽是恶意的
- 如果人类将“饥饿”投射为“警示”→ 饥饿幻兽是中立的

**同一个幻兽，在不同文化中可能呈现不同面孔。**

## 二、幻兽的倾向分类

| 倾向 | 定义 | 举例 | 与人类关系 |
|------|------|------|------------|
| **守序·善** | 主动帮助人类，守护秩序 | 稻草人、记忆裁缝、九尾狐 | 盟友 |
| **中立·善** | 不主动帮助，但也不伤害 | 丰收之影、梦貘、海市蜃楼鲸 | 无害 |
| **绝对中立** | 按照“规律”行动，无善恶 | 镜中行者、回声鸟、沙海回响 | 可共存 |
| **中立·恶** | 不主动攻击，但会伤害触发者 | 织雾者、永饥花园、热浪行者 | 需警惕 |
| **混沌·恶** | 主动攻击，以人类为食/目标 | 饕餮遗胎、骨钟塔、瘟疫使者 | 需收容 |
| **秩序·恶** | 按照“规则”惩罚人类 | 无面判官（对罪人） | 需回避 |

- **与人类关系**：不主动进入城邦，人类不主动招惹

## 二、封印的本质

封印幻兽 = **压制概念**

方法：
1. **认知清洗**：让人类“忘记”这个概念（最有效，但最难）
2. **概念替代**：用新的概念覆盖旧概念（如用“审判”覆盖“恐惧”）
3. **物理封印**：用阵法压制幻兽的具现体（治标不治本）
4. **概念耗子**：让HDM-027吞噬相关概念（可控但有限）

**封印的代价**：
- 封印一只四阶幻兽，需要10名法相境异能者+100名扩域境异能者轮流维持
- 每年消耗一个城邦10%的幻元晶产量
- 封印一旦松动，幻兽会在72小时内重新具现

# 第五卷：主角A与幻兽——特殊关系

## 一、A的“认知炸弹”属性

A博览群书，脑中储存了大量神话传说的“认知模板”。

**风险**：
- A每“认出”一个幻兽，就等于给该幻兽注入锚点深度
- 可能引发“认知雪崩”——大量沉睡幻兽同时苏醒

**案例**：
- A在风蚀城认出“织雾者”→ 织雾者锚点从Lv.2跃升至Lv.3，开始影响现实天气
- A在镜湖城认出“镜中行者”→ 镜中行者锚点加深，镜湖城所有反射面出现异常

## 二、A的“认知者”能力

A无法修炼传统异能，但拥有“认知者”能力：

| 能力 | 描述 | 对幻兽的效果 |
|------|------|--------------|
| **认知具现** | 将认知中的事物“具现”到现实 | 可临时强化或削弱幻兽 |
| **认知抹除** | 通过“遗忘”来削弱事物 | 可降低幻兽锚点 |
| **认知共鸣** | 将自己的认知“分享”给他人 | 可让更多人“相信”某个幻兽 |
| **认知重构** | 改变事物的“认知锚点” | 可改变幻兽的“面孔” |

**A的终极可能性**：
- A可能成为新的“幻想家”，但不同于B的“无中生有”
- A是“认知成真”——通过改变人类的认知来重塑幻兽
