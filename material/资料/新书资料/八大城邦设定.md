# 🏰 蓝星人族八大城邦详细设定

---

## 📍 地理总览

陨石降临千年后，蓝星面积扩大十倍以上，原有大陆板块因陨石撞击与幻元粒子渗透发生剧变。人族在凶兽与幻梦生物的夹缝中，夺回八块核心区域建立城邦，形成 **"八邦十九镇"** 格局。

八大城邦以 **"星轮联邦议会"** 为名义最高决策机构，但实际上各邦自治，政治博弈暗流涌动。

```
                    【极北·霜棺城】
                         |
        【西疆·风蚀城】——|——【东渊·沧澜城】
               \         |        /
        【西南·铸魂城】——【中枢·衡都】——【东南·镜湖城】
                         |
              【南域·蔓城】——【深南·焚寂城】
```

## 一、衡都（Héngdū）—— 中枢之城

> *"天平之上，万邦归一。"*

### 基础信息
| 项目 | 详情 |
|------|------|
| **地理位置** | 蓝星中央大陆核心，原龙国首都遗址重建 |
| **人口** | 约 380 万（八邦之最） |
| **城邦特色** | 政治中心、联邦议会所在地、最大异能学院 |
| **城邦象征** | 天平与星环 |

### 主导势力
- **星轮联邦议会**：名义上统辖八邦的最高机构，实际权力有限，更多充当调停者
- **镇梦司总部**：异常收容的最高指挥中枢，掌握B的封印设施（极密）
- **衡都异能学院**：蓝星最大的异能培训机构，每年选拔各邦天才

### 特色异能流派
**【衡正流·规则系】**
- 核心理念：追求"平衡"与"秩序"，擅长制定规则型异能
- 代表能力：**「审判领域」**——在一定范围内设定规则（如"不可使用火系异能""速度上限为音速"），所有人必须遵守
- 进阶路线：规则越复杂、范围越广，对使用者精神负荷越大
- 弱点：规则对自身同样生效，且规则越强，"因果反噬"越重

### 城邦秘密
- B的封印设施就在衡都地下 3000 米的 **"永眠层"**
- 议会中至少有两位议员是 **"唤梦者"** 的暗桩
- 衡都地基中嵌入了B早期幻想的"秩序之锚"，使整座城市异常稳定，几乎不受凶兽侵袭——但无人知道这是B的功劳

## 二、沧澜城（Cānglán Chéng）—— 东渊之城

> *"深渊回望你时，我们回以炮火。"*

### 基础信息
| 项目 | 详情 |
|------|------|
| **地理位置** | 东部沿海，建于陨石撞击海洋后形成的巨型海崖之上 |
| **人口** | 约 260 万 |
| **城邦特色** | 军事强邦、海洋探索前线、凶兽猎杀重镇 |
| **城邦象征** | 深海巨浪中的铁锚 |

### 主导势力
- **沧澜军府**：军政一体的铁腕统治，军府大将军为城邦最高领袖
- **猎潮团**：专门猎杀海洋凶兽的精锐部队，拥有八邦最强的实战经验
- **深渊研究所**：研究海底陨石碎片与深海异变生物

### 特色异能流派
**【潮涌流·元素系（水）+ 强化系】**
- 核心理念：以海为师，刚柔并济
- 代表能力：**「潮汐铠甲」**——将海水凝聚为流动战甲，兼具防御与攻击，战甲随战斗强度自动切换刚柔形态
- 高阶能力：**「深渊压强」**——模拟万米深海压力碾压对手
- 特殊兵种：**"潜渊者"**——能够深入海底数千米的改造战士，身体进行了半凶兽化强化

### 城邦秘密
- 海崖下方的深海中沉睡着千年前陨石的 **最大碎片**，至今仍在缓慢释放幻元粒子
- 深渊研究所发现碎片周围出现了 **非凶兽、非幻梦的第三类生命体**，已列为最高机密
- 沧澜城的海水偶尔会变成血红色，军府对外宣称是"藻类异变"，实际原因不明

## 三、铸魂城（Zhùhún Chéng）—— 西南锻造之城

> *"一柄好刀，值一座城。"*

### 基础信息
| 项目 | 详情 |
|------|------|
| **地理位置** | 西南山脉深处，建于活火山群环抱的巨型熔岩台地上 |
| **人口** | 约 180 万 |
| **城邦特色** | 异能武器锻造中心、矿产资源最丰富 |
| **城邦象征** | 锤与火焰 |

### 主导势力
- **锻造师工会**：城邦实际统治者，最高领袖为"大匠师"
- **矿脉守卫军**：保护矿产资源的武装力量
- **火种商会**：垄断异能武器交易的商业联盟，触角伸入所有城邦

### 特色异能流派
**【锻魂流·元素系（火/金属）+ 创造系】**
- 核心理念：以异能为锤，以精神为火，锻造万物
- 代表能力：**「魂锻」**——将自身异能灌注到武器中，根据使用者灵魂共鸣度，武器觉醒不同能力
- 高阶能力：**「万炉归一」**——身体本身化为熔炉，可以吞噬任何金属和矿物并转化为武器的一部分
- 特殊职业：**"代价锻造师"**——以自身寿命、记忆、感官为代价，锻造传奇级武器

### 城邦秘密
- 火山群之所以千年不灭，是因为地底封印着B幻想的 **"不灭火神·祝融"**，其怒火维持着地热
- 铸魂城最深层的锻造间中，存放着一柄 **B亲手幻想的剑**，至今无人能拔出
- 大匠师已是第37代，每一代大匠师都会在就任时被告知一个秘密——**铸魂城本身就是一把武器**

## 四、镜湖城（Jìnghú Chéng）—— 东南学术之城

> *"真相倒映在湖面，但你看到的是哪一面？"*

### 基础信息
| 项目 | 详情 |
|------|------|
| **地理位置** | 东南平原，环绕一座直径 30 公里的完美圆形湖泊而建 |
| **人口** | 约 210 万 |
| **城邦特色** | 学术研究中心、异能理论最发达、幻梦界研究前沿 |
| **城邦象征** | 湖面上的眼睛 |

### 主导势力
- **学者议会**：由七大学派掌门组成的议会制政府
- **认知研究院**：专门研究认知锚点与幻梦界的顶级学术机构
- **镇梦司·分析部**：镇梦司在镜湖城的分支，负责幻梦生物的理论研究

### 特色异能流派
**【映照流·精神系】**
- 核心理念：以湖为镜，照见万物本质
- 代表能力：**「认知映射」**——读取目标的认知信息，包括记忆、知识、甚至潜意识中对幻梦生物的认知
- 高阶能力：**「镜像推演」**——在精神空间中模拟战斗、推演未来可能性
- 禁术：**「深湖凝视」**——直接观测幻梦界，极度危险，可能被幻梦生物反向认知
- 弱点：精神系使用者容易遭受"精神污染"，镜湖城的精神病患者比例是八邦之最

### 城邦秘密
- 那座完美圆形湖泊 **不是天然形成的**，它是B的一滴眼泪坠落后形成的认知湖
- 湖水本身就是一个巨大的"认知滤网"，镜湖城因此成为幻梦生物出现最少的区域
- 认知研究院的地下档案馆中，存有一份 **关于"外世界"存在的理论推演**，被列为SSS级机密
- HDM-006（镜中行者）最早便是在镜湖城被发现的

## 五、风蚀城（Fēngshí Chéng）—— 西疆游猎之城

> *"风带走一切，也带来一切。"*

### 基础信息
| 项目 | 详情 |
|------|------|
| **地理位置** | 西部荒漠戈壁，城邦本身是一座可以移动的巨型移动要塞 |
| **人口** | 约 120 万（含流动游猎民） |
| **城邦特色** | 唯一的移动城邦、游猎文化、情报网络最发达 |
| **城邦象征** | 三道风痕 |

### 主导势力
- **风主**：城邦最高领袖，同时是最强的风系异能者，负责驱动城邦移动
- **游猎十三部**：十三个游猎部族联盟，在荒野中狩猎凶兽获取资源
- **风语者**：西疆独有的情报组织，以风为媒介传递信息，情报网覆盖八邦

### 特色异能流派
**【风蚀流·元素系（风）+ 强化系】**
- 核心理念：不可被捕捉，不可被束缚
- 代表能力：**「风蚀体」**——身体部分风化，物理攻击直接穿过身体
- 高阶能力：**「沙暴葬场」**——召唤方圆数十公里的沙暴，将一切侵蚀为沙
- 独特异能：**「风的记忆」**——风系异能者可以"听到"风经过之处的声音残留，用于追踪和情报
- 弱点：风蚀流使用者寿命普遍较短，身体不断被自己的能力"侵蚀"

### 城邦秘密
- 风蚀城之所以不断移动，**并非主动选择，而是在逃避什么**——西疆地下有某种存在在缓慢苏醒
- 风语者截获过一段来自"外世界"的信号碎片，但无法解读
- 历代风主中有一位曾到达蓝星边缘，回来后疯了，留下一句话：**"蓝星是圆的，但世界是方的"**

## 六、霜棺城（Shuāngguan Chéng）—— 极北冰封之城

> *"我们不惧怕死亡，因为这里的一切都已死过一次。"*

### 基础信息
| 项目 | 详情 |
|------|------|
| **地理位置** | 极北冰原，建于一座被永冻冰层覆盖的远古巨兽尸骸之上 |
| **人口** | 约 90 万（八邦最少） |
| **城邦特色** | 极端环境生存、死亡研究、封印技术最强 |
| **城邦象征** | 冰晶中的棺椁 |

### 主导势力
- **冬眠议会**：由能够进入"假死"状态的长老们组成，部分长老已"冬眠"数百年
- **葬冰骑士团**：极北最强战力，在冰原上对抗冰域凶兽
- **镇梦司·封印部**：镇梦司中封印技术最高的部门驻扎于此

### 特色异能流派
**【永冻流·元素系（冰）+ 规则系】**
- 核心理念：冰封万物，终结一切变化
- 代表能力：**「绝对零域」**——在领域内将一切（包括异能、分子运动、甚至时间流速）减缓直至冻结
- 高阶能力：**「葬冰棺」**——将目标永久封印在特殊冰棺中，生不如死也死不彻底
- 终极封印术：**「永冬」**——传说中的禁术，可以冻结概念本身，霜棺城用弱化版封印了数头噩梦级幻梦生物
- 弱点：使用者情感会逐渐被"冻结"，高阶使用者几乎丧失所有情绪

### 城邦秘密
- 城邦下方的远古巨兽尸骸 **并未完全死亡**，它的心脏仍在极缓慢地跳动，每跳一次约 3 年
- 冬眠议会中最古老的长老已"冬眠"800 年，她是 **B被封印时的见证者**
- 霜棺城保存着一具特殊的冰棺——里面封印的是 **B的一缕精神残留**，偶尔会说梦话，镇梦司专门记录这些梦话用于分析B的状态

## 七、蔓城（Màn Chéng）—— 南域丛林之城

> *"与自然共生，或被自然吞噬。"*

### 基础信息
| 项目 | 详情 |
|------|------|
| **地理位置** | 南部巨型丛林带内，城邦与变异植物群落共生 |
| **人口** | 约 200 万 |
| **城邦特色** | 生态共生型城邦、药剂学最发达、唯一与部分凶兽建立共存关系的城邦 |
| **城邦象征** | 缠绕的藤蔓与花朵 |

### 主导势力
- **生蔓祭司团**：城邦领导层，由能与变异植物沟通的祭司组成
- **共生者协会**：研究人类与凶兽共存可能性的组织
- **万药阁**：垄断蓝星80%珍稀药材供应的商业机构

### 特色异能流派
**【共生流·元素系（木/毒）+ 强化系】**
- 核心理念：万物共生，以命养命
- 代表能力：**「蔓甲共生」**——与特定变异植物签订共生契约，植物化为铠甲/武器/伙伴
- 高阶能力：**「万林同根」**——接入整片丛林的根系网络，以森林为眼、为手、为武器
- 特殊职业：**"驯兽师"**——极少数能与凶兽建立精神链接的异能者
- 弱点：共生过深会导致"植化"，使用者身体逐渐变为植物

### 城邦秘密
- 蔓城的巨型丛林 **本身是一棵树**——B幻想的"世界树·扶桑"的根系蔓延形成了整片丛林
- 生蔓祭司团能听到扶桑的"低语"，那其实是B沉睡时的潜意识碎片
- 蔓城深处有一片"伊甸区"，那里的动植物 **完全没有异变**，保持着陨石降临前的原始状态——没有人能解释为什么

## 八、焚寂城（Fénjì Chéng）—— 深南末日之城

> *"如果世界注定毁灭，那就由我们点燃最后一把火。"*

### 基础信息
| 项目 | 详情 |
|------|------|
| **地理位置** | 最南端，建于一片永恒燃烧的焦土之上——"焚原" |
| **人口** | 约 150 万 |
| **城邦特色** | 最激进的城邦、"唤梦者"势力最强、拥有八邦最强的个体战力 |
| **城邦象征** | 燃烧的凤凰 |

### 主导势力
- **焚主**：城邦独裁者，以绝对武力统治，现任焚主为300年来最强的SSS级异能者
- **涅槃军团**：焚寂城的核心战力，成员全部经过"浴火重生"仪式，死亡后可重生一次
- **唤梦者·焚寂分支**：在焚寂城半公开活动，主张唤醒B以重建龙国荣光

### 特色异能流派
**【焚灭流·元素系（火/雷）+ 规则系】**
- 核心理念：毁灭即新生，极致的破坏就是最强的力量
- 代表能力：**「业火」**——燃烧的不是物质，而是目标的"存在感"，被烧尽者会被世界遗忘
- 高阶能力：**「天罚」**——召唤雷火交织的毁灭风暴，可以抹除一个小型城镇
- 终极能力：**「涅槃焚天」**——自爆后从灰烬中重生，重生后实力短暂暴涨至更高层级
- 弱点：焚灭流使用者人格会越来越偏激和暴躁，高阶者普遍有严重的暴力倾向

### 城邦秘密
- 焚原永恒燃烧的火焰来自B幻想的 **"末日之火"**，本应烧尽世界，但被认知滤网限制在这片区域
- 焚主手中有一件B的遗物——**"幻想家的日记残页"**，记录着B的部分幻想清单
- 唤梦者在焚寂城的真正计划：**利用焚原的末日之火烧穿认知滤网，让所有幻梦生物重新具现**
