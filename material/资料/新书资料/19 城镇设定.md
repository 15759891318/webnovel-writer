## 一、北境雪原区（3 镇）

### 1. 雪落镇

| 项目 | 内容 |
|------|------|
| **位置** | 北境雪原南部，距雪城 300 公里 |
| **人口** | 约 8000 人 |
| **城主** | 秦雪（B 级，冰系异能） |
| **特产** | 冰晶矿、雪狼皮、寒铁 |
| **威胁** | 二级变异冰狼群、三级冰霜巨魔 |

**特色**：
- 建筑全部由冰砖砌成，夜晚会发出淡蓝色荧光
- 地下有天然冰晶矿脉，是制作冰系武器的重要材料
- 每年举办"冰雕节"，吸引各地商人

**防御**：
- 城墙厚 5 米，高 15 米，内置供暖阵法
- 常备军 500 人，异能者 50 人
- 紧急情况可点燃"烽火台"，雪城 1 小时内支援

---

### 2. 寒霜镇

| 项目 | 内容 |
|------|------|
| **位置** | 北境雪原东部，极寒山脉脚下 |
| **人口** | 约 5000 人 |
| **城主** | 寒夜（A 级，精神系 + 冰系双异能） |
| **特产** | 霜灵草、冰魄石、雪参 |
| **威胁** | 三级雪妖、四级冰霜巨龙（偶尔出没） |

**特色**：
- 建立在温泉群之上，是唯一能在雪原享受温泉的城镇
- 温泉含有特殊矿物质，可缓解异能反噬
- 设有"疗伤院"，收费昂贵但效果显著

**秘密**：
- 温泉深处封印着一只二级雪妖，为城镇提供热能
- 寒夜与雪妖签订契约，每月需喂食一次凶兽血肉

---

### 3. 冰谷镇

| 项目 | 内容 |
|------|------|
| **位置** | 北境雪原西部，冰峡谷入口 |
| **人口** | 约 12000 人 |
| **城主** | 谷冰凝（S 级，冰系） |
| **特产** | 冰谷灵米、寒髓液、冰蚕丝 |
| **威胁** | 冰谷深处的"冰棺"（收容级异常） |

**特色**：
- 建立在巨大冰峡谷入口，易守难攻
- 冰谷内种植特殊灵米，食用可小幅提升冰系亲和力
- 是北境最大的粮食供应地之一

**收容物**：
- **冰棺**：收容等级【醒梦级】
- 位置：冰谷地下 500 米
- 描述：灾厄历 52 年 B 幻想出的"冰封王座"碎片，触碰者会被永久冻结
- 用途：冰谷镇用它制造"寒冰牢狱"，关押重犯

### 4. 铁壁镇

| 项目 | 内容 |
|------|------|
| **位置** | 中部平原北部，龙渊城以南 200 公里 |
| **人口** | 约 30000 人 |
| **城主** | 铁山（A 级，金系） |
| **特产** | 精铁、钢锭、铠甲 |
| **威胁** | 二级铁甲犀群、三级岩甲熊 |

**特色**：
- 人族最大军事装备供应地
- 城墙厚 20 米，高 30 米，号称"永不陷落的堡垒"
- 城内遍布铁匠铺，日夜锻造声不绝

**军事**：
- 常备军 5000 人，其中重装步兵 3000 人
- 配备"铁壁战阵"，可抵挡 A 级攻击 1 小时
- 是龙渊城的第一道防线

---

### 5. 青木镇

| 项目 | 内容 |
|------|------|
| **位置** | 中部平原东部，靠近南疆雨林边缘 |
| **人口** | 约 15000 人 |
| **城主** | 木青（A 级，木系） |
| **特产** | 青木灵液、治疗药剂、木系兽核 |
| **威胁** | 三级食人花王、四级藤蔓巨怪 |

**特色**：
- 整座城市建立在一棵巨大的"古树"之上
- 建筑与树木共生，会缓慢生长
- 是人族最大的治疗药剂供应地

**秘密**：
- 古树是 B 灾厄历 20 年幻想出的"世界树幼苗"
- 古树核心藏有一颗 SS 级兽核，维持城镇防御结界
- 木青是古树选中的"守护者"，与古树性命相连

### 6. 风语镇

| 项目 | 内容 |
|------|------|
| **位置** | 中部平原西部，风口要道 |
| **人口** | 约 10000 人 |
| **城主** | 风无痕（A 级，风系） |
| **特产** | 风系兽核、飞行坐骑、风符 |

**特色**：

- 是人族唯一驯养"风鹰"的城镇，风鹰可作为飞行坐骑
- 设有"飞行驿站"，可快速传递情报

**战略**：
- 控制着东西方交通要道
- 风语镇的风系异能者可借助风力，将情报送到 500 公里外
- 是人族情报网的核心节点

### 7. 石岩镇

| 项目 | 内容 |
|------|------|
| **位置** | 中部平原西南部，石岩山脉脚下 |
| **人口** | 约 20000 人 |
| **城主** | 石破天（A 级，土系） |
| **特产** | 石材、玉石、土系功法 |
| **威胁** | 三级岩甲虫、四级地震蠕虫 |

- 地下迷宫纵横交错，是战时避难所

**防御**：
- 山体内部被掏空，改造成要塞
- 可随时封闭入口，固守半年以上

### 8. 丰收镇

| 项目 | 内容 |
|------|------|
| **位置** | 中部平原核心，最肥沃的黑土地带 |
| **人口** | 约 25000 人 |
| **城主** | 田丰收（B 级，土系 + 木系双异能） |
| **特产** | 灵米、灵麦、各类蔬菜 |
| **威胁** | 二级变异蝗虫群、三级噬金鼠 |

**特色**：
- 人族最大的粮食生产基地
- 土地经过特殊改良，产量是外界的 5 倍
- 设有"粮仓"，储备可供 8 大城邦吃一年

**秘密**：
- 土地下方埋有 B 幻想出的"丰收之灵"（梦寐级）
- 丰收之灵每年苏醒一次，会让当年粮食产量翻倍
- 但需要献祭 100 头二级凶兽血肉
