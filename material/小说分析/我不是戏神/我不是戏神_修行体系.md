## 《我不是戏神》完整力量体系分析

---

### 一、世界框架

**两界并存**
- **现实界**：人类居住的九大界域（极光界域、红尘界域、无极界域、南海界域等）
- **灰界**：与现实并存的异界，天空铅灰，充斥灾厄，两界会通过倒影等方式交汇

**九大人类界域**（各有主城与特色文化，如极光城、红尘主城等）

---

### 二、灾厄体系

灰界中的怪物，按危险等级分级：

| 等级 | 说明 |
|------|------|
| 一般级 | 常见灾厄，能被低阶神道拥有者处理 |
| 高危级（约4-8级） | 威胁一个区域 |
| **灭世级**（第9级） | 能灭绝一整座人类界域；全灰界仅有数只 |

特殊灾厄：
- **咒文生物**（如咒文鳝鱼）：遍布咒文，被攻击即自爆
- **嘲灾（忌灾）**：灭世级，是灰界最强势力之一，盘踞"禁忌之海"

---

### 三、通神道路体系

#### 1. 总览
世界上原本存在**18条通神道路**，因时代演变，有**4条被遗落**，目前人类界域认可的只有**14条**。

#### 2. 现存十四神道（已确认出现的）

| 神道 | 特征与代表人物 |
|------|---------------|
| **兵神道** | 最主流，极光界域执法官专属；擅长战斗；路径有7种 |
| **医神道** | 楚牧云所走；擅长治疗与身体改造 |
| **青神道** | 画/绣类艺术神道；肖春萍、姚清（红尘君）所走 |
| **盗神道** | 篡火者使用；可隔空盗取事物 |
| **戏神道** | 表演艺术；戏道古藏守护；极为稀少，几近遗落 |
| **黄神道** | 冷门神道，需神眷才能踏上 |
| **娼神道** | 冷门神道，需神眷 |
| **巫神道** | 引动了陈伶的神道之一（紫色星辰） |
| **法神道** | 有提及 |
| **书神道** | 出现过一位书神道强者 |
| **偶神道** | 有提及（纸人类能力） |
| **修罗道**（兵神道路径）| 实为兵神道的一条路径 |

> 注：部分神道名称已确认，其余几条仅从字里行间推测存在。

#### 3. 四条遗落神道

| 遗落神道 | 说明 |
|----------|------|
| **帝神道** | 废除封建帝制后遗落；对应职业【皇帝】 |
| **其余三条** | 书中提及"有四条遗落"，具体名称未全部披露 |

### 四、神道的核心机制

#### （1）进阶方式
- **神眷**：神道自主选中天才，为最快捷的踏道方式
- **古藏试炼**：通过对应古藏的试炼，被神道认可
- **两者缺一不可**：只有"被神道看中"才能真正踏上该道路

#### （2）阶位体系

| 阶位 | 说明 |
|------|------|
| **一阶** | 踏上神道，自动掌握第一路径技能 |
| **二阶** | 获得第二技能 |
| **三阶** | 获得第三技能 |
| **四阶** | **质变**，获得"领域"；前三阶只是技能组合，四阶起一切技能在领域基础上延伸；同一路径的领域也因人而异 |
| **五阶** | 领域完全掌控 |
| **六阶** | 精英层 |
| **七阶** | 稀有；一个界域顶多数位 |
| **八阶** | 极为罕见，九大界域合计寥寥数人 |
| **九阶 / 半神** | 九君级别；"半神"境界，威压可笼罩城市 |
| **十阶（传说）** | 皇帝的野心目标，"两界冠绝古今的唯一真皇" |

#### （3）路径
同一神道下根据个人性格与天赋延伸出不同"路径"，路径决定具体技能。前三阶部分技能相同，四阶后技能差异越来越大，甚至同一路径不同拥有者的技能也会出现差异。

---

### 五、兵神道（最详细的神道）

路径已知有7种，主要出现：

| 路径 | 代表人物 | 代表技能 |
|------|----------|----------|
| 【审判】路径 | 韩蒙 | 一阶【杀戮舞曲】、三阶【杀戮舞曲（升阶）】、四阶【审判庭】（解构领域，泯灭物质）、五阶【宗罪判决】 |
| 【天狼】路径 | 聂雨、席仁杰 | 领域【目野猎场】（覆盖数公里，锁定猎物、速度体能剧降），虚空狼眸注视 |
| 【修罗】路径 | 简长生、其他 | 一阶【血衣】（超强生命力与再生）、二阶【滴血陀】（血珠变身） |
| 【铁衣】 | 多人 | 防御强化 |

### 六、戏神道（主角核心）

#### （1）踏道特殊性
戏神道因传统戏曲没落，几近遗落，极为稀少；靠"演出/表演"为核心驱动，"观众"的情感反应是力量来源。

**陈伶的戏神道极为特殊**——是被弟弟陈宴"扭曲"后的变体，比普通戏神道更强大也更诡异。

#### （2）陈伶的技能列表

| 技能 | 来源 | 说明 |
|------|------|------|
| 【无相】 | 扭曲戏神道（陈宴遗留），一阶变体 | 不仅能变脸变声，还能变成物品（超越普通【千面】） |
| 【猩红戏法】 | 扭曲戏神道，二阶 | 变换替换戏法，可瞬间替换自身与他物位置等 |
| 【描魂】 | 扭曲戏神道，三阶 | 代入角色，影响周围环境（陈伶的版本是代入"编导"自身） |
| 【织命】 | 扭曲戏神道，四阶（领域级） | 操控剧情与命运走向，安排场景 |
| 【血衣】 | 从简长生身上学到（修罗路径技能） | 濒死状态下力量暴涨，越受伤越强；加持身体素质与恢复力 |
| 【心蟒】 | 从他人身上学到 | 吞噬吸收情绪（如愤怒）；可反向灌回 |
| 【秘瞳】 | 医神道【血屠】路径一阶，学来 | 超强观察力，分析细节，后被融入【绘朱颜】 |
| 【审判庭】 | 兵神道【审判】路径四阶，学来 | 解构之力，泯灭物质；以三阶精神力驱动，威力有限 |
| 【正义的铁拳】 | 普通人文仕林技能 | 与神道无关的普通强化拳 |
| 【杀戮舞曲】 | 兵神道【审判】路径三阶，学来 | 战斗强化 |
| 【借月】 | 盗神道【借月】路径六阶，学来 | 高阶盗取能力 |

**核心能力：抽取技能**
陈伶的"观众"系统允许他在完成每段"剧目"后，从本剧目出场角色中**随机抽取一项技能**进行学习，抽取珍稀技能的概率与当次**综合观众期待值**相关，这是陈伶能集百家之长的核心外挂。

#### （3）戏道古藏五大秘法（师门传承）

| 秘法 | 说明 |
|------|------|
| 【唱】字秘法 | 以唱腔传递力量，如栾梅的戏腔即为此 |
| 【念】字秘法 | 以念白影响环境（如一字破风） |
| 【做】字秘法 | 形体融入角色，输出精准力量 |
| 【打】字秘法→**【袖手拨天】** | 无需精神力与阶位，将"戏道信念"注入戏神道，与角色灵魂共鸣后爆发惊人力量；可越阶杀敌（一阶杀三四阶），上限无穷；需"信念感"越深越强 |
| **【绘朱颜】** | 融合了【秘瞳】的观察能力；脸谱浮现，可以窥探他人真实面貌/内心 |

#### （4）戏神道的门派角色分工
**生、旦、净、末、丑**五种行当，对应五位师兄弟，各有不同的神道方向和技能风格：

| 角色 | 身份 | 主要能力 |
|------|------|----------|
| 【生角】宁如玉（大师兄） | 白衣，八阶级 | 极强实力，枪影开山；【袖手拨天】大师 |
| 【旦角】栾梅（二师姐） | 青神道+戏神道双修，六阶 | 绣丝领域，斩马刀，幕布封锁 |
| 【净角】闻人佑（三师兄） | | 枫叶化身（变形能力） |
| 【末角】四师弟 | 擅长分身 | 极远距离制造分身 |
| 【丑角】（老五） | 先天哑，守护丑峰 | 白灰封印技能、抽空精神力；扭曲空间如哈哈镜；速度极快、力量恐怖 |
| 【编导/陈伶】（六师弟/关门弟子） | 主角 | 扭曲戏神道，集百家之技 |

### 七、帝神道（遗落神道之一）

**路径：【皇帝】**，机制极为特殊：

| 机制 | 说明 |
|------|------|
| **浮动阶位** | 没有固定阶位；阶位取决于麾下臣子的实力 |
| **征用臣子技能** | 可直接使用所有臣子的神道技能（如有天狼五阶臣子，就能用天狼技能） |
| **引力本能** | 所有神道拥有者会无意识被【皇帝】吸引靠近，共鸣越强引力越强 |
| **孤家寡人则极弱** | 无臣子时，随便一个二阶都能击杀 |
| **上限极高** | 若收服九君级臣子，自身可接近九阶 |

踏上条件：封建帝制废除后几乎不可能出现，帝道古藏也未出世，书中那位"皇帝"是时代存档中的谜团人物。

---

### 八、九君与半神体系

**九君**：三百多年前，赤星碎片爆炸后诞生的九位顶级强者，代表人类最高战力（九阶半神）：

- **赤星愿力**是他们力量的本源（科研领域的极致——电磁、弦理论、数字、天体物理、材料学等各自"活过来"）
- 九君之间存在矛盾与对立
- 已知部分：极光君（已陨）、无极君（楼羽，材料学）、红尘君（苏知微，弦理论/青神道半神）

**贤者之石**：某种可以承载并延续九君精神与灵魂的容器。

---

### 九、"观众"体系（陈伶专属核心系统）

这是全书最独特的力量来源：

| 要素 | 说明 |
|------|------|
| **观众** | 无数猩红眼瞳的神秘存在，永远注视着陈伶的"表演" |
| **观众期待值** | 百分比；精彩表演/战斗/危险行动涨值；枯燥/失败/无聊降值 |
| **20%红线** | 低于20%不保证演员人身安全（"观众"会暴怒） |
| **70%阈值** | 达到70%可无副作用地复活（消耗50%期待值） |
| **剧目完成** | 完成某阶段"剧目"后，可从本剧目角色中随机抽取技能 |
| **舞台**与**帷幕** | 陈伶的人生是一场演出，他是唯一的主角，帷幕后藏有更深的秘密 |

复活机制：死亡时消耗50%观众期待值，以"重生"形式复活，因此陈伶多次在必死情况下存活。

### 总结：力量层次图

```
十阶（传说/皇帝野心目标）
    ↑
九阶·半神（九君，如红尘君、极光君、无极君）
    ↑
八阶（极少数，如鹤老、宁如玉师傅）
    ↑
七阶（一界数位，如鹤老）
    ↑
六阶（精英层，如肖春萍、宁如玉）
    ↑
五阶（强者，如聂雨·天狼）
    ↑
四阶——【质变·领域觉醒】
    ↑
三阶（陈伶当前主要活动层次）
    ↑
二阶
    ↑
一阶（踏上神道起点）
    ↑
普通人（无神道）
```

这套体系以"表演与信念"为核心美学，将戏曲文化与超凡力量深度融合，陈伶凭借扭曲的戏神道+观众期待值系统+抽取技能的外挂能力，走出了一条完全不同于任何神道的"编导之路"。
