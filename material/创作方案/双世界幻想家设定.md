## 一、核心世界观：双世界架构

### 【世界层级结构】

```
┌─────────────────────────────────────────────────────┐
│                    源初世界（本源）                    │
│                  一切存在的起点                        │
└─────────────────────────────────────────────────────┘
                        ↓ 分裂
        ┌───────────────┴───────────────┐
        ↓                                ↓
┌───────────────┐              ┌───────────────┐
│   外世界      │              │   里世界      │
│   (A 的世界)   │              │   (B 的世界)   │
│   科技蓝星    │              │   异能蓝星    │
│   无超凡力量  │              │   超凡泛滥    │
└───────────────┘              └───────────────┘
        ↓                                ↓
   由 B 幻想诞生                      真实存在
   依赖 B 的精神力                    独立运行
   存在 BUG 修复                      自然演化
```

---

### 【双世界本质区别】

| 维度 | 外世界 (A) | 里世界 (B) |
|------|------------|------------|
| **力量体系** | 纯科技，核弹为最强武器 | 异能超凡，S 级可灭城 |
| **时间流速** | 正常 | 相对缓慢（里世界 1 年=外世界 3 年） |
| **存在本质** | B 的幻想产物 | 真实本源世界 |
| **稳定性** | 存在 BUG，需自我修复 | 稳定自然演化 |
| **生物认知** | 无法看见里世界生物 | 可看见但需锚点 |
| **历史长度** | 约 200 年（B 幻想的起点） | 千年以上（陨石后） |
| **人口规模** | 80 亿 + | 不足 5 亿 |

---

### 【世界连接机制】

**水晶石（界石）**：
- **外观**：七彩剔透，拳头大小，内部有星河流转
- **来历**：B 接触的那颗陨石核心碎片，B 在幻想外世界时剥离出的"世界之种"
- **功能**：双世界穿梭媒介，唯一通道
- **特性**：
  - 只认 A 为宿主（因为 A 是 B 幻想的"自己"，血脉同源）
  - 穿越后自动回归祖宅，冷却 7 天后可再次穿越
  - 穿越时会携带当前世界的"气息"，导致两边世界产生微妙影响

**穿越规则**：
1. A 可自由往返双世界
2. A 在外世界死亡→真正死亡
3. A 在里世界死亡→回归外世界，但会丢失里世界获取的物品
4. B 无法感知 A 的存在（除非 A 主动接触封印）
5. A 在里世界待得越久，外世界的身体会越虚弱

## 二、陨石灾难编年史

### 【灾难前时代】（灾前纪元）

**时间**：陨石降临前
**世界状态**：
- 科技发达，与外世界 21 世纪相似
- 人口约 80 亿
- 龙国人口 14 亿，为世界第一大国
- 各国关系紧张，但未爆发大规模战争

**关键事件**：
- B 出生于龙国沿海城市
- 6 岁时父母带其去海边散心（父母发现 B 有轻度妄想倾向）
- 陨石灾难降临

---

### 【灾难元年】（灾厄历 0 年）

**陨石降临事件**：

```
【阶段一：检测】
- 直径 10 公里陨石被全球天文台检测到
- 预计撞击时间：30 天后
- 撞击点预测：太平洋海域

【阶段二：拦截】
- 全球各国联合发射导弹拦截
- 共计发射导弹：3,847 枚
- 拦截结果：失败，陨石仅被炸裂

【阶段三：碎裂】
- 主陨石碎裂为：
  - 1 块直径 1 公里的主核心（坠入太平洋）
  - 12 块直径 100-500 米的次核心（坠入各大洲）
  - 无数小型陨石（大部分在大气层解体）
  - 大量陨石尘埃（化为石粒散落全球）

【阶段四：撞击】
- 主核心撞击太平洋，坐标：(35.2°N, 142.8°E)
- 撞击能量：相当于 100 万颗广岛原子弹
- 引发的海啸：
  - 第一波：120 米高，袭击日本沿岸
  - 第二波：85 米高，袭击中国东部沿海
  - 第三波：65 米高，袭击美国西海岸
  - 后续余波：数十道 30-50 米海啸持续 72 小时

【阶段五：损失统计】
- 直接死亡：约 35 亿人（海啸 + 撞击）
- 间接死亡：约 15 亿人（灾后瘟疫 + 饥荒 + 辐射）
- 人类剩余：约 30 亿（原 80 亿）
- 城市毁灭：沿海城市 90% 被毁
- 国家消失：17 个岛国彻底灭国
```

### 【灾变初期】（灾厄历 1-10 年）

**世界状态**：
- 秩序崩溃，幸存者各自为战
- 通讯中断，交通断绝
- 辐射污染严重，变异生物开始出现
- B 在灾难中失去父母，独自生存

**B 的觉醒**：
```

【地点】：太平洋某岛屿（原中国沿海）
【事件】：
- 11 岁的 B 在废墟中流浪
- 发现一块七彩陨石碎片（界石本体）
- 触碰瞬间，陨石融入体内
- 觉醒 X 级天赋【幻想家】

【觉醒症状】：
- 高烧 7 天 7 夜
- 期间不断呓语，描述"另一个世界"
- 醒来后发现可以"想象出实物"
- 第一次具现：一块面包（耗时 3 小时）
```

**异能觉醒浪潮**：
- 灾厄历 5 年起，人类开始出现异能者
- 初期觉醒率：约 0.01%
- 后期觉醒率：逐年上升，至灾厄历 50 年达 30%
- 动植物变异率：约 60%

```
【尝试二：封印 B】
```

### 【封印时代】（灾厄历 61-1000 年）

**封印机制**：
```
【封印地点】：龙国腹地，地下 3000 米

- 营养仓：维持 B 生命

【封印代价】：
- 每年消耗：龙国 30% 能源
- 人员消耗：每 10 年更换一批小队（精神透支）

```

**幻梦界**：
```
【本质】：认知层面的亚空间
【规则】：
- 生物存在"锚点"
- 锚点=认知该生物的人类数量
- 锚点不足：生物无法影响现实
- 锚点足够：生物可短暂现世
- 锚点极深：生物可长期存在于现实

【封印生物清单】：
- 旧日支配者：12 位
- 东方鬼神：108 位
- 妖王魔尊：72 位
- 泰坦巨怪：24 头
- 后室实体：无数
- 丧尸变异体：无数

【现状】：
- 百年后（灾厄历 160 年），部分生物锚点已足够
- 千年后（灾厄历 1000 年），S 级生物可自由现世
```

**人族联邦扩张**：
```

  1. 龙渊城（龙国首都，原成都）

【人族控制区域】：
```

```
1. 想象（越详细越好）
2. 凝聚精神力
3. 物质重组（从虚空抽取能量）
4. 具现完成

【耗时规则】：
- 简单物品（面包、水）：1-3 小时
- 普通武器（刀剑）：1-3 天
- 奇幻武器（S 级）：1-3 月
- 奇幻生物（A 级）：3-6 月
- 神话生物（SS 级）：1-3 年
- 旧日支配者（SSS 级）：5-10 年
- 规则类（认知滤网）：瞬间（但消耗极大）

【消耗规则】：
- 精神力消耗与具现物强度成正比
- 过度消耗会导致精神崩溃
- 睡眠中具现消耗减半但不受控制
```

**限制**：
```
【无法具现】：
- 超越自己认知的东西
- 比自己强的存在（初期）
- 真正的生命（只能创造傀儡）
- 时间相关能力

【副作用】：
- 每次具现后精神疲劳
- 过度使用会加重妄想症
- 具现物过于强大时会反噬
- 具现的"神明"会获得自我意识
```

**特殊状态**：
```
【不死不灭】：
- 来源：具现的众神赐予
- 效果：物理攻击无效，精神攻击无效
- 限制：只能维持生命，无法行动

【幻想外溢】：
- 封印失效时发生
- 周围空间会出现幻想场景
- 封印生物可能逃脱
```

### 【金手指：界石】

**功能**：
```

- 需要定期返回外世界净化
- 严重时会分不清两个世界

- 无法将里世界的物品在外世界具现
- 无法将里世界的人带到外世界
- 外世界是"固定"的
```

## 十、创作注意事项

### 【逻辑自洽】

1. 双世界时间流速要一致（设定好比例）
2. A 的能力成长要有过程（不能太快）
3. 锚点机制要清晰（认知人数=锚点强度）
4. B 的幻想能力要有限制（不能无敌）

---

### 【避免毒点】

1. 不要让 A 过于圣母（该杀就杀）
2. 不要让 B 过于悲惨（要有希望）
3. 不要频繁穿越（会割裂剧情）
4. 不要让外世界太安全（要有危机感）

---

### 【推荐写法】

1. **双世界交替**：每 3-5 章切换一次视角
2. **悬念铺设**：每卷至少 3 个伏笔
3. **情感渲染**：B 的回忆杀要足够虐心
4. **战斗描写**：突出锚点规则的运用
