# 幻梦界19座次级城市设定

*注：8大城邦为联邦核心，19城为战略支点，分布在不同地理区域，各有特色*

---

## 一、地理位置与战略分布

### 北境防线（3城）
1. **冰骸城** - 北境第一屏障
   - **地理位置**：位于蓝星北半球冻土带边缘，直面"永夜裂谷"（凶兽王庭北境入口）
   - **主导势力**：人族联邦·冰骸守备军 + 镇梦司北境分部
   - **城邦主官**：守备将军·秦霜（SS级冰系法相者）+ 镇梦司统领·陆沉（S级精神系）
   - **人口规模**：约120万（其中异能者占30%）
   - **城市布局**：三层环形城墙，外层平民区、中层商业区、内层军事要塞
   - **特色异能流派**：
     * **"霜脉诀"**：冰系极致流，修炼至法相期可凝聚"冰魄法相"，寒气可冻结空间碎片
     * **"铁壁寒罡"**：躯体系防御流派，结合冰霜硬化皮肤，形成"冰岩龟甲"
     * **"寒音镇魂"**：精神系+冰系复合流派，用冰晶共振干扰精神力扫描
   - **城邦政治关系**：
     * 对8大城邦：忠诚联邦，但经常抱怨补给不足
     * 对其他19城：与南境炎城结为"阴阳同盟"，共享气候对抗经验
     * 与镇梦司：合作密切，但私下不满"认知封锁"政策——北境凶兽威胁太大，需要更多信息
   - **收容设施**：北境异常收容所（关押浮梦级~噩梦级生物12种）
   - **特殊制度**："全民觉醒体检"——每名新生儿强制检测，疑似认知敏感者送联邦培养（实为监控）

2. **雪松堡** - 北境科研重镇
   - **地理位置**：冰骸城南80公里，建立在古陨石撞击坑遗址上
   - **主导势力**：联邦科学院·北境分院 + 部分自由学者联盟
   - **城邦主官**：院长·墨清（SS级规则系"重力操控"）+ 学术委员会
   - **人口规模**：约80万（科研人员占40%）
   - **特色异能流派**：
     * **"陨石炼金术"**：造物系分支，研究陨石碎片提纯与异能增幅
     * **"重力场编织"**：规则系精密操控，可制造局部高重力训练场
     * **"数据可视化精神术"**：精神系辅助流派，将探测数据转化为3D影像
   - **研究重点**：
     * 认知锚点量化模型
     * 幻梦界生物"现实化"阈值研究
     * 陨石能量与灵根序列关系
   - **政治关系**：技术中立，但受联邦资助，倾向于保守派（维持现状）
   - **著名设施**：陨石撞击坑纪念馆（收容"梦寐级"生物"陨石悲鸣"）

3. **北风要塞** - 商旅枢纽
   - **地理位置**：北境交通咽喉，连接冻土带与温带区的唯一安全通道
   - **主导势力**：商盟自治 + 联邦驻军监督
   - **城邦主官**：商盟主席·万通（E级"千里眼"）+ 驻军指挥官
   - **人口规模**：约60万（流动人口占50%）
   - **经济特色**：陨石碎片黑市（半公开）、凶兽材料贸易、异能装备租赁
   - **特色异能流派**：
     * **"风语传讯"**：元素风系+精神系复合，可跨城邦加密传讯
     * **"探查八相"**：精神系侦查流派，开发出"锚点敏感度探测术"
   - **政治关系**：中立贸易区，各方势力都有办事处，镇梦司在此设"认知污染监测站"

### 西境荒漠（3城）
4. **沙砾城** - 荒漠绿洲奇迹
   - **地理位置**：西境大荒漠东部，依靠地下古水系幸存
   - **主导势力**：自治议会 + 联邦西境防务局
   - **城邦主官**：议长·沙远山（A级土系+水系"沙漠甘霖"）
   - **人口规模**：约50万
   - **特色异能流派**：
     * **"沙遁术"**：土系变异应用，可融入沙粒移动，偷袭流
     * **"水源共鸣"**：水系稀缺流派，能从空气、植物中提纯水分
     * **"古文字解读"**：精神系特殊能力，部分人觉醒后可解读古陨石铭文（疑似B当年留下的信息）
   - **政治关系**：独立倾向较强，因资源匮乏常与联邦讨价还价
   - **收容设施**：荒漠收容站（关押与沙土相关的醒梦级生物）

5. **遗迹镇** - 古文明探秘中心
   - **地理位置**：西境荒漠深处，发现大规模前陨石时代遗迹群
   - **主导势力**：考古学者公会 + 联邦文化部
   - **城邦主官**：公会会长·文渊（S级精神系"记忆回溯"）
   - **人口规模**：约30万（学者比例极高）
   - **重大发现**："龙国先民碑"——记载千年前陨石降落时的恐怖景象，碑文提及"紫色流星"（B那块陨石）
   - **特色异能流派**：
     * **"历史重现"**：精神系极致应用，可短暂回放特定地点的历史片段
     * **"遗迹能量共鸣"**：与古遗迹产生共振，解锁隐藏空间
   - **政治关系**：因研究敏感历史，被镇梦司严密监控
   - **与A的关联**：A穿越后可能被此处学者发现，因其对"外世界"的描述与研究悖论

6. **驼铃镇** - 荒漠贸易中转站
   - **地理位置**：沙砾城与遗迹镇之间400公里荒漠的唯一补给点
   - **主导势力**：商队行会自治
   - **人口规模**：约10万（极小型）
   - **特色异能流派**：
     * **"沙舟术"**：在沙面快速移动的技巧，结合风系、土系
     * **"方向感知"**：精神系辅助，荒漠中永不迷路（稀有）
   - **政治关系**：中立，向沙砾城和遗迹镇纳贡换取保护

### 东境海岸（4城）
7. **潮汐城** - 最大海港
   - **地理位置**：东部海滨，原陨石撞击大海形成的"陨星海"岸边
   - **主导势力**：联邦海军司令部 + 商会联盟
   - **城邦主官**：海军上将·龙063（SS级水系"海皇法相"）+ 商会会长
   - **人口规模**：约200万（19城中最大）
   - **特色异能流派**：
     * **"潮汐咒文"**：水系法术体系，利用月相、潮汐涨落增强威力
     * **"深潜者"**：躯体系变异，可长时间深海活动，皮肤再生
     * **"海鲜培育"**：造物系应用，养殖变异海产（高价值凶兽材料）
   - **经济地位**：海洋资源进出口中心，深海凶兽狩猎队集散地
   - **收容设施**：海洋异常收容所（关押水生幻梦生物，如"深潜梦魇"）
   - **政治关系**：与内陆城邦贸易往来密切，但被讥讽为"海鲜暴发户"

8. **渔歌镇** - 传统渔村转型
   - **地理位置**：潮汐城北100公里，陨星海内湾
   - **主导势力**：渔民公社 + 镇梦司海洋监测站
   - **人口规模**：约40万
   - **特殊现象**：渔民常年在陨星级碎片辐射下工作，觉醒率异常高（50% vs 全国95%）
   - **特色异能流派**：
     * **"渔网术"**：水系+躯体系复合，可编织能量渔网
     * **"海雾编织"**：元素系+精神系，制造带有幻觉的浓雾
   - **与收容体系关系**：渔民常误捞浮梦级生物，与镇梦司冲突频发

9. **灯塔岛** - 孤立海港
   - **地理位置**：陨星海中央孤岛，原联邦灯塔改造
   - **主导势力**：联邦直管·孤岛监狱/收容所
   - **人口规模**：约5万（含罪犯、收容失效危险生物）
   - **收容设施**：噩梦级收容塔（关押3只清醒级生物）
   - **特殊制度**："轮换制度"——高危险度收容人员每月从8大城邦轮换
   - **与A的关联**：如果A被镇梦司擒获，初期可能关押在此

10. **礁石堡** - 海岸防线要塞
    - **地理位置**：潮汐城南50公里，扼守入海河道
    - **主导势力**：联邦海岸警卫队 + 本地民兵
    - **特色异能流派**：
      * **"礁石硬化"**：躯体系防御，身体局部石化
      * **"水箭术"**：基础水系攻击，但射速极快
    - **政治关系**：潮汐城的卫星城，提供缓冲纵深

### 南境丛林（4城）
11. **绿洲城** - 丛林都市
    - **地理位置**：南境热带雨林北缘，陨石撞击形成的巨大湖"幻梦湖"旁
    - **主导势力**：联邦南境管理总局 + 丛林猎手公会
    - **人口规模**：约150万
    - **特色异能流派**：
      * **"植物操控"**：精神系与造物系交叉，可加速植物生长、改造植物性质
      * **"毒抗体质"**：躯体系变异，长期接触丛林毒素产生抗性
      * **"雨林隐匿"**：利用植物、气候隐藏身形，侦察流派
    - **经济特色**：药用植物培育、凶兽毒素提取、热带水果出口
    - **收容设施**：南境丛林收容所（关押植物类幻梦生物）

12. **苗圃镇** - 变异植物研究
    - **地理位置**：绿洲城西南50公里，深入雨林
    - **主导势力**：联邦生物研究院分院
    - **特色异能流派**：
      * **"嫁接术"**：造物系应用，将不同植物特性融合
      * **"光合呼吸"**：躯体系变异，可进行光合作用减少进食
    - **重要设施**：变异植物基因库（保存了大量已灭绝/变异前的物种基因）

13. **蟒穴镇** - 危险狩猎区
    - **地理位置**：绿洲城东南，靠近"巨蟒谷"（A级凶兽"虚空巨蟒"巢穴）
    - **主导势力**：猎人工会分会 + 雇佣兵団
    - **人口规模**：约20万（高风险高收益）
    - **特色异能流派**：
      * **"蟒语术"**：精神系沟通凶兽，稀有能力
      * **"蜕皮再生"**：模仿凶兽的自愈术
    - **政治关系**：与绿洲城关系紧张——这里危险，但猎人不愿受管束

14. ** orchidelice** - 幻梦湖畔小镇
    - **地理位置**：幻梦湖西岸，原名"兰花镇"，因异能催生珍稀兰花改名
    - **主导势力**：花商行会 + 镇梦司隐蔽观测点
    - **特色异能流派**：
      * **"幻香术"**：精神系+造物系，培育散发幻觉香气的花卉
      * **"花粉过敏"**：特殊体质，可免疫大部分植物毒素
    - **特殊现象**：湖面常在午夜浮现"倒影城市"（疑似幻梦界入口），镇梦司严密监控

### 中央腹地（5城）
15. **锈铁城** - 工业废墟上的重生
    - **地理位置**：中央平原，曾是陨石撞击最严重的工业区
    - **主导势力**：联邦工业部 + 机械师工会
    - **人口规模**：约180万
    - **特色异能流派**：
      * **"金属操控"**：元素系分支，可磁化、软化金属
      * **"机械共生"**：躯体系+造物系融合，将机械部件融入身体
      * **"焊接术"**：造物系实用应用，快速修复、制造
    - **经济地位**：制造业中心，生产异能武器、汽车、工业设备
    - **特殊设施**：陨石撞击纪念馆（内有"锈蚀梦魔"收容）

16. **谷物镇** - 联邦粮仓
    - **地理位置**：锈铁城东南，中央大平原农业区核心
    - **主导势力**：农业合作社 + 联邦粮食部
    - **人口规模**：约100万
    - **特色异能流派**：
      * **"催熟术"**：木系变异，加速作物生长（稀缺）
      * **"土壤改良"**：土系应用，逆转陨石污染
      * **"抗灾术"**：组合法术，抵御农药无法解决的变异害虫
    - **政治地位**：粮食安全命脉，受到严密保护

17. **矿山镇** - 陨石矿脉重镇
    - **地理位置**：锈铁城西北，发现大量陨石矿脉
    - **主导势力**：联邦矿业集团 + 矿工工会
    - **特色异能流派**：
      * **"矿脉感应"**：精神系探矿能力
      * **"爆破术"**：火系应用，定向爆破
      * **"岩壁行走"**：土系能力，垂直表面移动
    - **特殊现象**：矿工长期暴露高浓度幻元粒子，偶有"矿难的记忆"集体幻听（疑似收容失效）

18. **齿轮镇** - 科技研发中心
    - **地理位置**：锈铁城卫星城，10公里
    - **主导势力**：私立研究所集群
    - **特色异能流派**：
      * **"能量回路雕刻"**：造物系精细操作，制作异能装备核心
      * **"自动傀儡术"**：造物系创造机械/能量生命
    - **著名机构**："陨石能量应用研究所"（研究陨石碎片提纯技术）
    - **政治关系**：独立于联邦，但技术被各方购买；与唤梦者、幻梦教廷均有秘密接触

19. **书城** - 知识中心
    - **地理位置**：中央腹地，原国家图书馆废墟重建
    - **主导势力**：联邦学术委员会 + 各大高校
    - **人口规模**：约70万（师生比例高）
    - **特色异能流派**：
      * **"记忆宫殿"**：精神系辅助，超强记忆力
      * **"知识具现"**：规则系罕见应用，可将理论知识转化为临时实体（如具现一个物理公式模型）
      * **"古籍修复"**：造物系+精神系，修复古文献
    - **与A的关联**：如果A在里世界展现"外世界知识"，此地学者会极度狂热
    - **政治关系**：中立学术立场，但被镇梦司要求 censored 部分"危险知识"

## 二、城市间的政治与经济关系

###  alliance格局
- **核心8城**：联邦权力中心，严格控制异能修炼资源、收容体系、情报网络
- **19城定位**：
  * 战略要地（冰骸城、潮汐城、锈铁城）：受联邦直接军管
  * 资源产地（矿山镇、谷物镇、苗圃镇）：经济价值高，政治地位中等
  * 科研中心（雪松堡、书城、齿轮镇）：影响力大但武力弱
  * 边境贸易（北风要塞、驼铃镇）：中立但受各方拉拢
  * 特殊区域（灯塔岛、礁石堡）：收容体系节点
