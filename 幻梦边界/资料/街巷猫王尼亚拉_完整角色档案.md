## 二、外观描述

### 2.1 常态形象
- 体型如普通家猫，但通体覆盖**深紫灰色**短毛，在暗处呈现流动的**星空纹路**
- 双眼为**琥珀色竖瞳**，瞳孔深处有微型星系在旋转——仔细看会发现那是一个缩微版的蓝星
- 左耳有一道陈旧的缺口，像是被什么东西咬掉的（实际上是自愿给予某个存在的"信物"）
- 尾巴尖端始终笼罩着一层淡薄的**紫雾**，走过的地面会短暂浮现猫爪形的符文

### 2.2 真实形态（极少展露）
- 身高可达**三米**的人形猫科生物，双足直立
- 全身覆盖刻满**原初文字**的深紫鳞甲，每一片鳞甲都是一个被封存的"概念"
- 头部保持猫形，但长有**九条尾巴**，每条尾巴连接着一个不同的"认知维度"
- 背后展开一对由纯粹**信息流**构成的翅膀——看见翅膀的人会瞬间理解一个终极真理，然后立刻忘记
- 胸口有一个**空洞**，形状恰好是一块水晶石的轮廓（与A在祖宅发现的七彩水晶石完全吻合）

### 2.3 伪装形态
- 可变化为任何品种的普通猫咪
- 最常使用的伪装：一只瘸腿的橘猫，名叫"阿橘"，在恒都第七区流浪猫群中混迹
- 偶尔伪装为人类——一个穿紫灰色风衣、戴圆框墨镜的消瘦青年，自称"倪先生"

## 三、能力体系

### 3.1 核心能力——「万巷通途」
**本质：** 尼亚拉掌控着所有"巷道"的概念。只要是两面墙壁之间的缝隙、建筑之间的通道、甚至概念上的"夹缝"，都是它的领域。

| 能力名称 | 描述 | 等级 |
|----------|------|------|
| **巷道穿行** | 通过任意巷道瞬间到达另一条巷道，无视距离与城邦边界 | 基础 |
| **夹缝窥视** | 通过任何"缝隙"（门缝、墙缝、甚至心理防线的裂缝）进行窥视 | 基础 |
| **概念夹层** | 在两个概念之间创造"夹缝空间"，可用于藏匿物品、生物甚至整个事件 | 高阶 |
| **巷道迷宫** | 将一片区域的所有通道扭曲成无限循环的迷宫，困住目标 | 高阶 |
| **缝隙之门** | 打开通往"里世界与外世界之间"的裂缝——这是唯一一种不需要七彩水晶石就能沟通两个世界的方式 | 禁忌 |

### 3.2 次级能力——「九命猫王」
- 拥有**九条命**，但并非简单的复活——每"死"一次，就会在一个不同的认知维度重新凝聚
- 目前已消耗**六条命**，剩余三条
- 每消耗一条命，对世界真相的理解就更深一层
- 第一条命：死于陨石坠落（获得了对"灾变"的理解）
- 第二条命：死于第一代镇梦司司长的封印术（理解了"人类的恐惧"）
- 第三条命：自愿死于一头Lv.5凶兽（理解了"野性与进化"）
- 第四条命：死于一次"概念坍缩"事件（理解了"存在与虚无的边界"）
- 第五条命：死于试图唤醒B的失败尝试（理解了"封印的本质"）
- 第六条命：死于观测到A的诞生瞬间（理解了"幻想与现实的区别"）

### 3.3 特殊能力——「认知免疫」
- 尼亚拉**完全免疫**所有基于认知锚点的攻击和影响
- 原因：它自身就是一个"已经被完全认知"的存在——全世界的猫的概念汇聚而成
- 它不怕被遗忘，因为只要世界上还有一只猫，它就存在

### 3.4 终极能力——「薛定谔的观测」
- 可以让任何事物进入"既存在又不存在"的叠加态
- 在这个状态下，目标同时是真实的和幻想的，直到被"观测"
- **关键：** 这个能力与A的"认知者"能力形成完美互补——尼亚拉制造叠加态，A的观测决定结果

## 四、真实身份与起源

### 4.1 它到底是什么？

**尼亚拉是B在幻想外世界时，无意中赋予了"自我意识"的一个概念。**

具体来说：
- B在创造外世界（A的世界）时，幻想了"街头巷尾的流浪猫"这一温馨场景
- 这个幻想注入了B对"自由"和"不被约束"的强烈渴望（因为B此时正被世界的重压压得喘不过气）
- 这份渴望太过强烈，导致这个幻想**反向穿透**回了里世界
- 于是，一只凝聚了"自由"概念和"B的部分意识碎片"的猫，在里世界的巷道中诞生了

### 4.2 与B的关系
- 尼亚拉携带着B在创造外世界时的**情感记忆碎片**
- 它知道外世界的存在，但无法完整了解——就像只看了一本书的目录
- 它对B有一种复杂的情感：既是创造者与被造物的纽带，又是囚犯与自由化身的对照
- **关键秘密：** 尼亚拉胸口的空洞就是B当初"抽取"自由概念时留下的痕迹——那个空洞的形状与七彩水晶石吻合，因为水晶石就是那块被抽走的"自由"凝结而成

### 4.3 与七彩水晶石的关系
- 七彩水晶石 = B的"自由意志"结晶 = 尼亚拉诞生时被分离出的核心
- 水晶石被B无意识地送往了外世界（送到了A的祖宅）
- 当A触碰水晶石穿越到里世界时，实际上是**尼亚拉失散的核心找到了新的承载者**
- 这就是为什么尼亚拉会第一时间察觉到A的到来

## 五、真实目的（三层嵌套）

### 第一层（表面目的）——「守护者」
**对外宣称：** 保护蓝星的街巷秩序，维护猫族在人类城邦中的生存空间。

- 这是镇梦司和各城邦认知中的尼亚拉
- 它确实在做这件事——管理着一个庞大的流浪猫情报网络
- 各城邦默许它的存在，因为它的猫群是最好的低级异常预警系统
- **可信度：** 高。它确实花了数百年时间建立这个网络

### 第二层（隐藏目的）——「寻匙者」
**真正在做的事：** 寻找一个能够"正确观测"这个世界的人，用来打开里世界与外世界之间的通道。

- 尼亚拉知道这个世界是B幻想的产物，但它不确定这意味着什么
- 它消耗了六条命来理解世界真相，得出结论：**需要一个"外来者"的视角来校准这个世界**
- 它一直在等待A的出现——一个来自"外世界"的认知者
- 七彩水晶石就是它留下的"钥匙"，A的穿越是它千年计划的第一步
- **矛盾：** 它并不确定打开通道后会发生什么——是两个世界融合？还是其中一个崩溃？

### 第三层（最深层目的）——「自由的追寻」
**它自己都未完全意识到的驱动力：** 找回自己失去的"核心"，实现真正的"自由"。

- 尼亚拉的本质是"自由"的概念体，但它诞生时核心就被分离了（变成了水晶石）
- 这意味着它是一个**"不完整的自由"**——它可以去任何地方，却永远觉得缺少什么
- 它潜意识中渴望与水晶石重新融合，但水晶石现在与A绑定了
- 这造成了一个终极矛盾：**要获得完整的自由，它可能需要牺牲A**
- 但A是B幻想的产物，而B的幻想创造了尼亚拉——毁掉A可能导致尼亚拉自身也消失

## 六、与主角A的互动方式

### 6.1 相遇（第一阶段：试探）

**时间线：** A刚穿越到里世界，在荒野被凶兽追赶时

| 阶段 | 尼亚拉的行为 | 真实意图 |
|------|-------------|----------|
| 初遇 | 以"阿橘"形态出现，一只看似普通的瘸腿橘猫，在A逃跑时突然出现在他面前 | 确认A是否携带水晶石的气息 |
| 救助 | 引导A通过巷道（即使在荒野中也"恰好"有两块巨石形成的缝隙）逃离凶兽 | 展示"巷道穿行"能力的冰山一角，同时测试A是否能感知异常 |
| 观察 | 远远跟随A，在他被人类小队发现前始终保持距离 | 观察A对里世界的"认知反应"——他能看见多少？理解多少？ |
| 初次对话 | A被小队收留后的第一个夜晚，阿橘跳上A的窗台，开口说话："你看得见我的尾巴有几条？" | 关键测试——普通人只能看到一条尾巴，认知越深看到的越多。如果A能看到全部九条，说明他就是"那个人" |

**A的可能反应：**
- A因为熟读各种神话传说，可能立刻联想到"九尾猫"的传说
- A可能看到的不是九条尾巴，而是**不确定数量**的尾巴——因为他同时是"幻想存在"和"外来观测者"
- 这个模糊的观测结果反而让尼亚拉更加确信：A就是它要找的人

### 6.2 建立关系（第二阶段：引导）

**时间线：** A进入恒都后的前三个月

**互动模式：** 尼亚拉以"阿橘"身份成为A的"导游猫"

| 互动方式 | 表面作用 | 真实目的 |
|----------|----------|----------|
| **街巷情报** | 带A走各种捷径，帮他熟悉恒都地理 | 让A的"认知地图"逐渐覆盖恒都的所有巷道——这些巷道是尼亚拉的力量节点 |
| **异常科普** | 在A遇到低级异常时，用看似无意的猫叫声暗示危险等级 | 训练A的"认知判断力"，让他学会区分不同等级的异常 |
| **信任建立** | 偶尔带回小鱼干给A，做一些普通猫会做的事（蹭腿、呼噜、占领键盘） | 降低A的戒心，让A把它当成"宠物"而非"异常生物" |
| **关键暗示** | 在A睡着时，轻声说一些关于"梦"和"创造"的模糊话语 | 在A的潜意识中植入对"世界真相"的疑问种子 |
| **认知投喂** | 引导A去图书馆查阅特定的古籍，或"恰好"路过某个展示异常档案的地方 | 系统性地扩展A的认知范围，让他的"认知者"能力快速成长 |

**标志性场景：**
> A在恒都第七区的一条死胡同里，看到阿橘坐在墙头上，影子却投射在**墙的另一面**。A问："你的影子怎么是反的？"阿橘舔了舔爪子："你倒是先找找你自己的影子在哪儿。"这是A第一次意识到自己在里世界没有影子。

### 6.3 深入合作（第三阶段：共谋）

**时间线：** A加入镇梦司后

**互动模式：** 从"宠物猫"升级为"非官方顾问"

| 事件 | 尼亚拉的角色 | 隐藏推动 |
|------|-------------|----------|
| A的第一次收容任务 | 以"倪先生"人形出现，自称"民间异常研究者"，提供关键情报 | 确保A接触的第一个异常是"可控级别"的，让他建立信心 |
| A发现自己无法修炼异能 | 阿橘叼来一本破旧的手札，上面记载着"认知者"的概念 | 这本手札是尼亚拉用第四条命的代价从"概念坍缩"中抢救出来的，里面记载了一种不需要异能也能对抗异常的方法 |
| A第一次面对高危异常 | 尼亚拉短暂展露"万巷通途"能力，将A从战场拉入巷道夹缝 | 让A亲身体验"概念夹层"的存在，为后续理解"里外世界夹层"做铺垫 |
| A开始质疑世界的真实性 | 尼亚拉第一次以"半真实形态"（常态猫但九尾可见）出现在A面前，坦白自己不是普通猫 | 开始逐步向A透露世界真相，但只给碎片化信息，保持A的好奇心 |
| A遭遇镇梦司内部的政治阴谋 | 利用猫群网络为A收集情报，暗中保护A | 镇梦司中有人想利用A的"世界BUG"特性来加强封印，这与尼亚拉的计划冲突 |

### 6.4 关系裂痕（第四阶段：冲突）

**时间线：** A的认知等级达到Lv.3后

**核心冲突：** A开始足够强大，能够感知到尼亚拉的隐藏意图

| 冲突点 | A的立场 | 尼亚拉的立场 |
|--------|---------|-------------|
| **世界真相** | A发现里世界可能是"被创造的"，感到恐惧和愤怒 | 尼亚拉认为"被创造"不等于"不真实"，但拒绝透露更多 |
| **利用嫌疑** | A意识到尼亚拉一直在"培养"自己，质疑所有互动的真实性 | 尼亚拉承认有目的性，但坚持情感是真实的："利用和在乎不矛盾" |
| **水晶石** | A发现水晶石与尼亚拉胸口空洞的关联，怀疑尼亚拉最终会夺取水晶石 | 尼亚拉第一次表现出真正的痛苦："我确实想要它回来，但我更想知道...没有它的我，算不算真正的自由" |
| **B的命运** | A不确定是否应该唤醒B（唤醒B可能导致外世界消失=A的家人消失） | 尼亚拉也不确定——唤醒B可能让一切重来，包括它自己 |

**标志性场景：**
> A在雨夜的巷道里抓住阿橘的尾巴（此时能看到全部九条）："你到底是谁？你到底想要什么？" 尼亚拉第一次沉默了很久，然后变成真实形态，蹲下来与A平视："我是你祖宅里那块石头做的一个梦。而你……你是那个做梦的人做的一个梦。我们都是梦，孩子。区别在于——我想醒来，而你还不知道自己在做梦。"

### 6.5 最终抉择（第五阶段：共鸣）

**时间线：** 故事高潮

**终极互动：** 当A面临最终选择时（唤醒B vs 维持现状 vs 第三条路）

- 尼亚拉消耗第七条命，为A打开一条"缝隙之门"，让A短暂与B的意识对话
- 在这个过程中，尼亚拉终于明白："自由不是一块石头，自由是**选择**的权利"
- 它放弃了夺回水晶石的念头，转而帮助A寻找"第三条路"——既不唤醒B也不维持现状，而是让两个世界都成为"真实"
- **代价：** 尼亚拉可能需要消耗剩余的全部生命来维持两个世界之间的"巷道"

## 七、隐藏计划全貌

### 7.1 千年计划时间线

```
陨石降临 → 尼亚拉诞生（从B的幻想中反向凝聚）
  ↓
前100年 → 消耗三条命理解世界本质
  ↓
100-500年 → 建立猫群情报网络，收集关于B的信息
  ↓
500-800年 → 消耗第四、第五条命，确认需要"外来观测者"
  ↓
800-999年 → 布局——在外世界的"对应位置"留下水晶石的线索
            （通过"缝隙之门"将信息渗透到A的祖宅所在位置）
  ↓
第1000年 → A触碰水晶石，穿越到里世界
           消耗第六条命确认A的身份
  ↓
当前 → 培养A的认知能力，准备打开"第三条路"
```

### 7.2 棋局中的各方关系

```
          镇梦司（想维持封印）
              ↑ 对抗
              |
    焚寂城（想唤醒B）←——冲突——→ 尼亚拉（想找到第三条路）
              \                    /
               \                  /
                ↘              ↙
                  主角A（关键变量）
                      ↕
                   原身B（沉睡中）
```

### 7.3 隐藏的棋子
尼亚拉在千年间布置了几个关键棋子：

1. **静湖城的"外世界理论"** —— 是尼亚拉通过猫群散布的碎片信息催生的学术方向
2. **蔓城伊甸区** —— 那个"未变异区域"实际上是尼亚拉用"概念夹层"能力维持的——它在那里复刻了一小块外世界
3. **恒都第七区的流浪猫群** —— 其中有三只猫是尼亚拉的"分身"，分别监视着永眠层（B的封印处）的三个关键节点
4. **风蚀城的情报** —— 风蚀城能探测到A出生时的"认知波"，其实是尼亚拉刻意引导的

## 八、性格特征与行为模式

### 8.1 核心性格

| 特征 | 表现 |
|------|------|
| **傲慢而孤独** | 以猫特有的高傲行事，但千年的独自布局让它内心极度孤独。A是它千年来第一个真正的"对话者" |
| **慵懒而警觉** | 90%的时间在睡觉（或假装睡觉），但任何异常波动都逃不过它的感知 |
| **诚实的说谎者** | 它说的每句话都是真的，但永远不说完整的真话。"我没骗你，我只是没全告诉你" |
| **自由的囚徒** | 可以去任何地方，但胸口的空洞让它永远无法真正感到"完整"。它是自由的化身，却是唯一不自由的存在 |
| **矛盾的慈悲** | 它真心关心A，但不确定这份关心有多少是"利用的副产品"。这个自我怀疑本身折磨着它 |

### 8.2 标志性行为

- **口癖：** 经常以反问回答问题。"你问我是谁？你先告诉我，你觉得你是谁？"
