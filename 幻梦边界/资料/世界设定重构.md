# 第一卷：禁忌之源——B的真相

## 一、B的存在——被掩埋千年的真相

### 1.1 千年前的那一天

**新历元年之前**，陨石降临，人类濒临灭绝。在混乱中，一个名叫**B**的年轻人觉醒了前无古人的异能——“幻想家”。

B做了什么？
- 他用幻想稳定了碎裂的大陆板块
- 他用幻想建立了“认知滤网”，将幻梦界与现实层分离
- 他用幻想创造了“外世界”——一个没有陨石的完美世界
- 他用幻想创造了无数生灵——神、魔、妖、怪、鬼、诡

代价是什么？
- 他的精神崩溃了
- 他的身体被他自己幻想的神明赐予了“不死不灭”
- 他陷入了永恒的沉睡——既不能醒，也不能死

### 1.2 “醒祸事件”——为什么真相只能口口相传

**新历742年**，发生了一场几乎毁灭世界的灾难。

当时的一位联邦议长（第26代），为了“让后人铭记B的牺牲”，将B的真相详细记录在一份绝密文档中，存放在衡都的地下 vault。文档中包含了：
- B的姓名、样貌、生平
- B的封印地点（衡都地下3000米）
- B的封印结构
- 唤醒B的方法

这份文档被一个潜伏在衡都的间谍组织（后来被证实是“唤梦者”的前身）截获。

**他们做了什么？**

他们用了三年时间，组织了127名精神系异能者（最强者为SS级），在封印地周围布下了“唤梦大阵”。他们的目的是——**唤醒B**。

他们成功了。

B醒了。

**然后呢？**

B醒来的那一瞬间：
- 他的意识碎片像洪水一样涌入现实
- 所有被他幻想过的存在——无论善恶、无论大小——都在那一刻**同时具现**
- 幻梦界与现实层的边界瞬间崩塌

**那一天被称为“醒祸日”。**

**灾难的规模**：
- 幻兽爆发：超过**3000只**幻兽同时具现，从潜梦级到清醒级不等
- 伤亡：**7座城镇被彻底摧毁，死亡人数超过50万**
- 泰坦级幻兽“终焉之龙”的躯体从幻梦界挤出来，仅仅是一个爪子，就压垮了衡都的东墙
- 概念级幻兽“群体恐慌”在人群中蔓延，导致三座城邦陷入暴乱
- 神明级幻兽“审判者”开始审判所有人——“有罪者死”，一天之内处决了3万人

**B做了什么？**

B醒来后，用了大约**30秒**理解发生了什么。

然后他做了一件事：**他重新沉睡了。**

不是被迫的，是主动的。他在意识消散的最后一刻，用尽全部力量：
- 将所有幻兽重新推回幻梦界
- 加固了认知滤网
- 在封印上增加了一层“自我封印”——任何人试图唤醒他，他会自动加深沉睡

**B的最后一段话**（被当时在场的守护者记录，代代口传）：
> *“不要叫醒我。永远不要。我不是英雄，我是……一个会做梦的人。梦醒了，世界就碎了。让我睡吧。”*

### 1.3 “醒祸事件”后的规则

**规则一：只口传，不记录**
- 任何关于B的文字、图像、声音记录，必须在24小时内销毁
- 违者——不是法律惩罚，而是**会被B的精神残留“抹除”**（原因不明，推测是B的潜意识在保护自己）

**规则二：领导人必须是精神系异能者**
- 只有精神系异能者能承受B的精神残留
- 只有精神系异能者能“听到”B的梦话（判断封印状态）
- 只有精神系异能者能执行“最后的手段”

**规则三：退位领导人成为“守墓人”**
- 退位的联邦议长、龙国执政官、镇梦司司长，自动成为永眠层的守护者
- 守护者不退休、不离开、不见外人
- 守护者的寿命会被B的精神残留“同化”——变得很长（数百年），但会逐渐失去自我

**规则四：B的存在是最高禁忌**
- 除了守护者和现任领导人，任何人不得知道B的存在
- 所有关于B的讨论，只能在永眠层内进行
- 违反者——会被“遗忘”（B的精神残留会抹除相关记忆）

## 二、B的诅咒——不死不灭的死循环

### 2.1 永生的赐福

B在幻想“神明”时，幻想了一个“守护之神”——一个会保护他、让他永远安全的存在。

但这个神明“误解”了B的愿望。

B想的是：“希望我永远不会受到伤害。”

神明理解的是：“希望他永远不会死。”

于是，神明赐予了B**不死不灭之身**：
- 他不会老（年龄永远停在20岁）
- 他不会病（任何疾病都会自愈）
- 他不会死（任何致命伤都会在瞬间恢复）

### 2.2 死循环的形成

**B不死 → 神明不死 → 幻兽不死**

B的幻想是有“根”的——根就是B自己。只要B活着，所有被他幻想出来的存在就**不会真正消亡**。

- 杀死的幻兽会重新凝聚
- 封印的幻兽会慢慢挣脱
- 遗忘的幻兽会在被想起时复活

**幻兽不死 → 世界被威胁 → B必须沉睡**

如果B醒来，所有幻兽会同时具现，世界会毁灭。

如果B死去，所有幻兽会瞬间消散——但B不会死。

**所以B只能沉睡。**

这是一个死循环。

### 2.3 沉睡的状态

B的沉睡不是普通的睡眠。他的意识分为三层：

| 层级 | 状态 | 表现 |
|------|------|------|
| **表层** | 浅眠 | 会做梦，梦话是“B的精神残留”，影响幻梦界的波动 |
| **中层** | 深眠 | 无梦，意识几乎静止，幻梦界稳定 |
| **深层** | 无意识 | 只有心跳和呼吸，B的“自我”几乎消失，外世界开始崩塌 |

**B目前的状态**：中层偏浅。因为“醒祸事件”后，B的自我封印让他的沉睡加深了，但最近百年，他的梦话越来越多——他在梦见“A”。

### 2.4 永眠层——B沉睡的地方

**位置**：衡都地下3000米

**结构**：
```
地面：衡都·镇梦司总部
    ↓
地下500米：第一封印层（认知滤网）
    ↓
地下1000米：第二封印层（精神屏障）
    ↓
地下1500米：第三封印层（幻梦界隔离）
    ↓
地下2000米：第四封印层（时间缓滞——1:100）
    ↓
地下2500米：守护者居所（3-5人轮值）
    ↓
地下3000米：永眠层·B的沉睡之地
    ↓
地下4000米：B的精神残留扩散区（不可进入）
```

**B的肉身**：
- 悬浮在直径10米的球形空间中
- 身体被“秩序之锚”的碎片包裹
- 面容平静，像在做梦
- 偶尔微笑、皱眉、流泪

**B的梦话**（被守护者记录，代代相传）：

# 第二卷：异能体系——X级与概念

## 一、异能的真相

### 1.1 异能的本质

异能的本质是**陨石碎片中的幻元粒子与人类基因的结合**。但幻元粒子不只是能量——它是“幻想”的残留。

陨石不是普通的石头。它是B的幻想家异能“投射”到现实的产物。所以陨石碎片中残留着“幻想”的种子。

这就是为什么：
- 异能者的能力千奇百怪（不仅是元素控制，还有“预知”“因果操控”等概念级能力）
- 某些异能者能觉醒“概念级”异能（X级）

### 1.2 异能的“等级”真相

**官方说法**：异能有F到SSS的等级划分。

**真相**：异能的“等级”只是**检测机构对异能者当前表现的评价**，不是异能的本质。异能的本质是**概念深度**。

**检测方法**：用陨石碎片制作的“灵根检测仪”，通过共振频率判断异能的“概念深度”。

**为什么有等级？**
- 因为大部分人觉醒的异能只是“元素”或“躯体”层面的——这些是“浅层概念”
- 少数人觉醒的异能触及“规则”或“概念”——这些是“深层概念”
- 极少数人觉醒的异能触及“存在”本身——这些是“X级”

# 第三卷：幻梦界——认知的世界

## 一、幻梦界的本质

### 1.1 幻梦界是什么

幻梦界是**B的潜意识空间**，也是一个**认知构成的世界**。

它的存在方式类似“第四面墙”（HDM-010）——它不是物理空间，而是**认知空间**。

**核心法则**：
- 幻梦界中的一切，都是“认知”的产物
- 认知越深，存在越真
- 认知越广，存在越强
- 无人认知的存在，会“沉睡”在幻梦界深处

### 1.2 幻梦界与现实层的关系

幻梦界与现实层**重叠但不重合**。

```
现实层（人类、凶兽、植物）
    ↕ 认知滤网（B建立的边界）
幻梦界（幻兽、神明、诡异）
```

**认知滤网**是B用“秩序之锚”建立的分界线。它的作用是：
- 阻止幻梦界的生物随意进入现实层
- 阻止现实层的生物随意感知幻梦界

但当B的精神波动变大时，认知滤网会**松动**。

### HDM-200：「终焉之龙」

**收容等级：** 🔴🔴🔴 A级·世界级威胁
**认知锚点：** Lv.4（共识）
**威胁指标：** ∞（无法量化）

**外观描述：**
终焉之龙是B幻想中“世界终结者”的具象化。它的躯体**无法被完整观测**——仅仅一个爪子就有一座山那么大，仅仅一片鳞片就覆盖了整个天空。它沉睡在幻梦界的最深处，躯体缠绕着整个幻梦界。

如果它醒来，它的躯体从幻梦界“挤”出来的过程，就会摧毁现实层。

**异常特性：**

- **躯体的压迫**：终焉之龙不需要“攻击”。它仅仅是**存在**，就会对世界产生压力。它沉睡时，压力最小；它翻身时，压力增大（表现为全球地震、海啸、火山喷发）；它醒来时，世界会因它的躯体而“破碎”。

- **鳞片的坠落**：终焉之龙的鳞片偶尔会从幻梦界“脱落”，坠落到现实层。一片鳞片直径约100公里，落地时会形成一座“龙鳞山”。鳞片会持续释放B的精神残留，导致周围区域出现认知污染。

- **龙息的低语**：终焉之龙的呼吸会产生“龙息”——不是火焰，而是“概念”。龙息会“改写”它经过的地方的规则。被龙息覆盖的区域，物理法则会变得混乱——重力时有时无，时间倒流，空间扭曲。

**幻想原型：**
B对“末日”的恐惧，混合了北欧神话的“耶梦加得”和东方神话的“应龙”。

**收容方式：**
- **无法收容**。终焉之龙是幻梦界的“骨架”之一，封印它等于封印幻梦界本身。
- 目前的“收容”方式是**不让它醒来**——通过维持B的沉睡，让终焉之龙也保持沉睡。
- 守护者的职责之一：监听终焉之龙的“心跳”，如果心跳加速，说明它要醒了，需要立即加深B的沉睡。

**历史记录：**
- 新历742年“醒祸事件”中，终焉之龙的部分躯体挤出了幻梦界——仅仅是一个爪子，就压垮了衡都的东墙。
- 那次之后，B的自我封印加深，终焉之龙再也没有“动”过。
