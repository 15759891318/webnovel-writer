# 蓝星人族联邦·十九城镇设定

> 档案编撰：联邦城建总署
> 密级：公开
> 最后更新：新历1042年

---

城镇相较于八大城邦规模较小，人口在5000至50000之间，各自承担特殊职能，分布于城邦势力辐射范围内或偏远地区。城镇虽小，却往往掌握着独特的资源、技术或地理优势。

---

## 第一城镇·雾隐镇（Wùyǐn Zhèn）

**格言：** "迷雾之中，唯有清醒者能找到路。"

| 项目 | 详情 |
|------|------|
| 地理位置 | 衡都西北方300公里，终年被浓雾笼罩的盆地之中 |
| 人口 | 约28,000 |
| 隶属城邦 | 衡都 |
| 城镇特色 | 镇梦司外围观测站所在地，幻梦界生物出没频繁的前线城镇 |

**主要势力：** 镇梦司·外围观测第三分站，负责监测该区域幻梦界生物活动。驻扎有一支30人的精神系异能者小队。

**特色产业：** 出产"雾露精华"——一种在浓雾中自然凝结的液体，具有短暂增强精神力的效果，是精神系异能者的重要辅助药剂。

**隐秘：** 浓雾并非自然现象，而是HDM-001「织雾者」早期活动的残留效应。镇梦司将此地选为观测站正是为了研究这种残留。

## 第二城镇·铁脊镇（Tiějǐ Zhèn）

**格言：** "钢铁不朽，人心亦然。"

| 项目 | 详情 |
|------|------|
| 地理位置 | 铸魂城东部，一条巨型凶兽脊椎骨化石带上 |
| 人口 | 约35,000 |
| 隶属城邦 | 铸魂城 |
| 城镇特色 | 联邦最大的凶兽骨骼加工基地，异能武器原料主要产地 |

**主要势力：** 锻兵师工会·铁脊分会，专门将凶兽骨骼加工为武器和防具原料。与铸魂城的火种商会有密切贸易往来。

**特色产业：** 凶兽骨粉提炼、骨制武器胚体锻造。这里生产的"兽骨钢"是异能武器最优质的基底材料之一。

**隐秘：** 化石带中最深处的巨骨属于一头远古凶兽王，至今仍在缓慢释放幻元粒子。铁脊镇的居民觉醒率高达99%，远超联邦平均水平。

**主要势力：** 潮汐壁·第七观测哨，沧澜城深渊研究所在此设有分支实验室，研究浅海区域的异变海洋生物。

**特色产业：** 特殊海产养殖——饲养经过温和异变的海洋生物，产出富含幻元粒子的食材，在八大城邦中属于奢侈品。

**隐秘：** 岩柱群水下部分刻满了不明来源的符文，与HDM-002「饕餮遗胎」腹甲上的铭文高度相似。沧澜城深渊研究所怀疑这是B的另一处幻想遗迹。

## 第四城镇·枯木镇（Kūmù Zhèn）

**格言：** "枯木逢春，亦是轮回。"

| 项目 | 详情 |
|------|------|
| 地理位置 | 茗城西南方，一片由枯死巨木形成的"死亡森林"边缘 |
| 人口 | 约18,000 |
| 隶属城邦 | 茗城 |
| 城镇特色 | 药材采集前线、异变植物研究基地 |

**主要势力：** 共生祭司团·枯木分坛，负责监控死亡森林的边界变化。百草堂在此设有最大的野外采药营。

**特色产业：** 枯死巨木的木材蕴含大量浓缩幻元粒子，是制作高级符箓和法阵媒介的顶级材料。同时在森林边缘可采集到数十种稀有异变药草。

**隐秘：** "死亡森林"并非真的死亡——那些枯木仍在地下通过根系网络交换信息。茗城的大祭司认为，这片森林是在"沉睡"，等待某种信号苏醒。信号可能与B的封印有关。

## 第五城镇·碎镜镇（Suìjìng Zhèn）

**格言：** "碎裂之物，映出更多真相。"

| 项目 | 详情 |
|------|------|
| 地理位置 | 镜湖城南部，围绕一片碎裂的巨型水晶矿脉建造 |
| 人口 | 约31,000 |
| 隶属城邦 | 镜湖城 |
| 城镇特色 | 幻元水晶开采与加工中心，联邦最重要的能源供给点之一 |

**主要势力：** 学者议会·矿业监管委员会直接管辖。认知研究院在此设有"水晶共鸣实验室"，研究幻元水晶与幻梦界的关联。

**特色产业：** 幻元水晶开采——这种水晶是异能修炼的核心辅助资源，可加速幻元粒子在体内的精炼。联邦80%的幻元水晶产自此地。

**隐秘：** 矿脉最深处有一块巨型水晶核心，内部封存着一个完整的"微型幻梦界"——一小片B幻想的世界碎片。认知研究院的最高机密项目就是尝试进入这个微型世界。

## 第六城镇·风铃镇（Fēnglíng Zhèn）

**格言：** "风声即是消息，铃声即是警报。"

| 项目 | 详情 |
|------|------|
| 地理位置 | 风蚀城的游牧路线上，一处罕见的永久绿洲 |
| 人口 | 约12,000（常驻）+ 流动人口约20,000 |
| 隶属城邦 | 风蚀城 |
| 城镇特色 | 风蚀城最大的固定贸易站、沙漠游牧民的补给中心 |

**主要势力：** 风语者·绿洲守护队，负责维护绿洲安全并管理贸易秩序。风语者联盟在此中转情报。

**特色产业：** 沙漠特产贸易集散地——包括沙漠凶兽材料、耐旱异变植物、以及风蚀城独有的"风纹石"（一种可储存风系异能的天然矿石）。

**隐秘：** 绿洲之所以能在沙漠中永久存在，是因为地下深处有一具沉睡的凶兽王级水系异变体。它的"呼吸"维持着地下水源。一旦它苏醒，绿洲将在数小时内消失。

## 第七城镇·烽火镇（Fēnghuǒ Zhèn）

**格言：** "烽火不灭，人类不退。"

| 项目 | 详情 |
|------|------|
| 地理位置 | 焚寂城前沿，蓝星最东端的永恒裂隙边缘 |
| 人口 | 约15,000（全员为战斗人员或后勤） |
| 隶属城邦 | 焚寂城 |
| 城镇特色 | 联邦最前线的军事要塞城镇，人类领土的最东端极点 |

**主要势力：** 炽灭军团·第一前哨营，焚寂城最精锐的部队之一常年驻守于此。灼魂教会在此设有"浴火殿"，为战士进行战前祝福仪式。

**特色产业：** 无民用产业。全镇经济依赖联邦军事拨款和焚寂城支援。唯一的"产出"是从前线猎杀的凶兽获取的材料。

**隐秘：** "永恒裂隙"实际上是幻梦界与现实交界最薄弱的区域之一。焚寂城的永恒炽照之火的一部分能量被引导至此，形成了一道勉强维持的"火墙"。焚寂城灯主知道——一旦炽照之火熄灭，这道火墙会在一瞬间崩塌。

| 项目 | 详情 |
|------|------|

| 隶属城邦 | 霜棺城 |
| 城镇特色 | 霜棺城亡者议会的"采掘场"，提取巨兽残余生命能量 |

**主要势力：** 亡者议会·深层采掘队，以及镇梦司·尸解部的一个秘密研究站。

**特色产业：** 从巨兽尸骸中提取的"沉眠精华"是霜棺城永恒流派修炼的核心资源。同时，尸骸的骨髓腔中偶尔会结晶出极珍贵的"生死石"。

**隐秘：** 这具巨兽并未真正死亡——它的心脏还在以约3年一次的频率跳动（与霜棺城设定一致）。沉眠镇的真正作用不是采掘，而是监控。一旦心跳频率加快，将立即向亡者议会发出警报。

## 第九城镇·渡口镇（Dùkǒu Zhèn）

| 项目 | 详情 |
|------|------|
| 地理位置 | 衡都与沧澜城之间，建于一条巨型异变河流的渡口 |
| 人口 | 约42,000 |
| 隶属城邦 | 衡都（名义上），实际为衡都与沧澜城共管 |
| 城镇特色 | 联邦最大的内陆水运枢纽，八大城邦间的核心物流节点 |

**主要势力：** 联邦运输署·渡口管理局，以及各大城邦的贸易代表处。由于地理位置特殊，这里也是各势力情报交换的灰色地带。

**特色产业：** 水运贸易、内河造船业。渡口镇建造的"破浪舟"经过特殊处理，可抵抗河流中异变水生生物的攻击。

**隐秘：** 河流本身是有意识的——它是B早期幻想的产物之一，拥有模糊的自我意识，能根据"心情"改变水流方向和速度。渡口镇的老船工们代代相传一套"读水术"，实际上是在与河流的意识进行原始沟通。

**特色产业：** 霜鸦繁育与训练、飞禽类凶兽侦察。鸦巢镇的"鸦语者"是一种独特的精神系异能分支，可与鸟类进行有限的意识沟通。

**隐秘：** 霜鸦群落中有一只特殊的白色个体，它已活了超过300年。这只白鸦从不服从任何人的命令，但偶尔会主动叼来某些物品——事后总被证明对某次危机至关重要。镇上的老人们私下称它为"先知鸦"。

## 第十六城镇·集市镇（Jíshì Zhèn）

**格言：** "万物有价，诚信无价。"

| 项目 | 详情 |
|------|------|
| 地理位置 | 蓝星中南部，八大城邦地理中心点附近 |
| 人口 | 约48,000（联邦最大城镇） |
| 隶属城邦 | 无隶属（联邦直辖，八大城邦共管） |
| 城镇特色 | 联邦最大的自由贸易区，"蓝星商会联盟"总部所在地 |

**主要势力：** 蓝星商会联盟，由八大城邦各自派出商业代表组成。这里是联邦唯一一个八大城邦势力完全平等的地方。

**特色产业：** 全品类贸易——从日常用品到异能武器，从凶兽材料到幻元水晶，只要不违反联邦法律，一切皆可交易。每季度举办"万物大集"，吸引全蓝星的商人。

**隐秘：** 商会联盟的地下金库中保存着一件B的遗物——一本空白笔记本，每隔不定期会自动浮现新的文字。目前已知的文字都是B沉睡中的梦话碎片。各城邦为争夺这本笔记本的解读权暗中博弈了数百年。

## 第十七城镇·望乡镇（Wàngxiāng Zhèn）

**格言：** "回不去的故乡，忘不掉的根。"

| 项目 | 详情 |
|------|------|
| 地理位置 | 蓝星西北荒原边缘，一座孤立的山丘上 |
| 人口 | 约7,000 |
| 隶属城邦 | 风蚀城（名义上），实际高度自治 |
| 城镇特色 | 流浪者和难民的聚居地，联邦最"边缘"的城镇 |

**主要势力：** 无正式势力。由一位自称"镇长"的退役SS级异能者自发管理。这里收容了从凶兽袭击中幸存的村落难民、被城邦驱逐的异能者、以及各种不见容于主流社会的人。

**特色产业：** 废品回收与再加工。望乡镇的居民将荒野中收集的凶兽残骸和废弃物资改造成实用工具，自给自足。

**隐秘：** "镇长"——真名不详，外号"老望"——实际上是镇梦司的前任副司长。他在一次任务中目睹了第四面墙（HDM-010），之后主动申请记忆封印并"退役"。他选择在此守望，是因为这个山丘上偶尔能看到不属于蓝星的星空——那是外世界的天空渗透进来的影像。

## 第十八城镇·药谷镇（Yàogǔ Zhèn）

**格言：** "百草皆药，万病可医。"

| 项目 | 详情 |
|------|------|
| 地理位置 | 茗城东部，一条湿润的峡谷之中 |
| 人口 | 约19,000 |
| 隶属城邦 | 茗城 |
| 城镇特色 | 联邦最大的药剂生产基地，百草堂总部所在地 |

**主要势力：** 百草堂总部，以及联邦医疗署·药谷分局。全蓝星80%的异能者用药和医疗用品产自此地。

**特色产业：** 异变药草种植、药剂研发与量产。药谷镇最著名的产品包括"醒神丸"（恢复精神力）、"固核液"（辅助凝核境突破）和"净化散"（清除精神污染）。

**隐秘：** 百草堂的最高机密药剂"归梦汤"可以让服用者暂时进入幻梦界的边缘层。这本是镇梦司委托开发的侦察工具，但百草堂的首席药剂师发现了一个副作用——偶尔会在幻梦界边缘看到一个安静坐着的年轻人的身影，疑似是沉睡中的B。

## 第十九城镇·界碑镇（Jièbēi Zhèn）

**格言：** "这里是人类的边界，也是人类的起点。"

| 项目 | 详情 |
|------|------|
| 地理位置 | 蓝星南端，人类已知领土的最南极点 |
| 人口 | 约5,000（联邦最小城镇） |
| 隶属城邦 | 无隶属（联邦军方直辖） |
| 城镇特色 | 联邦最南端的军事前哨与探索基地 |

**主要势力：** 联邦军方·南疆探索军团，常年向南方未知区域派出侦察队。镇梦司在此设有一个超小型的"异象感知站"。

**特色产业：** 无民用产业。完全依赖军事补给维持运转。

**隐秘：** 界碑镇最南端矗立着一块高10米的黑色方碑——没有人知道它是谁建造的，碑面上只刻着一句话："不要再往南走了。"联邦军方数次派出SS级异能者组成的精锐小队向南探索，只有一支小队回来过。回来的三人全部精神崩溃，只反复说同一句话："南边……南边没有尽头……那里是梦开始的地方……"

镇梦司怀疑，蓝星的最南端就是B幻想的"世界的边缘"——再往南，就是幻梦界本身。
