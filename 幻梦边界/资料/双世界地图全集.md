# 第一卷：外世界地图——未毁灭前的蓝星

## 一、外世界的本质

### 1.1 外世界是什么

外世界是B用“幻想家”异能创造的**平行世界**。它的设定是：**陨石从未降临，世界正常发展**。

- **时间锚点**：B在幻想时，将时间“固定”在陨石降临前的最后一天
- **空间锚点**：外世界的蓝星与里世界的蓝星在“地理上”一致，但面积、生态、文明完全不同
- **认知锚点**：外世界的存在依赖于B的“世界之种”（七彩水晶），水晶能量耗尽，外世界就会崩塌

### 1.2 外世界的居民

外世界的所有人都是B幻想的产物——但他们不知道。他们有完整的记忆、人格、情感。

- **总人口**：约78亿（陨石降临前的世界人口）
- **文明水平**：21世纪初的科技水平（互联网、航空、核能）
- **特殊之处**：没有异能、没有凶兽、没有幻兽

### 1.3 外世界的“BUG”

外世界不是完美的。因为B的精神状态不稳定，外世界存在“BUG”：

| BUG类型 | 表现 | 频率 |
|---------|------|------|
| **NPC化** | 路人重复同一动作、同一句话 | 罕见（A穿越后变频繁） |
| **物理异常** | 重力短暂失效、时间流速不一致 | 极罕见 |
| **记忆模糊** | 居民的某些记忆变得不清晰 | 罕见 |
| **建筑老化** | 无人居住的建筑快速腐朽 | 缓慢但持续 |
| **边界模糊** | 世界边缘出现“虚空” | 仅A见过 |

# 第二卷：里世界地图——陨石降临后的蓝星

## 一、里世界的本质

### 1.1 里世界是什么

里世界是B的**真实世界**——陨石降临后的蓝星。

- **面积**：陨石降临后，蓝星面积扩张了**10倍以上**（约5.1亿平方公里 → 约51亿平方公里）
- **人类活动区域**：约500万平方公里（不到总面积的**百万分之一**）
- **未知区域**：超过99.99%的区域未被探索

### 1.2 扩张的原因

蓝星为什么变大了？

| 原因 | 解释 |
|------|------|
| **幻元粒子渗透** | 陨石碎片释放的幻元粒子渗入地壳，使大陆板块“膨胀” |
| **幻梦界重叠** | 幻梦界与现实层重叠的部分“固化”为新的土地 |
| **B的幻想** | B在沉睡中幻想的“新大陆”会逐渐具现 |
| **时间扭曲** | 部分区域的时间流速不同，导致“生长”速度不同 |

### 1.3 人类生存的现状

人类生活在**不到百万分之一**的土地上。

- **八大城邦总面积**：约300万平方公里
- **十九镇总面积**：约50万平方公里
- **村落总面积**：约150万平方公里
- **总计**：约500万平方公里

**对比**：
- 里世界总面积：约51亿平方公里
- 人类活动区域占比：**0.098%**

其余99.9%的土地是：
- 凶兽领地（约60%）
- 变异植物覆盖区（约20%）
- 幻梦界影响区（约10%）
- 未知区域（约10%）

### 4.2 最神秘的五个未知区域

#### 未知区域一：扶桑主干区

- **位置**：南部丛林以南500公里
- **特征**：世界树·扶桑的主干所在，高度无法测量（据说穿过云层）
- **推测**：扶桑的树冠层可能有一个独立的生态系统
- **风险**：藤蔓行者集群、植物意识体、飞行凶兽
- **探索记录**：无。所有靠近的探索队都“消失”了

#### 未知区域二：地心入口

- **位置**：西南山脉最深处
- **特征**：一个直径约100公里的垂直洞穴，深不见底
- **推测**：通往蓝星地心，可能有地心文明或祖级凶兽
- **风险**：重力异常、岩浆生物、地鸣者母体
- **探索记录**：铸魂城曾派遣3支探索队，最深到达地下50公里，之后失联

#### 未知区域三：虚空鲸通道

- **位置**：东部外海深处，无固定坐标
- **特征**：虚空鲸靠近蓝星时留下的“通道”，空间扭曲
- **推测**：通道可能通往“虚空”——蓝星所在的宇宙空间
- **风险**：空间裂缝、时间异常、虚空生物
- **探索记录**：无。所有靠近的船只都“消失”了

#### 未知区域四：世界蛇尾部

- **位置**：南极冰架深处
- **特征**：世界蛇的尾巴，据说埋在冰层下
- **推测**：如果找到尾巴，就能知道世界蛇何时“首尾相接”
- **风险**：极寒、冰封生物、世界蛇的精神污染
- **探索记录**：霜棺城曾派遣1支探索队，全部冻死，死前发出“看到了尾巴”的信号

#### 未知区域五：幻梦界核心

- **位置**：不存在于现实层，存在于幻梦界最深处
- **特征**：B的潜意识核心，所有幻兽的源头
- **推测**：B的“自我”可能在这里
- **风险**：认知污染、概念抹除、存在消失
- **探索记录**：只有精神系异能者能“进入”，但从未有人回来
