# 幻梦界生物/异常收容档案 —— 完整版

**档案总数**：409份（HDM-001至HDM-010见基础档案，本卷收录HDM-011至HDM-409共399份）

**收容等级说明**：
- 🟢 **潜梦级（Slumber）**：低威胁，常规收容即可
- 🟡 **清醒级（Waking Dream）**：中等威胁，需专业人员处理
- 🔴 **噩梦级（Nightmare）**：高威胁，需S级以上资源
- ⚫ **清明级（Lucid）**：不可收容/不可理解

**认知锚点等级**：Lv.1（传闻）→ Lv.5（群体共识）
