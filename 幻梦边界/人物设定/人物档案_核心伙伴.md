## 凌霜——镇梦司追捕者 / 霜刃

### 基本信息
- **性别**：女
- **年龄**：22岁
- **外貌**：身材修长，黑色短发，眼神锐利如刀锋。左手腕有一道旧伤疤——不是战伤。面部表情极少变化，被同事叫"人形武器"。穿镇梦司制式战斗服，但领口总是拉到最高，遮住脖子上一个小小的纹身——凌月的名字。

### 异能等级与能力
- **天赋异能**：冰系·A级→S级（成长型）
- **核心能力**：
  - **霜刃术**：将任何接触的物体冻结，冰从接触点扩散。可以冻结空气形成冰墙、冰矛。
  - **霜域·绝对零度**（后期觉醒）：展开领域，领域内温度骤降至绝对零度。概念层面——冻结的不是温度，是"运动"。
- **梦裂觉醒**（第5卷）：在苏木牺牲后极度悲痛中觉醒梦裂，进入浅裂。

### 性格核心
**三个关键词**：创伤后的控制欲 / 冷酷下的自我惩罚 / 被廉价食物治愈的人

**具体怪癖/习惯**：
1. 任务结束后，会找到当地最便宜的食物，一个人吃完。不是节俭，是只有在吃廉价食物的时候，她才觉得自己是个普通人。
2. 手腕上的旧伤是她自己留的——某次执行"收容任务"之后。她说是意外。没有人问第二遍。
3. 在写报告时字迹极其工整，每一行都用尺子比过——这是她控制欲的外化。如果一行字歪了，她会撕掉整页重写。
4. 她有严重的失眠，但从不告诉任何人。她会在深夜坐在窗台上，把凌月给她的那条发光手链握在手心里。
5. 笑——她几乎不笑。唯一一次在余耀面前笑，是余耀在被追杀时说"你的追捕效率可以写进教科书，但你的追捕路线选择需要优化"。她笑了一声，然后马上恢复冷脸。

### 思维底色
**创伤后的控制欲**——凌霜的冷酷不是天生的，是"制造"出来的。在执行那次十二岁孩子的收容任务后（孩子死了），她开始系统性地关闭自己的情感通道。她不是感受不到，是不允许自己感受。因为一旦开始感受，她就必须面对"那个孩子死的时候自己在做什么"这个问题。

### 背景履历
- 出身普通，父母早逝，独自抚养妹妹凌月
- 16岁加入镇梦司，成为最年轻的追捕者
- 17岁执行"收容任务"：目标是一个12岁的孩子，无意中觉醒梦裂，被镇梦司认定为威胁。她执行了命令。孩子死了。
- 18岁：凌月觉醒梦裂，被收容转移途中"失踪"
- 18-22岁：为了找到凌月，在镇梦司内部攀升，获取更高权限
- 接到追捕余耀的任务时，她视余耀为"任务目标"——直到她发现余耀在给一只回声鸟唱歌

### 核心矛盾与隐藏恐惧
- **核心矛盾**：她在镇梦司的体制内寻找凌月，但镇梦司可能就是让凌月消失的元凶。
- **隐藏恐惧**：她怕自己变成"那种人"——下令杀死十二岁孩子的人。但她已经是了。这个认知是她所有痛苦的根源。

### 弧光轨迹
**起点**：冷酷高效的追捕者，相信"执行命令就是正义"。
**转折①**（第30章）：在监视余耀时发现他在给回声鸟唱歌。她在报告里写"目标无威胁行为，继续观察"，把那一页折起来压在抽屉里。
**转折②**（第200章）：发现凌月失踪的真相与镇梦司有关，信仰崩塌。
**转折③**（第400章）：苏木牺牲，她在暴怒中觉醒梦裂——她变成了她追捕的那种人。
**转折④**（第700章）：找到凌月，在凌月面前第一次哭。
**终点**：脱离镇梦司，成为认知黎明的核心成员。最终与余耀的关系从"追捕者与猎物"变为"两个被破碎世界选中的人"。

### 关键章节标注
| 章节 | 事件 |
|------|------|
| 第15章 | 第一次追捕余耀 |
| 第30章 | 发现余耀给回声鸟唱歌 |
| 第100章 | 随余耀进入永眠层入口 |
| 第200章 | 凌月真相浮出水面 |
| 第400章 | 苏木牺牲，觉醒梦裂 |
| 第500章 | 叛逃镇梦司 |
| 第700章 | 找到凌月 |

### 与其他角色的独立关系网
- **与苏木**：微妙的张力——苏木对她有好感，她知道但假装不知道。苏木死后，她在他的遗物里发现一本笔记，里面有一页画了她的侧脸素描。她把那一页撕下来，夹在凌月的手链旁边。
- **与廖原**：凌霜曾给廖原写信询问凌月的线索。廖原沉默了很久，说"我知道一个人，可以查到这件事"。这是廖原第一次为她冒险。
- **与司长**：她恨司长，但也隐约感知到司长在某些事上故意"放水"——某些该杀死余耀的机会，司长"恰好"错过了。

### 标志性台词
1. "我执行命令。我不问为什么。"（早期）
2. "如果我问了为什么……那个孩子是不是就不会死？"（转变期）
3. "你在给鸟唱歌。你知道那只鸟听不到吗？……你知道。你还是唱了。"（对余耀说）

### 存在质感细节
1. 她的冰系异能有一个只有她知道的"bug"：当她情绪波动剧烈时，她周围的温度会无意识下降。第一次和余耀吵架时，整个房间结了一层薄霜。她假装什么都没发生，走了。余耀看着满地的霜，在笔记本上写："凌霜·情绪外泄现象·待归档。"
2. 她有一双多余的手套，是凌月的尺寸。她随身带着，从不解释。

## 尼亚拉（HDM-008）——街巷猫王 / 自由的概念体

### 基本信息
- **性别**：无固定性别（默认以雌性猫形态出现）
- **年龄**：与B的幻想同龄（约千年）
- **外貌**：常态为一只紫灰色猫，体型比普通猫略大，瞳孔是竖瞳但颜色不断变换（紫→金→银）。尾巴尖端有一撮七彩毛发（与七彩水晶同源）。人形态：紫灰色短发少女，穿着斗篷，赤脚，脚踝有铃铛纹路。表情永远是半笑不笑的傲慢。

### 异能等级与能力
- **收容等级**：清醒级（五阶）·概念型
- **概念本质**："自由"的化身——任何束缚、封印、规则对她无效
- **核心能力**：
  - **领域·无主之城**：展开范围内，一切"所有权"消失——锁打不上、墙拦不住、合同失效
  - **路径感知**：能感知任何空间中所有"通道"——包括幻梦界与现实层的裂缝
  - **认知免疫**：无法被任何认知系异能影响——因为"自由"的概念无法被"控制"
- **核心限制**：她的核心（七彩水晶）嵌在余耀体内。取回核心→余耀消散。不取回→她永远不完整。

### 性格核心
**三个关键词**：傲慢 / 不承认的温柔 / 被束缚的自由

**具体怪癖/习惯**：
1. 说话时总是斜着眼看人，像在打量"你值不值得我搭理"。
2. 喜欢在最不合适的时候出现和消失——余耀在严肃讨论时她会突然跳上桌子舔爪子。
3. 讨厌被触碰，但会主动蹭余耀的脚踝——然后假装是不小心碰到的。
4. 她对"美食"有异常的执念——作为概念体她不需要吃东西，但她喜欢闻食物的味道。尤其是鱼。

### 思维底色
**作为"自由"概念体的悖论**——她是所有存在中最自由的，但因为核心在余耀体内，她是最不自由的。她选择保护余耀，不是因为任务，是因为如果余耀死了，她的核心也没了。但随着故事推进，她发现自己保护余耀的理由已经不只是"核心"——她第一次想要保护某个人，只是因为想。这让她感到恐惧，因为"想要保护某个人"是一种束缚，而她是"自由"。

### 背景履历
- B在觉醒幻想家能力时，基于对"自由"的渴望创造了尼亚拉
- B将自己的幻想核心（七彩水晶）的一部分交给尼亚拉，作为"给余耀的保险机制"——当余耀触碰水晶穿越时，水晶嵌入余耀体内，尼亚拉成为余耀的守护者
- 千年来在里世界的城市巷弄中游荡，被称为"街巷猫王"
- 是所有幻兽中唯一"选择不攻击人类"的清醒级存在
- 里世界的猫都听她的。所有猫。

### 核心矛盾与隐藏恐惧
- **核心矛盾**：取回核心就是杀死余耀；不取回就永远不完整。
- **隐藏恐惧**：她最怕的是"被需要"——因为被需要意味着不自由。但她已经被余耀需要了，而且她发现自己也需要余耀。

### 弧光轨迹
**起点**：傲慢的自由概念体，保护余耀只是"保护自己的核心"。
**转折**（某个宁静章节）：余耀问她"如果你不用守着我，你会去哪里？"她沉默很久，说了一个具体的地方。
**高潮**（第965章前后）：选择把水晶永久留给余耀，让自己从"清醒级幻兽"退化为"普通猫"——不是牺牲，是自由。她第一次真正自由了。
**终点**：一只紫灰色小猫，蜷在余耀家的窗台上，尾巴尖端有一点紫色。它不记得自己曾经是谁，但它选择留在这里。

### 标志性台词
1. "我不是在保护你。我只是不想让我的核心到处乱跑。"
2. "自由？……自由是最重的锁链。因为你选择了自由，就不能选择留下。"
3. "那个地方……有风。只是有风。我路过的时候停了一下。然后我走了。因为我没有时间停下来。"

### 存在质感细节
1. 当她以猫形态蜷在余耀身边时，她的呼噜声有一个特点——频率与B的心跳完全同步。苏木发现了这一点，但没有告诉余耀。
2. 她有一个秘密行为：在每个她到过的城市，她会找到一个最高的地方，坐在那里看日落。不是因为美，是因为日落是一天中唯一"什么都不发生"的时刻，而那是她最接近真正自由的时候。

## 苏木——镇梦司分析官 / "理解派"学者

### 基本信息
- **性别**：男
- **年龄**：34岁
- **外貌**：戴圆框眼镜，头发总是乱的（不是故意的，是真的忘了梳），衬衫扣子经常扣错一格。手指上有长年握笔留下的茧。左手无名指有一道细小的伤疤——他弟弟曾经抓伤他的。

### 异能等级与能力
- **天赋异能**：精神系·A级——"认知解析"
- **核心能力**：能将幻兽的认知锚点"拆解"成可视化的数据图谱，是目前唯一能将幻兽信息"量化"的人。
- **局限**：纯分析型，几乎没有战斗能力。被同事叫"纸上谈兵苏分析"。

### 性格核心
**三个关键词**：用学术掩盖内疚 / 苦涩的幽默 / 不自觉地画图

**具体怪癖/习惯**：
1. 做研究时会走神，突然开始画示意图，画满一整个本子的奇怪图表。最后那些图表都是有用的。他说："不是有意为之，是思维路径在纸上走了一遍。"
2. 在极端情况下说最轻描淡写的话——余耀快被干死时，苏木的紧急通讯只说了一句："我现在不在镜湖城，大概15分钟到，你先别死。"
3. 泡茶有强迫症——水温必须83度，不是85，不是80，是83。他说这是"唯一一件他能精确控制的事"。
4. 衬衫口袋里总是放着一支多出来的笔——那支笔是他弟弟的。

### 思维底色
**用学术掩盖内疚**——苏木的"理解派"立场不完全来自学术判断。他的弟弟是梦裂修炼者，被镇梦司认定为威胁。苏木在处置档案上签了字。弟弟死了。从那天起，他的"理解派"立场不是因为他认为梦裂修炼者是好人，是因为他需要相信"那不是唯一的选择"。他的一切学术研究，本质上都是在证明"存在不消灭梦裂修炼者的方法"——这样他就可以相信，当年的他如果再坚持一下，弟弟就不用死。

### 背景履历
- 学者世家出身，父母均为镜湖城研究员
- 弟弟苏桐，比他小8岁，15岁时觉醒梦裂
- 苏木在弟弟的处置档案上签了字（作为家属，有知情权和"异议权"，但他没有提出异议）
- 弟弟被"消除"后，苏木从"中立派"转向"理解派"，开始系统性研究梦裂修炼者的可控性
- 28岁提出"A是世界免疫系统"理论，引起镇梦司高层注意
- 成为镇梦司分析部核心成员，暗中推动对余耀的"研究"而非"消灭"
- 第四卷牺牲——为了保护余耀和凌霜撤退，独自面对渊识的第一波入侵

### 核心矛盾与隐藏恐惧
- **核心矛盾**：他最优秀的学术能力建立在最深的愧疚之上——他研究得越好，就越证明弟弟的死是不必要的。
- **隐藏恐惧**：怕"自己研究了十年的理论是错的"——因为如果理论是错的，那他弟弟的死就是唯一正确的处置方式。那他将无法继续活下去。

### 弧光轨迹
**起点**：用学术理性包裹自己的学者，看似温和理性，实则逃避。
**转折**（牺牲前20章）：有一章完全是苏木视角——他在想弟弟，他在重新审视当年的签字。他在某个安静的时刻意识到：如果当年有人像他现在对待余耀一样对待苏桐，结果会不一样。
**高潮**（第400章）：牺牲。他最后对余耀说的不是豪言壮语，而是："你替我……活到能证明我的理论的那天。数据发你邮箱了，83度的水泡的茶最好喝，别弄错了。"
**终点**：缺席。但他的理论在后续成为余耀找到"第三条路"的关键基础。他的笔记本被凌霜收着。

### 与其他角色的独立关系网
- **与凌霜**：微妙的张力。苏木对凌霜有好感，但他从不表达——因为他觉得自己没有"资格"去喜欢一个人（一个签字杀了弟弟的人不配喜欢人）。凌霜知道他的好感，假装不知道。
- **与维里蒂**：学术对立——维里蒂认为"真相比安全重要"，苏木认为"安全是追求真相的前提"。两人吵过无数次，但互相尊重。

### 标志性台词
1. "我不在镜湖城，大概15分钟到，你先别死。"
2. "你替我活到能证明我的理论的那天。数据发你邮箱了。"
3. "……如果当年我多问了一句'还有没有别的办法'，会不会不一样？大概不会。但我应该问的。"

### 存在质感细节
1. 他的遗物里有一本私人笔记，最后一页画了凌霜的侧脸素描——不是有意为之，是"思维路径在纸上走了一遍"。凌霜发现后撕下那一页，夹在凌月的手链旁边。
2. 苏木死后，余耀再也没有做过"口述记录"的习惯——因为再也没有人能在旁边说"你这个分类方式有问题，我给你画个图"了。
