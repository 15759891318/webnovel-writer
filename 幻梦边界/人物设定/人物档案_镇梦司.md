## 廖原——追捕部基层执法者 / "开门缝的人"

### 基本信息
- **性别**：男
- **年龄**：28岁
- **外貌**：相貌普通到路上擦肩而过记不住。中等身材，总穿着标准制服，领带永远歪的。唯一特点是眼角有一道细小的疤——新人时期的训练事故。

### 异能等级与能力
- **天赋异能**：感知系·B级——"微光感知"（能感知微弱的认知波动，范围50米）
- **战斗力**：中下。在追捕部排名倒数。

### 性格核心
**三个关键词**：平凡中的善良 / 不问为什么就做对的事 / 沉默的勇气

**具体怪癖/习惯**：
1. 每次执行任务回来都会去食堂吃一碗白粥——不加任何东西。他说这是"让自己记住还是普通人"。
2. 写报告时字迹潦草到只有他自己能看懂。上司已经放弃纠正了。
3. 他有一个习惯：遇到需要做选择的时刻，会先想"如果是我被困在那边"。

### 弧光轨迹（全书隐形高光·仅约30章戏份）
| 章节 | 事件 |
|------|------|
| 第7章 | 追捕余耀时，给余耀开了一道门缝，让他逃脱。没有人看到。 |
| 第50章 | 收到凌霜关于凌月的信，沉默很久后说"我知道一个人，可以查到这件事" |
| 第100章 | 不出现，但在衡都内部悄悄为余耀的通行做准备 |
| 第200章 | 因在体制内帮助余耀被发现，降职。但没被清除——因为他"没有直接违命" |
| 第400章 | 苏木牺牲后，提交内部申请——调离追捕部门，加入认知黎明。申请最后一行写了不标准的话 |
| 末卷 | 世界重建后，"初裂援助"部门（帮助刚觉醒梦裂的人）第一任负责人——廖原 |

### 标志性台词
1. （第7章，没有台词。只是开了一道门缝。）
2. "我知道一个人，可以查到这件事。"（对凌霜说）
3. "申请理由：因为有人给我开过门。"（调职申请末尾）

## 沈戒——镇梦司执法部中层 / "斯内普"型补充角色

### 基本信息
- **性别**：男
- **年龄**：45岁
- **外貌**：面容刚毅，下巴线条硬朗。头发花白（提前白发）。穿戴一丝不苟，皮鞋永远锃亮。右手中指有一个银戒指——他妻子的遗物。

### 异能等级与能力
- **天赋异能**：躯体系·A级——"铁壁"（被动强化型，身体防御力极高）
- **战斗风格**：硬抗型。不躲，不闪，用身体接一切攻击然后反击。伤疤满身。

### 性格核心
**三个关键词**：相信自己在做对的事 / 方式是错的 / 不可被说服

**具体怪癖/习惯**：
1. 每天早上起来先擦皮鞋——10分钟，一秒不多一秒不少。他说这是"维持秩序的第一步"。
2. 他对下属极其严厉，但每个受他训练的人都承认"沈戒的方法有用"。
3. 他不喝酒，不抽烟，不任何"放松"——因为他认为"放松是对警惕性的背叛"。

### 思维底色
**相信自己在做对的事，但方式是错的**——沈戒真心相信镇梦司的使命是正确的。他认为"收容"是保护人类的必要手段。他不是冷血，他是真的认为"如果不这样做，会死更多人"。问题是：他的"这样做"包括了杀死无辜的梦裂觉醒者。他不觉得他们无辜——他觉得他们是"尚未爆发的威胁"。

### 背景履历
- 妻子在醒祸事件的余波中被幻兽杀死
- 从那以后加入镇梦司，成为最强硬的执法者之一
- 亲手"处置"过47名梦裂觉醒者，每一个的名字他都记得
- 他把那47个名字刻在银戒指的内侧——不是忏悔，是"提醒自己这件事的重量"

### 核心矛盾与隐藏恐惧
- **核心矛盾**：如果梦裂觉醒者真的可以被"引导"而非"消灭"，那他杀的47个人都是冤枉的。
- **隐藏恐惧**：怕余耀是对的。因为如果余耀是对的，他就是杀人犯。

### 弧光轨迹
**起点**：镇梦司最强硬的执法者，余耀最直接的执行层敌人。
**转折**（第六卷）：看到余耀成功"引导"一个梦裂觉醒者而非消灭，他第一次沉默了很久。
**终点**（第九卷）：在最终战前，他没有加入余耀的阵营，也没有继续执行命令。他独自走进荒野，消失了。后来有人在废墟中发现了他的银戒指——内侧刻着47个名字，最后一个名字是他自己的。

### 标志性台词
1. "我不需要你理解我。我只需要你活到理解我的那天。"
2. "47个。我记得每一个。如果再来一次——我不知道我会不会做不同的选择。但我知道我应该。"

## 蔡明——天平派领袖

### 基本信息
- **性别**：女
- **年龄**：52岁
- **外貌**：慈眉善目的中年妇女，看着像学校的教导主任。总是微笑，但笑意不到眼底。

### 异能等级与能力
- **天赋异能**：精神系·A级——"情绪天平"（能感知并"平衡"一定范围内的情绪波动）

### 性格核心
**三个关键词**：表面中立实则精算 / 政治动物 / 没有底线的温和派

### 思维底色
她是真正的"中间派"——不是因为她没有立场，是因为她的立场就是"让自己活到最后"。她支持哪一方取决于哪一方更可能赢。

### 标志性台词
1. "我只是觉得，大家都有道理。我们不应该太急。"（每次都这么说，每次都在拖延，每次都在等赢家出现。）

## 陆沉——铁幕派领袖

### 基本信息
- **性别**：男
- **年龄**：56岁
- **外貌**：身材魁梧如铁塔，面部棱角分明，像用斧头劈出来的。左耳缺了一角——被凶兽咬掉的。

### 异能等级与能力
- **天赋异能**：躯体系·S级——"铁幕壁垒"（展开不可穿透的力场，范围越大消耗越大）

### 性格核心
**三个关键词**：军人思维 / 非黑即白 / 保护弱者的方式是把他们关在笼子里

### 思维底色
陆沉是真正的"保护者"——他创建铁幕派的初衷是"让平民不受幻兽威胁"。但他的保护方式是"把一切危险隔绝在外"，包括梦裂觉醒者。他不恨他们，他只是认为"有风险的东西就该被隔离"。

### 标志性台词
1. "我不管你有没有恶意。有风险就够了。"

## 江漓——织梦派领袖

### 基本信息
- **性别**：女
- **年龄**：38岁
- **外貌**：长发如瀑，说话轻柔如水。穿着总是飘逸的长裙，像从画里走出来的人。但眼神比任何人都锐利。

### 异能等级与能力
- **天赋异能**：精神系·S级——"织梦术"（能进入他人梦境，在梦中获取信息或植入暗示）

### 性格核心
**三个关键词**：温柔的操控者 / 理想主义者 / 相信"改造"比"消灭"好

### 思维底色
江漓是真正的理想主义者——她相信梦裂修炼者可以被"引导"，幻兽可以被"教化"。她的织梦派方法是"进入目标的梦境，在梦中植入和平的种子"。问题是：这种方法的本质是"精神操控"，即使目的是好的。

### 标志性台词
1. "消灭和改造的区别是什么？区别是改造之后他还活着。这就够了。"

## 钟离——凌霜小队成员（新增）

### 基本信息
- **性别**：男
- **年龄**：24岁
- **外貌**：娃娃脸，看着像高中生。但身上有十几道战斗伤疤。喜欢嚼口香糖。

### 异能等级与能力
- **天赋异能**：感知系·B级——"回声定位"（通过声波感知周围环境，有效范围200米）

### 性格核心
**三个关键词**：话多 / 乐观到令人怀疑 / 团队的润滑剂

### 思维底色
钟离是凌霜小队的"普通人视角"——他不是天才，不是精英，只是一个"考试刚好及格就入了追捕部"的普通执法者。他的存在是为了告诉读者：镇梦司不是只有冷血的工具人和天才，也有嚼着口香糖、在巡逻时偷听八卦的普通人。

### 标志性台词
1. "队长，我觉得你应该——""闭嘴。""好的。但我真的觉得——""闭嘴，钟离。""明白。"
