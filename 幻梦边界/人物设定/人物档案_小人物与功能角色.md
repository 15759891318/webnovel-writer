# 《幻梦边界》人物档案 · 小人物与功能角色

## 老周——雾沼镇面摊老板

### 基本信息
- **性别**：男
- **年龄**：63岁
- **外貌**：微胖，秃顶，围着油腻的围裙。笑起来缺了一颗门牙。

### 异能等级与能力
- **天赋异能**：无（空白者）
- 是雾沼镇为数不多的空白者之一

### 性格核心
**三个关键词**：朴实 / 什么都不在乎只在乎面好不好吃 / 沉默的善良

### 叙事功能
余耀第一次在里世界吃到"热食"就是在老周的面摊。老周没有问他从哪来、为什么满身伤。只是端了一碗面，说"先吃"。这碗面是余耀在里世界第一次感受到"这个世界也有温暖"的时刻。

### 标志性台词
1. "先吃。"
2. "钱？没钱就算了。面放久了也是倒掉。"

## 小七——镜湖城研究院助理

### 基本信息
- **性别**：女
- **年龄**：20岁
- **外貌**：扎马尾，戴巨大的圆框眼镜，总是抱着一摞比她还高的资料。走路经常绊倒。

### 异能等级与能力
- **天赋异能**：精神系·C级——"微量认知感应"（能感知到极微弱的认知波动，但无法解读内容）

### 性格核心
**三个关键词**：毛手毛脚 / 学术狂热 / 维里蒂的迷妹

### 叙事功能
她是维里蒂实验室的日常参照——通过她的视角，读者看到镜湖城的学术日常。她在第一卷会频繁出现在余耀接受研究的场景中，提供轻松的喜剧缓冲。

### 标志性台词
1. "维里蒂老师说——等等这页掉了——维里蒂老师说，你的认知波动指数是——哎呀资料又掉了……"

## 铁心——铸魂城大匠师

### 基本信息
- **性别**：男
- **年龄**：58岁
- **外貌**：粗壮的矮个子，双手满是烧伤疤。永远穿着厚重的皮围裙，身上带着金属和火焰的气味。

### 异能等级与能力
- **天赋异能**：造物系·SS级——"万物锻造"
- **核心能力**：能用任何材料锻造异能武器。武器能"记住"使用者的异能频率，威力提升50%以上。

### 性格核心
**三个关键词**：务实 / 直接 / 只关心"能不能造出来"

### 叙事功能
为余耀和凌霜提供关键装备。他锻造室里有一柄"无法锻造的剑"——B亲手幻想的剑，无人能拔出。这柄剑在最终卷有关键作用。

### 标志性台词
1. "政治？我不懂。你告诉我要什么形状、什么材料、什么功能。其他的不关我事。"

## 阿娜——焚寂城酒馆老板娘

### 基本信息
- **性别**：女
- **年龄**：35岁
- **外貌**：火红卷发，身材高挑，笑起来很爽朗。手臂上有火焰纹身——焚寂城居民的标志。

### 异能等级与能力
- **天赋异能**：火系·C级——"温火"（只能加热液体，最多到沸腾程度）

### 性格核心
**三个关键词**：爽快 / 八卦 / 什么秘密都藏不住但什么秘密都知道

### 叙事功能
焚寂城的"民间情报源"。余耀在焚寂城的很多线索都是从她的酒馆获得的。她的酒馆是赤帝"消失日"前最后出现的地方——阿娜知道赤帝每年去哪，但她从不说。

### 标志性台词
1. "这杯酒免费。故事另算。"
2. "你问赤帝去哪了？我不知道。真的不知道。（低声）你别告诉别人我知道。"

## 夏安——衡都基层士兵

### 基本信息
- **性别**：男
- **年龄**：21岁
- **外貌**：新兵蛋子模样，脸上还有稚气。穿着不太合身的制服。

### 异能等级与能力
- **天赋异能**：躯体系·C级——"微力强化"（力量比普通人强20%左右）

### 性格核心
**三个关键词**：普通 / 害怕但不退缩 / "如果我不站在这里，谁站"

### 叙事功能
最终战中的小人物高光——他是守卫永眠层入口的普通士兵之一。在渊识大军压境时，他是最先被攻击的防线。他没有逃。他的死亡不壮烈、不英雄，只是——没有逃。余耀在战后记住了他的名字。

### 标志性台词
1. "我的异能只能让我比普通人多举30斤。但30斤……大概够举起一面盾吧。"
