## 一、三重世界结构

```
┌─────────────────────────────────────────────────────────────┐
│                      外世界（The Outer World）               │
│  - B 幻想的"没有陨石的世界"                                   │
│  - A 生活的世界（正在缓慢崩塌）                               │
│  - 由"世界之种"（七彩水晶）锚定                              │
│                          ↕ 第四面墙（HDM-010）               │
│  ┌─────────────────────────────────────────────────────┐   │
│  │    里世界（The Inner World）—— 蓝星                  │   │
│  │    - B 肉身沉睡的世界                                  │   │
│  │    - 陨石降临后的千年文明                            │   │
│  │    - 幻梦界与现实层交织                              │   │
│  └─────────────────────────────────────────────────────┘   │
│                          ↕ 认知滤网                         │
│  ┌─────────────────────────────────────────────────────┐   │
│  │    幻梦界（The Dream World）                         │   │
│  │    - 幻梦生物的栖息层                                │   │
│  │    - B 的潜意识投射                                   │   │
│  │    - 认知锚点决定具现程度                            │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

### 1.1 外世界（A 的世界）

| 属性 | 描述 |
|------|------|
| **本质** | B 使用"幻想家"异能创造的平行世界，是一个"没有陨石降临"的蓝星 |
| **锚定物** | 七彩水晶（B 从自己体内的陨石剥离出的"世界之种"） |
| **居民** | 所有居民都是 B 幻想的产物，但拥有完整的人格和记忆 |
| **主角 A** | B 幻想的"更好的我"，被赋予了完整的人生和家庭 |
| **当前状态** | 因世界之种能量流逝，正在缓慢崩塌 |

**崩塌表现**:
- 物理定律异常：重力偶尔失效、时间流速不一致
- NPC 化路人：部分居民开始重复同一句话、同一动作
- 建筑自发老化：房屋在没有外力作用下快速腐朽
- 记忆缺失：A 发现自己的部分记忆变得模糊

### 1.2 里世界（蓝星）

| 属性 | 描述 |
|------|------|
| **本质** | B 肉身沉睡的现实世界，陨石降临后的千年文明 |
| **面积** | 陨石降临后扩张了 10 倍以上 |
| **居民** | 约 1200 万人类（八邦十九镇） |
| **特殊** | B 的肉身封印在衡都地下 3000 米的"永眠层" |
| **当前时间** | 新历 1043 年·春 |

### 1.3 幻梦界

| 属性 | 描述 |
|------|------|
| **本质** | B 的潜意识空间，与里世界现实层重叠但不同维度 |
| **生物** | HDM-001 至 HDM-099 等幻梦生物栖息于此 |
| **显现条件** | 认知锚点越高，生物越能从幻梦界"具现"到现实层 |

| 术语 | 定义 |
|------|------|
| **蓝星** | 陨石降临后的人类对地球的称呼 |

| **第四面墙** | 里世界与外世界的边界 |
| **空白者** | 无法觉醒异能的人，约占 5% |

## 五、A 的能力设定

### 认知锚点系统

| 能力 | 效果 | 代价 |
|------|------|------|
| 看破伪装 | 看穿幻梦生物真身 | 失去外世界记忆 |
| 认知干预 | 改变他人认知 | 外世界崩塌加速 1% |
| 第四面墙窥视 | 看到外世界景象 | 1 小时存在主义危机 |
| 幻想残留感知 | 感知 B 的幻想痕迹 | 吸引 HDM-094 |

### 使用限制

1. A 不能主动攻击任何幻梦生物
2. A 的记忆每 50 章会被自然清洗一次
3. 外世界崩塌累计 100% 时彻底崩塌
