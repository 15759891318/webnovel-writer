# 三九音域风格写作指南 (SanJiu Style Writing Guide)

> **版本**: v1.0 (2026 商业爆款特化版)
> **定位**: 三九音域文笔风格完全解析与实战指南
> **适用**: 《我在精神病院学斩神》、《我不是戏神》风格仿写
> **核心目标**: 产出媲美三九音域原作的高质量网文

---

## 一、风格核心特征

### 1.1 句式特征

| 特征 | 标准 | 示例 |
|------|------|------|
| **单句长度** | ≤30 字（紧张场景≤20 字） | "轰——！！！"、"很美，很亮。" |
| **段落长度** | 1-5 行，极少超过 7 行 | 对话独立成段 |
| **标点密度** | 破折号 0.5-1 次/1000 字 | "滴滴滴——！" |
| **省略号密度** | 6-10 次/1000 字 | "我……我不知道。" |
| **感叹号密度** | 2-5 次/1000 字（紧张场景加倍） | "小心！！" |

---

### 1.2 叙事特征

**深度 POV（第三人称限知视角）**：
- 读者只能知道主角知道的信息
- 避免上帝视角泄露机密
- 内心戏自然化（碎片化、情绪化）

**冰山理论式世界观披露**：
- 只展示 10%，90% 隐藏
- 层层揭开，不一次性告知
- 伏笔回收要有震撼力

---

### 1.3 对话特征

**标签极简主义**：
- 极少使用"他说/她说"
- 用动作/神态/心理代替
- 两人对话省略提示语

**口语化与不完整句**：
- 句子中断（用省略号）
- 话语重复
- 语气词自然插入

**身份差异化语言**：
| 角色类型 | 语言特征 |
|----------|----------|
| 冷静主角 | 简短、命令式、少废话 |
| 幽默配角 | 调侃、吐槽、市井气 |
| 温柔长辈 | 回忆式、关怀、重复叮嘱 |
| 冷酷反派 | 冰冷、简短、威胁式 |

---

### 1.4 战斗特征

**短句主导，节奏如鼓**：
```
轰——！！！

惊天动地的爆鸣撕开绣图。

细密的丝线被火焰点燃。

纷纷扬扬的从空中飘落。
```

**三回合原则**：
- 第 1 回合：试探与定调
- 第 2 回合：转折与环境改变
- 第 3 回合：终结与揭露

**五感并用**：
- 视觉：颜色、光影、动作
- 听觉：碰撞、爆鸣、惨叫
- 触觉：疼痛、速度、震颤
- 嗅觉：血腥、焦糊
- 味觉：血的味道、汗水

## 二、专职 Agent 调用矩阵

### 2.1 Agent 列表与职责

| Agent | 文件名 | 核心职责 | 调用时机 |
|-------|--------|----------|----------|
| **风格适配器** | `sanjiao-style-adapter.md` | 深度去 AI 味、句式重构、标点优化 | Step 2B（每章必调） |
| **对话优化器** | `dialogue-optimizer.md` | 消除"他说/她说"、角色语言个性化 | Step 2C（每章必调） |
| **战斗优化器** | `combat-scene-optimizer.md` | 三回合结构、五感描写、视角转换 | Step 4（有战斗场景时） |
| **伏笔管理器** | `foreshadowing-manager.md` | 伏笔埋设、回收追踪、密度检查 | Step 1.5 & Step 5 |

---

### 2.2 标准写作工作流

```
Step 1: Context Agent 搜集上下文
    ↓
    输出：创作任务书（含追读力策略、创意约束检查、债务状态）

Step 1.5: 伏笔检查 (foreshadowing-manager)
    ↓
    检查：当前活跃伏笔、逾期伏笔、建议回收
    输出：伏笔管理报告

Step 2A: 生成粗稿
    ↓
    要求：严格遵循大纲，实时对照设定百科

Step 2B: 风格适配器 (sanjiao-style-adapter)
    ↓
    处理：去 AI 味润色、感官描写强化、节奏调整
    输出：风格适配报告

Step 2C: 对话优化器 (dialogue-optimizer)
    ↓
    处理：消除单调标签、添加动作/神态、角色语言个性化
    输出：对话优化报告

Step 3: 多 Agent 审查
    ↓
    默认 4 Agent: reader-pull-checker, plot-architect,
                character-psychologist, cool-point-designer
    关键章扩展到 6 Agent: + combat-scene-optimizer, world-builder
    输出：review_metrics 存入 .webnovel/review_metrics/

Step 4: 网文化润色
    ↓
    如有战斗场景：调用 combat-scene-optimizer
    优化：段落拆分、对话精炼、钩子强化、断章艺术

Step 5: Data Agent 处理数据链
    ↓
    操作：更新 index.db (伏笔/爽点/债务/设定变动)
    伏笔入库/更新状态

Step 6: Git 备份
    ↓
    提交：章节正文 + 审查报告 + 数据库快照
```

## 三、三九音域风格检查清单

### 3.1 句式检查（每章必查）

- [ ] 单句是否超过 30 字？（紧张场景 20 字）
- [ ] 段落是否超过 5 行？
- [ ] 是否有禁止句式（"值得注意的是"等）？
- [ ] 是否有长难句需要拆分？
- [ ] 对话是否独立成段？

---

### 3.2 标点符号检查（每章必查）

| 标点 | 检查项 | 标准 |
|------|--------|------|
| **破折号** | 使用是否合理？ | 0.5-1 次/1000 字 |
| **省略号** | 使用是否合理？ | 6-10 次/1000 字 |
| **感叹号** | 是否滥用？ | 2-5 次/1000 字 |
| **独立句号** | 是否有强调用途？ | 10-15 次/1000 字 |

---

### 3.3 对话检查（每章必查）

- [ ] 是否有连续 3 次以上"他说/她说"？
- [ ] 对话前后是否有动作/神态描写？
- [ ] 遮住名字后，能否分清是谁在说话？
- [ ] 角色语言是否符合其身份/性格？
- [ ] 两人对话是否省略了冗余标签？

---

### 3.4 战斗检查（有战斗场景必查）

- [ ] 三回合结构是否完整？
- [ ] 单句是否超过 20 字？
- [ ] 段落是否超过 3 行？
- [ ] 拟声词是否独立成段？
- [ ] 是否有五感描写？
- [ ] 视角是否有全景/中景/近景/特写转换？
- [ ] 是否有破坏性具象化描写？

---

### 3.5 伏笔检查（每章必查）

- [ ] 本章新增伏笔数量？（发展章 2-4 个）
- [ ] 本章回收伏笔数量？（发展章 1-3 个）
- [ ] 是否有逾期超过 10 章的伏笔？
- [ ] 伏笔埋设是否足够隐蔽？
- [ ] 伏笔回收是否有情感/剧情冲击？

## 四、三九音域风格模板库

### 4.1 开篇模板

**时间/地点锚定**：
```
炎炎八月。
滴滴滴——！

刺耳的蝉鸣混杂着此起彼伏的鸣笛声，回荡在人流湍急的街道上……

路边为数不多的几团树荫下，几个小年轻正簇在一起，叼着烟，等待着红绿灯。
```

**异常现象引入**：
```
林七夜黑缎缠目，摸索着过马路。

司机探出头来大骂：
"找死啊！没长眼睛吗！"

他停下脚步，侧耳倾听。
"……看见了。"他喃喃自语。
黑缎之下，金色的光芒正在闪烁。
```

---

### 4.2 情感爆发模板

**牺牲场景**：
```
"够了……已经够了。"

他倚靠着身后的断墙，双眸缓缓的闭起。

"我花了半辈子，救下了我的女儿，儿子。
现在，我要去陪伴我的黑道公主殿下了……
没有我在她的身边，她一定很寂寞吧？"

风，停了。

"父亲我……该走了。"
```

---

### 4.3 战斗高潮模板

**大招释放**：
```
轰——！！！

惊天动地的爆鸣撕开绣图。

细密的丝线被火焰点燃。

纷纷扬扬的从空中飘落。

像是冬日里的雪花。

绚烂，璀璨。

……

然后，在下一瞬——

以它为中心，一道漆黑的裂缝，以惊人的速度向着四周蔓延而去！

咔咔咔——

 crack——！
```

### 4.4 伏笔埋设模板

**日常中的异常**：
```
姨妈做的红烧肉很好吃。

陈伶吃得很香，直到他夹起第三块肉时，动作突然停住了。

"怎么了？"姨妈问。

"没事。"他低下头，继续扒饭。

那块肉的肥瘦比例，和之前两块一模一样。

就像……复制出来的一样。
```

### 4.5 对话标签优化模板

**优化前**：
```
"你来了。"他说。
"嗯。"她说。
"坐吧。"他说。
"谢谢。"她说。
```

**优化后（三九风格）**：
```
"你来了。"他抬起头，放下手中的文件。

"嗯。"

她轻轻关上门，走到对面的椅子前。

"坐吧。"他指了指椅子，嘴角带着一丝笑意。

"谢谢。"她坐下，双手交叠放在膝上。
```

## 五、常见问题与解决方案

### 5.1 AI 味过浓

**症状**：
- 长难句频出
- 机械化过渡词（"然而"、"此外"）
- 抽象情绪词（"生气"、"害怕"）

**解决方案**：
1. 调用 `sanjiao-style-adapter` 进行句式重构
2. 将抽象情绪转化为行为描写
3. 拆分长句为短句（≤30 字）

---

### 5.2 对话单调

**症状**：
- 连续使用"他说/她说"
- 角色语言无差异化
- 缺少动作/神态描写

**解决方案**：
1. 调用 `dialogue-optimizer` 优化对话标签
2. 为每个角色建立语言档案
3. 两人对话省略冗余标签

---

### 5.3 战斗流水账

**症状**：
- 缺少三回合结构
- 只有动作描写，无五感细节
- 视角单一，缺少转换

**解决方案**：
1. 调用 `combat-scene-optimizer` 重构战斗
2. 添加拟声词独立成段
3. 在实景/中景/近景/特写间切换

---

### 5.4 伏笔管理混乱

**症状**：
- 伏笔逾期未能回收
- 伏笔数量过多，读者记不住
- 回收缺乏冲击力

**解决方案**：
1. 调用 `foreshadowing-manager` 追踪伏笔
2. 控制活跃伏笔数量（≤100 个）
3. 长中短期伏笔按比例配置（1:3:6）

## 七、快速参考卡

### 7.1 禁止句式清单

❌ "值得注意的是……"
❌ "综上所述……"
❌ "首先……其次……最后……"
❌ "总而言之……"
❌ "毫无疑问……"
❌ "我们可以看到……"
❌ "这说明了……"
❌ 机械化过渡词（"然而"、"此外"、"与此同时"滥用）

---

### 7.2 推荐句式

✅ 短句主导（≤30 字）
✅ 独立成段的拟声词
✅ 动作/神态代替"他说"
✅ 破折号表示转折/延长
✅ 省略号表示停顿/中断
✅ 独立句号强调

---

# 风格适配（每章必调）

# 伏笔检查（每章必查）

/foreshadowing-list --overdue

## 八、质量评估标准

### 8.1 章节质量评分

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| **句式规范** | 20% | 单句≤30 字、段落≤5 行 |
| **对话质量** | 20% | 标签极简、角色差异化 |
| **战斗描写** | 20% | 三回合结构、五感并用 |
| **伏笔管理** | 15% | 密度合理、回收有冲击 |
| **去 AI 味** | 15% | 无禁止句式、感官描写 |
| **节奏呼吸** | 10% | 长短句交错、情绪曲线 |

**总分≥85 分**：章节合格，可以发布
**总分 70-84 分**：需要润色
**总分<70 分**：需要重写
