# 角色一致性维护手册 (Character Consistency Handbook)

> **版本**: v6.0
> **目标**: 确保角色行为符合性格逻辑，成长有铺垫，转折不 OOC

### 完整角色档案模板

```markdown

- **首次出现**: 第 X 章
- **身份**: [表面身份] / [实际身份]
- **年龄**: X 岁
- **境界/等级**: [当前境界]
```

## 二、OOC 检测方法

### OOC 定义

**OOC **(Out Of Character): 角色行为与其性格、动机、历史不符，缺乏合理铺垫。

### OOC 判定流程

```
1. 提取角色行为/对话
   ↓
2. 对照角色档案（性格/动机/历史）
   ↓
3. 判断是否有合理触发条件
   ↓
4. 判定是否 OOC 及严重程度
```

### OOC 风险等级

| 等级 | 说明 | 处理方案 |
|------|------|---------|
| **Low** | 行为符合性格 | 无需处理 |
| **Medium** | 略有偏差但有触发事件 | 补充心理描写 |
| **High** | 明显违背性格 | 必须修改或添加充分铺垫 |
| **Critical** | 与核心人设冲突 | 必须重写 |

### 常见 OOC 类型

#### 1. 性格 OOC

**示例**:
- 设定是"谨慎保守"，突然无脑冲
- 设定是"冷酷无情"，突然圣母心泛滥
- 设定是"正直善良"，突然不择手段

**检测规则**:
```python
if action.contradicts(personality.core_trait) and not has_valid_trigger():
    return OOC_High
```

#### 2. 动机 OOC

**示例**:
- 行为没有合理动机支撑
- 动机与核心欲望冲突
- 突然改变目标无解释

**检测规则**:
```python
if not has_valid_motivation(action):
    return OOC_High
```

#### 3. 关系 OOC

**示例**:
- 关系突变无铺垫（敌人突然变朋友）
- 互动模式与设定不符（恭敬变放肆）
- 忘记历史包袱（杀父仇人突然和平相处）

**检测规则**:
```python
if relationship_change and not has_proper_setup():
    return OOC_Medium
```

#### 4. 能力 OOC

**示例**:
- 突然掌握未学习的能力
- 突然知道不该知道的信息
- 越级挑战无合理解释

**检测规则**:
```python
if ability_not_in_profile and not has_learning_process():
    return OOC_High
```

#### 5. 对话 OOC

**示例**:
- 粗人说文绉绉的话
- 智者说啰嗦废话
- 角色说话风格突变

**检测规则**:
```python
if not matches_speech_pattern(dialogue):
    return OOC_Low_to_Medium
```

## 三、角色成长弧光设计

### 成长阶段模型（英雄之旅）

```
阶段 1: 平凡世界 (Ordinary World)
  特征：角色日常状态，展示性格 baseline
  ↓ [触发事件/激励事件]
阶段 2: 冒险召唤 (Call to Adventure)
  特征：面临选择，内心挣扎
  ↓ [犹豫/拒绝召唤]
阶段 3: 跨越门槛 (Crossing the Threshold)
  特征：做出决定，踏上旅程
  ↓ [考验、盟友、敌人]
阶段 4: 接近洞穴 (Approach to Inmost Cave)
  特征：接近核心冲突，压力增大
  ↓ [严峻考验]
阶段 5: 核心考验 (Ordeal)
  特征：生死关头，最大挑战
  ↓ [奖励/成长]
阶段 6: 回归之路 (The Road Back)
  特征：带着成长返回，新的挑战
  ↓ [最终考验]
阶段 7: 携恩赐回归 (Return with Elixir)
  特征：完成蜕变，帮助他人
```

### 成长指标检测

**成长的表现**:

| 维度 | 成长前 | 成长后 |
|------|--------|--------|
| **决策模式** | 冲动/犹豫 | 果断/周全 |
| **情绪控制** | 易怒/脆弱 | 稳定/坚韧 |
| **能力水平** | 弱/不熟练 | 强/熟练 |
| **人际关系** | 依赖/孤立 | 独立/领导 |
| **自我认知** | 迷茫/自卑 | 清晰/自信 |
| **价值观** | 单一/极端 | 多元/平衡 |

### 成长铺垫要求

**重大成长/转变** 必须满足以下至少 3 项：

1. **事件触发**: 至少 1 个重大事件作为转折点
2. **心理描写**: 至少 3 处内心挣扎/思考的描写
3. **行为累积**: 至少 3 个前置事件展示变化过程
4. **他人反馈**: 至少 2 个配角注意到变化
5. **代价展示**: 明确写出成长付出的代价

**示例**: 主角从"仁慈"转变为"狠辣"

```
❌ 错误写法（无铺垫）:
以前主角从不杀俘虏，这次突然把俘虏全杀了。

✅ 正确写法（有铺垫）:
1. 事件触发：俘虏背叛，导致主角重要的人死亡
2. 心理描写：主角整夜未眠，思考仁慈的代价
3. 行为累积：之前已有 2 次因仁慈吃亏的经历
4. 他人反馈："你变了。"药老看着主角，复杂地说
5. 代价展示：主角知道自己回不去了，但选择继续
```

## 四、镜像对抗设计

### 镜像对抗定义

**核心逻辑**: 反派与主角共享核心欲望/缺陷，但选择相反的实现路径。

### 设计模板

```markdown
## 镜像对抗：[主角名] vs [反派名]

### 共同点
- **核心欲望**: [保护家人/追求力量/渴望认可等]
- **共同缺陷**: [过于仁慈/优柔寡断/极端自负等]

### 分歧点
| 维度 | 主角 | 反派 |
|------|------|------|
| **实现路径** | [路径 A] | [路径 B（相反）] |
| **核心选择** | [选择 A] | [选择 B] |
| **代价接受** | [接受代价 A] | [接受代价 B] |

### 深化方式
- **对话揭示**: 通过对话让反派阐述自己的理念
- **回忆对比**: 展示两人曾经的相似经历
- **对比事件**: 同一情境下两人的不同选择
```

### 示例：萧炎 vs 魂天帝

```markdown
### 核心欲望
- 萧炎：保护家人和朋友
- 魂天帝：保护家族和血脉

### 实现路径
- 萧炎：变强守护，遵守底线，不伤无辜
- 魂天帝：不择手段，牺牲他人，达成目的

### 共同缺陷
- 都过于执着于"保护"，愿意为此付出一切

### 深化场景
魂天帝："萧炎，你以为我和你不一样？若不是当年那场变故，我也会像你一样，选择另一条路。"

萧炎沉默。他确实从魂天帝眼中看到了熟悉的火焰——那是守护的执念，只是被扭曲成了另一种形态。

"可惜，"魂天帝继续说道，"这个世界不给我们选择的余地。要么成为主宰，要么成为蝼蚁。你我都清楚。"

萧炎握紧拳头："我选择第三条路。"

"哦？"魂天帝笑了，"让我看看，你的第三条路，能走多远。"
```

## 五、角色关系动态追踪

### 关系维度

| 维度 | 说明 | 追踪内容 |
|------|------|---------|
| **权力动态** | 谁占主导/平等 | 师徒/朋友/上下级 |
| **情感基调** | 信任/怀疑/敌意 | 从信任到怀疑的转变 |
| **互动模式** | 直接/含蓄/对抗 | 说话方式、身体语言 |
| **历史包袱** | 过往事件影响 | 恩怨情仇 |

### 关系变化检测

**关系变化必须有铺垫**:

```
关系突变检测:
if prev_relationship.trust == 'high' and curr_relationship.trust == 'low':
    if not find_betrayal_or_conflict_event():
        return Warning("关系变化无触发事件")
```

### 关系档案模板

```markdown
## 关系：[角色 A] ↔ [角色 B]

### 关系类型
- [表面]: 朋友
- [实际]: 互相利用

### 关系演变
- **初遇 **(第 X 章): [情况]
- **发展 **(第 Y 章): [事件]
- **转折 **(第 Z 章): [事件]
- **当前状态**: [状态]

### 互动模式
- [角色 A 对 B]: [态度/行为模式]
- [角色 B 对 A]: [态度/行为模式]

### 未解决冲突
- [冲突 1]: [状态]
- [冲突 2]: [状态]

### 潜在风险
- [可能导致关系破裂的因素]
```

## 六、审查检查清单

### 角色一致性终检清单

在章节发布前，必须检查：

- [ ] 所有出场角色行为符合性格设定
- [ ] 重大行为有合理动机支撑
- [ ] 关系变化有充分铺垫
- [ ] 对话符合角色说话风格
- [ ] 能力使用符合角色档案
- [ ] 成长/转变有足够铺垫（至少 3 项）
- [ ] 镜像对抗有深化（若适用）
- [ ] 无 OOC 风险或已添加充分铺垫

### OOC 风险评分卡

**评分规则**:

```
OOC 风险分 =
  性格冲突行为数 × 5 +
  动机缺失行为数 × 4 +
  关系突变数 × 3 +
  对话风格不符数 × 2 +
  能力来源不明数 × 3
```

**评分标准**:
- 0: 完美 ✅
- 1-5: 轻微风险，可接受
- 6-10: 中度风险，建议修改
- 11+: 高度风险，必须修改

## 七、常见错误与修正

### 错误 1: 圣母心突发

**问题**: 冷酷角色突然发善心

**修正**:
- 添加触发条件（想起自己的过去）
- 添加内心挣扎（"我这是在做什么..."）
- 添加合理动机（此人以后可能有用）

### 错误 2: 无脑冲

**问题**: 谨慎角色突然鲁莽

**修正**:
- 添加触发条件（触及底线/红线）
- 添加前置铺垫（已忍了很久）
- 添加事后反思（"刚才太冲动了"）

### 错误 3: 突然降智

**问题**: 智者角色犯低级错误

**修正**:
- 添加干扰因素（情绪波动/信息不足）
- 添加客观限制（时间压力/外力影响）
- 改为故意示弱（其实是装的）

### 错误 4: 关系突变

**问题**: 敌人突然变朋友

**修正**:
- 添加共同利益（共同的敌人）
- 添加过渡阶段（从敌对到中立到合作）
- 添加试探过程（多次试探后才信任）
