# 去 AI 味·拟人化写作协议 (Anti-AI Style Protocol)

> **版本**: v6.0
> **目标**: 消除 AI 写作痕迹，打造媲美人类作家的文字质感

---

## 一、AI 高频禁用词/句式

### 第一梯队（必须替换）

| AI 词/句式 | 问题 | 替代方案 |
|-----------|------|---------|
| 值得注意的是 | 学术化、说教感 | 关键是/重点是/要知道/别忘了 |
| 综上所述 | 论文腔 | 总之/说白了/一句话/兜了一圈 |
| 首先...其次...最后 | 机械化列举 | 先说...再看...最后/一来...二来...三来 |
| 总而言之 | 书面腔 | 总的来说/概括来说/绕回来 |
| 毫无疑问 | 绝对化 | 没跑/板上钉钉/铁了心/十有八九 |
| 可以预见的是 | 上帝视角 | 明摆着/用脚指头想都知道 |
| 让我们... | 说教感 | 来/走/看/话回 |
| 我们可以看到 | 旁观者视角 | 你瞧/你看/这不明摆着 |
| 这说明了 | 总结腔 | 这说明啥/意思很明白/摆明了 |
| 然而 | 书面化 | 可/但/话又说回来 |
| 此外 | 公文腔 | 还有/再说/另外/顺带一提 |
| 与此同时 | 机械化 | 同一时候/这边...那边.../说话间 |
| 因此/所以（句首滥用） | 逻辑连接词滥用 | 这才/这下/结果/这才有了 |
| 具体而言 | 学术化 | 说具体的/往细了说/拆开讲 |
| 从某种意义上来说 | 废话文学 | 说穿了/往深了想/说白了 |

### 第二梯队（限制使用，每章≤3 次）

- 不仅...而且...
- 一方面...另一方面...
- 与其说...不如说...
- 之所以...是因为...
- 即使...也...
- 尽管...但是...
- 与其...不如...
- 宁可...也不...
- 显而易见
- 不言而喻
- 总而言之
- 归根结底
- 从某种程度上来说
- 在一定程度上
- 值得注意的是（重复强调，因为太常见）

### 第三梯队（警惕句式）

| 句式模式 | 问题 | 改写方向 |
|---------|------|---------|
| "可以说" + 抽象概括 | 模糊、逃避具体 | 直接给具体画面 |
| "在一定程度上" | 废话、无信息量 | 删掉或改为具体程度 |
| "从...角度来看" | 学术化 | 直接用角色视角 |
| "值得注意的是" + 句 | 说教感 | 直接说事，别提醒 |
| "这说明" + 抽象 | 告诉而非展示 | 用角色行为展示 |
| "仿佛/似乎/好像"连用 | 不确定感 | 减少模糊词，增强确定性 |

## 二、感官描写优先原则

### 核心原则

**Show, Don't Tell** —— 用细节让读者自己得出结论，而不是直接告诉读者。

### 五感描写对照表

#### 视觉 (Visual)

| AI 写法 | 人类写法 |
|--------|---------|
| "这个地方很恐怖" | "墙壁上暗红色的痕迹还没干透，踩上去能感觉到脚下黏糊糊的" |
| "他很帅" | "剑眉星目，鼻梁高挺，嘴唇薄而锋利，笑起来像一把出鞘的刀" |
| "她很生气" | "胸口剧烈起伏，指节捏得发白，眼神像刀子一样剜过来" |
| "天色已晚" | "夕阳最后一抹余晖沉入地平线，墨色从四面八方涌来" |

#### 听觉 (Auditory)

| AI 写法 | 人类写法 |
|--------|---------|
| "发出很大的声音" | "'轰'的一声巨响，震得耳膜嗡嗡作响，胸腔都跟着共鸣" |
| "很安静" | "静得能听见自己的心跳，连呼吸都显得刺耳" |
| "他在敲门" | "'叩、叩、叩'，三声，不急不缓，像是算准了时间" |
| "她哭了" | "压抑的抽泣声从门缝里漏出来，像受伤的小兽" |

#### 嗅觉 (Olfactory)

| AI 写法 | 人类写法 |
|--------|---------|
| "闻到一股味道" | "腥甜味直冲脑门，像是铁锈混合着腐肉，呛得人胃里翻腾" |
| "很香" | "甜腻的脂粉香混着酒气，往鼻子里钻，让人想起昨夜那些涂脂抹粉的脸" |
| "有血腥味" | "铁锈味若有若无地飘着，像是有人刚杀过鸡，但萧炎知道，这味道来自人" |

#### 触觉 (Tactile)

| AI 写法 | 人类写法 |
|--------|---------|
| "感觉很冷" | "寒气顺着领口往里钻，鸡皮疙瘩一层层往外冒，牙齿不受控制地打颤" |
| "他很紧张" | "手心全是汗，握剑的手不受控制地发抖，掌心的纹路都被汗水填满" |
| "她抓住了他" | "指甲深深掐进他的胳膊，像是溺水的人抓住最后一根稻草" |

#### 味觉 (Gustatory)

| AI 写法 | 人类写法 |
|--------|---------|
| "尝起来很苦" | "苦味在舌尖炸开，顺着喉咙往下爬，苦得舌根发麻，胃里一阵抽搐" |
| "血的味道" | "咸腥味在嘴里弥漫开，混着泥土的苦涩，这是他自己的血" |
| "酒很烈" | "一口下去，喉咙像被火烧了一样，一路烫到胃里，辣得眼泪都出来了" |

## 三、句式多样化策略

### 长短句交错

**AI 写法**（全是短句，机械）:
```
他拿起剑。他走向敌人。他用力挥砍。敌人倒下了。
```

**AI 写法**（一句到底，憋气）:
```
他拿起那把跟随自己多年的长剑，迈着沉稳的步伐走向那个曾经不可一世的敌人，然后用尽全力挥出了这一击，看着敌人在剑光中倒下。
```

**人类写法**（长短交错，有呼吸感）:
```
他拿起剑。剑身很轻，像羽毛——可他知道，这一剑挥出，就是生死两隔。

脚步很稳。一步，两步，三步。

距离在缩短，心跳在加速。敌人就在那里，那个曾经不可一世的家伙，此刻眼中也有了一丝慌乱。

好，就是现在！

剑光闪过，血花绽放。
```

### 特殊句式运用

| 句式 | 作用 | 示例 |
|------|------|------|
| 倒装句 | 强调、变化节奏 | "来了，他。" / "好刀，真是好刀！" |
| 省略句 | 留白、紧张感 | "人呢？""跑了。" |
| 感叹句 | 情绪爆发 | "好！好得很！" |
| 反问句 | 增强语气 | "你以为这还是三年前？" |
| 独词句 | 强调、停顿 | "杀！" / "走！" / "滚！" |

### 对话口语化

**AI 写法**（书面化）:
```
"我非常感谢你给我的帮助，我会永远记住你的恩情。"他说。
```

**人类写法**（口语化）:
```
"这份情，我记下了。"他说，"以后有用得着的地方，尽管开口。"
```

**角色身份匹配**:
- 粗人：短、直、带粗话
- 智者：简、准、留余地
- 贵族：雅、绕、讲规矩
- 市井：活、俗、接地气

## 四、叙事视角沉浸

### 深度 POV (Point Of View)

**核心原则**: 读者只能知道主角知道的信息。

**AI 写法**（上帝视角泄露）:
```
萧炎走进大殿，他不知道的是，角落里正有一双眼睛盯着他，那是魂族的探子。
```

**人类写法**（紧贴主角视角）:
```
萧炎走进大殿。

总觉得哪里不对劲。

目光扫过角落，一个黑衣人迅速低下头，像是刻意回避他的视线。

萧炎脚步顿了顿，没说什么，径直走向自己的位置。

那人...有点问题。他记下了那个方位。
```

### 内心戏自然化

**AI 写法**（逻辑严密的论文式独白）:
```
他很清楚自己现在的处境。首先，实力不如对方；其次，没有外援；最后，时间拖得越久对自己越不利。因此，他决定速战速决。
```

**人类写法**（碎片化、情绪化）:
```
麻烦了。

打不过，跑不掉，援兵？别想了，这鬼地方谁知道他们躲在哪。

拖下去只有死路一条。

那还剩什么选择？

他握紧拳头，指甲掐进掌心。

只有拼了。速战速决，要么赢，要么死。
```

## 五、留白艺术

### 原则：不要把所有话说尽

**AI 写法**（说尽）:
```
他很愤怒，因为他感觉自己被背叛了，他最好的朋友竟然出卖了他，这让他非常生气。
```

**人类写法**（留白）:
```
他盯着那张熟悉的脸。

曾经一起喝酒，一起拼命，一起说"一辈子兄弟"。

现在，那把刀就插在自己胸口。

握着刀柄的手，还在微微颤抖。

"为什么？"

声音很轻，轻得像在问自己。

对方没说话。眼神躲闪，嘴唇动了动，最终只是低下头。

够了。不需要答案了。
```

### 情绪点留白

在关键情绪点，戛然而止，让读者自己填补：

```
她看着他，看了很久。

最终，她笑了。

"祝你幸福。"

转身，离去。没有回头。

萧炎站在原地，想说点什么，却发现喉咙像是被什么东西堵住了。

说什么呢？

已经什么都没有必要了。
```

## 六、断章艺术

### 章末卡点原则

**必须卡在**:
- 战斗即将爆发（拳头已到面前）
- 秘密即将揭晓（手已经放在门上）
- 抉择就在眼前（刀架在脖子上）
- 意外降临（平静中突然出现变故）

**禁止卡在**:
- 睡觉
- 赶路结束
- 无事发生
- 平淡的对话结束

### 优秀断章示例

**危机钩**:
```
"明天，就是你的死期。"

慕容战天转身离去，留下一句话在空气中回荡。

萧炎握紧拳头，掌心已被指甲掐出了血。

明天...

他看向药老："有几分把握？"

药老沉默片刻，缓缓伸出三根手指。

"三成？"

"三息。"
```

**信息钩**:
```
"你知道你母亲是什么人吗？"

萧炎猛地抬头，看向药老。

这个问题，他等了十几年。
```

**反转钩**:
```
"你以为，我真的是来帮你的？"

那张熟悉的脸露出陌生的笑容，萧炎如坠冰窖。

药老...有问题！
```

## 七、审查检查清单

### 去 AI 味终检清单

在章节发布前，必须检查：

- [ ] AI 禁用词出现次数 ≤ 2
- [ ] 单段最大长度 ≤ 5 行
- [ ] 连续 3 段无相同结构
- [ ] 每 300 字至少有 1 个感官细节
- [ ] 对话有动作/神态支撑
- [ ] 长短句交错，有呼吸感
- [ ] 关键情绪点有留白
- [ ] 章末卡在关键节点

### AI 痕迹评分卡

**评分规则**（满分 100，越低越好）:

```
AI 痕迹分 =
  禁用词次数 × 3 +
  长难句数（>40 字无标点）× 2 +
  抽象概括段落数 × 5 +
  句式重复数（连续 3 段相同）× 4 -
  感官细节数 × 2
```

**评分标准**:
- 0-20: 人类质感优秀 ✅
- 21-40: 轻微 AI 味，可接受
- 41-60: 明显 AI 味，需润色 ⚠️
- 61-80: 重度 AI 味，需大幅改写 ❌
- 81+: 机器痕迹严重，建议重写 ❌❌

## 八、题材特异性处理

### 玄幻/修仙

- 功法名称保留，解释性文字删减
- 境界突破强调身体感受（痛/热/涨/裂）
- 战斗描写优先视觉 + 听觉
- 对话可略带古风但不晦涩

### 都市/婚恋

- 对话口语化程度提高
- 心理描写增加现代感
- 环境描写贴近生活细节
- 避免书面化、说教感

### 科幻/末世

- 科技术语保留，增加直观比喻
- 环境描写强调异质感、压抑感
- 多用触觉 + 嗅觉营造氛围
- 对话简洁，符合高压环境

### 历史/古风

- 对话符合时代感但不晦涩
- 环境描写引用古典意象
- 避免现代词汇穿帮（手机、电脑等）
- 可适度使用文言词汇点缀

## 九、常见场景改写模板

### 场景：愤怒

**AI 版**:
```
他非常生气，因为他觉得自己被侮辱了。
```

**人类版**:
```
茶杯"咔嚓"一声裂开。

滚烫的茶水顺着掌心流下，他却浑然不觉。

"你再说一遍？"

声音很冷，冷得让对面的家伙打了个寒颤。
```

### 场景：紧张

**AI 版**:
```
他很紧张，手心出汗，心跳加速。
```

**人类版**:
```
手心全是汗。

握剑的手不受控制地发抖，掌心的纹路都被汗水填满。

心跳声在耳边回荡，一下，两下，越来越快。

该死，冷静点！他在心里对自己吼，可身体完全不听使唤。
```

### 场景：悲伤

**AI 版**:
```
她很伤心，眼泪止不住地流下来。
```

**人类版**:
```

眼眶发热。

有什么东西模糊了视线，顺着脸颊滑落，凉的。

她抬手去擦，越擦越多。

算了，不擦了。

想哭就哭吧，反正也没人看见。
```
