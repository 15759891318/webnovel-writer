# 约束冲突检测指南 (v1.0)

**应用场景**: 在写作或大纲规划阶段，当发现"创意约束与大纲存在矛盾"时，使用本指南判断和解决

---

## 冲突类型分类

### 类型 A: 约束 vs 大纲事件

**定义**: 创意约束规定A应该发生，但大纲规定¬A

**示例**:
```
创意约束: "反派智商在线" → 反派的计划必须周密，不能降智
大纲规定: "第 20 章，反派因一个小疏漏被主角逮住机会"
冲突: ❌ 反派因为疏漏被逮住，说明智商不在线
```

**判断标准**:

| 冲突程度 | 定义 | 处理建议 |
|--------|------|---------|
| 🔴 严重冲突 | 造成"约束明显崩坏" | 必须修改大纲或放弃约束 |
| 🟠 中等冲突 | 造成"约束弱化但可接受" | 可调和，通过修饰语或补充背景 |
| 🟡 轻微冲突 | 造成"约束需要特殊解释" | 可忽视，或在对话中说明 |

**调和方案**:
```
原大纲: "反派因为疏漏被逮住"
修改后: "反派故意露出破绽，引诱主角上钩（实为更大计划的一部分）"
→ 转化为"反派智商在线"的证据
```

---

### 类型 B: 约束 vs 约束冲突

**定义**: 两个被选中的创意约束之间存在矛盾

**示例**:
```
约束1: "主角有严重道德缺陷"（为达目的不择手段）
约束2: "反派是主角灵魂碎片"（代表主角的另一面）
冲突: 反派和主角都"不择手段"，怎么区分两个不同的角色?
```

**判断标准**:

| 程度 | 处理 |
|-----|------|
| 真正冲突 | 必须舍去一个约束，重新选择 |
| 假冲突 | 其实可以互补，深化彼此 (如上例：反派是"过度"的缺陷版本) |
| 可调和 | 调整约束的"强度"或"表现形式" |

**调和示例**:
```
约束1 (主角缺陷): 主角为了活下去，会伤害无辜
约束2 (反派碎片): 反派为了"保护"主角，会伤害无辜

区别: 都是伤害无辜，但动机不同
→ 深化"镜像对抗"：主角vs反派的伦理困境
```

---

### 类型 C: 约束 vs 题材气质冲突

**定义**: 约束的表现方式与整体题材气质不符

**示例**:
```
题材气质: 克苏鲁诡秘（压抑、疯狂、恐怖）
约束: "反派智商在线"
冲突: 如果反派过于"聪慧理性"，会削弱克苏鲁的"疯狂感"
```

**判断标准**:

| 程度 | 处理 |
|-----|------|
| 严重冲突 | 调整约束的表现方式（用疯狂来展现智商） |
| 轻微冲突 | 如实表现，读者会适应 |

**调和示例**:
```
原表现: "反派冷静地分析每一步棋"
新表现: "反派用疯狂的方式执行周密的计划，让主角分不清是疯狂还是智谋"
→ 融合"克苏鲁疯狂"与"反派智商"
```

## 冲突检测流程

### Step 1: 识别冲突

**触发条件**（以下任何一条）:
- 大纲规定的事件与约束期望不符
- 写作时发现"约束无法激活"
- 读者反馈"这个设定与之前的不一致"

**识别方法**:
```
1. 准确表述约束期望：
   "约束X期望的是：发生Y事件或呈现Z特征"

2. 查看大纲/正文中的现实：
   "大纲/正文实际上：发生¬Y事件或呈现¬Z特征"

3. 对比：
   期望 vs 现实 → 冲突程度?
```

### Step 2: 判断冲突严重程度

使用"约束崩坏指数"判断：

```
约束崩坏指数 = (期望 - 现实) / 期望 × 100%

> 50%: 🔴 严重崩坏，约束基本失效
25-50%: 🟠 中度崩坏，约束弱化但可见
< 25%: 🟡 轻微崩坏，约束仍能识别
```

**示例**:
```
约束: "反派智商在线" (每个计划都应该周密)
现实: 反派的 10 个计划中，9 个周密，1 个有疏漏
崩坏指数: (1-9)/10 = 10% 

判定: 🟡 轻微冲突，可接受
```

### Step 3: 选择处理方案

| 冲突程度 | 处理方案 |
|--------|--------|
| 🔴 严重 | 必须修改（大纲或约束选择） |
| 🟠 中等 | 调和（修饰某个细节或添加背景说明） |
| 🟡 轻微 | 可忽视或备注（供后期审查） |

## 处理方案详解

### 方案 A: 修改大纲

**适用**: 约束更重要，需要调整剧情

**步骤**:
1. 在细纲中标注冲突点
2. 提出"大纲修改建议"
3. 等待审批（或自行决定）
4. 重新生成 context-agent 的执行包

**示例**:
```
冲突: 第 20 章反派因疏漏被逮住，违反"智商在线"约束
修改建议: 将"反派疏漏"→"反派故意露出破绽"
影响: 需要在第 21 章补充"反派的真实目的"对白
```

### 方案 B: 调整约束表现方式

**适用**: 约束本身没问题，但表现方式需要優化

**步骤**:
1. 不改大纲，改"约束在大纲中的体现方式"
2. 在执行包中标注"特殊说明"
3. 写作时按照新的表现方式进行

**示例**:
```
冲突: "反派智商在线"与"克苏鲁疯狂"气质冲突
调整: 反派用"疯癫的方式"执行周密的计划
体现: 反派的对白带着疯笑，但逻辑清晰；动作看似混乱，但打击精准
```

### 方案 C: 修改或放弃约束

**适用**: 约束与大纲根本不兼容，且改大纲成本太高

**步骤**:
1. 在 idea_bank.json 中标注为"inactive"
2. 从反套路库选择替代约束
3. 重新规划后续章节的约束激活

**示例**:
```
原约束: "反派是主角灵魂碎片"
问题: 大纲后期需要"清晰的敌我对立"，无法体现碎片的"共同性"
决定: 放弃此约束，改为"反派是主角的镜像"（保留镜像对抗，但关系更清晰）
```

### 方案 D: 添加补充背景或设定

**适用**: 冲突其实可以用"额外信息"来解释

**步骤**:
1. 在细纲或执行包中添加"背景说明"
2. 在对话或独白中植入解释
3. 补充 index.db 的相关设定

**示例**:
```
冲突: 反派在 A 地行动谨慎，在 B 地却莽撞，违反"智商在线"
补充设定: 反派在 B 地有"盲点"或被某种力量控制，故意失控
体现: 在反派的独白或旁白中解释这个失控
```

## 冲突预防体系

### 定期检查 (每 5-10 章)

**检查清单**:
```
[ ] 约束激活日历的进度是否符合计划?
[ ] 本轮的约束激活是否与大纲冲突?
[ ] 新增的剧情是否破坏了已有的约束?
[ ] 是否出现了"约束虚化"的迹象? (后期被逐渐忽视)
```

### 风险预警

**高风险信号**:
- 🔴 某个约束已经 5 章未出现
- 🔴 约束与大纲的冲突程度超过 30%
- 🔴 读者评论提到"人物性格突变"or "逻辑不通"

### 保险机制

在 idea_bank.json 中设置"约束冲突容忍度":
```json
{
  "conflict_tolerance": {
    "max_acceptable_deviation": "30%",
    "auto_alert_threshold": "25%",
    "enforce_resolution_by_chapter": 100
  }
}
```

## 常见问题 (FAQ)

### Q: 如果约束和大纲都很重要，怎么办？

**A**: 尝试"融合"而非"选择"。
- 修改大纲的表现形式，使其符合约束
- 修改约束的表现方式，使其兼容大纲
- 查找"隐含的相容性"

### Q: 能否在写作中途改约束？

**A**: 不建议。但如果冲突程度 > 50%，可以考虑：
1. 标记为"inactive"（不再强制执行）
2. 选择替代约束
3. 补充说明（在作者后记中）

### Q: 约束放弃了，之前的伏笔怎么办？

**A**: 有两种方案：
1. **转移**: 将该约束的伏笔转化为"纯伏笔"，不再作为约束激活点
2. **保留**: 约束inactive，但与该约束相关的剧情仍按原计划进行（只是列目标弱化）

### Q: 如何判断冲突是"真冲突"还是"假冲突"？

**A**: 问自己：
- 这两者是否真的互相排斥？
- 是否存在"双方都可以满足"的方式？
- 问题出在"理解"还是"设定"？

若答案是"可以调和"，那就是假冲突，需要调和而非取舍。

## 总结

| 冲突类型 | 主要处理方式 | 决策权 |
|--------|-----------|--------|
| **约束 vs 大纲冲突** | 修改大纲或调整约束表现 | 优先约束 (约束是核心创意) |
| **约束 vs 约束冲突** | 调和或舍去一个 | 依情况而定 |
| **约束 vs 气质冲突** | 调整表现方式 | 优先气质 (氛围是基础) |

**核心原则**: 约束是"创意差异化"的源头，尽量保留；大纲是"执行方案"，相对灵活。当两者冲突时，**优先保护约束，调整大纲**。
