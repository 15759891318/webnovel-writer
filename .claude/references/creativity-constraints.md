# 创意约束完全手册 (Creativity Constraints Handbook)

> **版本**: v6.0
> **目标**: 确保每部作品都有独特创新点，避免套路化、同质化

---

## 一、三轴混搭引擎

### 核心原则

每部作品必须在以下三轴中**至少选择 2 轴为非默认配置**，确保创新性。

### 三轴定义

| 轴向 | 默认配置 | 非默认选项示例 |
|------|----------|---------------|
| **题材基础轴** | 传统玄幻 | 赛博修真/克苏鲁历史/无限流职场/末世种田/星际武侠/诡秘修仙/数据化末日/神话复苏/高武校园/废土捡漏 |
| **规则限制轴** | 无限制升级 | 代价交换制/寿命修炼法/情绪能量池/因果律束缚/等价交换/记忆献祭/气运借贷/功德兑换/痛苦转化/信仰燃烧 |
| **角色矛盾轴** | 正义主角 vs 邪恶反派 | 双主角理念冲突/反派是主角未来身/全员恶人求生/主角有严重道德缺陷/反派比主角更懂正义/亦正亦邪灰色地带/多重人格内战 |

### 激活示例

**示例 1: 赛博修真 + 寿命修炼 + 反派是主角未来身**

```
题材基础轴：【赛博修真】✅ 非默认
- 传统修真融入赛博朋克元素
- 功法=程序，丹田=服务器，渡劫=系统升级

规则限制轴：【寿命修炼法】✅ 非默认
- 修炼消耗寿命，突破=续命
- 境界越高，寿命消耗越快
- 终极悖论：成仙之日，寿元耗尽

角色矛盾轴：【反派是主角未来身】✅ 非默认
- 最终 BOSS 是主角来自未来的自己
- 反派的理念：阻止主角重蹈覆辙
- 核心冲突：现在的我 vs 未来的我
```

**示例 2: 克苏鲁历史 + 记忆献祭 + 全员恶人**

```
题材基础轴：【克苏鲁历史】✅ 非默认
- 古代中国背景 + 克苏鲁神话
- 修仙=接触不可名状的存在
- 走火入魔=被旧日支配者污染

规则限制轴：【记忆献祭】✅ 非默认
- 每次突破需要献祭记忆
- 境界越高，失去越多
- 最终抉择：成仙还是保留自我

角色矛盾轴：【全员恶人】✅ 非默认
- 没有真正的好人，只有立场不同
- 主角也为达目的不择手段
- 核心冲突：在黑暗中寻找微光
```

### 执行机制

1. **初始化阶段** (`/webnovel-init` Phase 6.5):
   - 生成 5-10 个创意包候选
   - 五维评分筛选 Top 3
   - 用户确认后写入 `idea_bank.json`

2. **大纲规划阶段** (`/webnovel-plan` Phase 2.5):
   - 从 `idea_bank.json` 加载选定创意包
   - 分解到各卷的约束触发点
   - 生成约束继承检查清单

3. **章节写作阶段**:
   - 每章细纲标注涉及的创意约束
   - 写作时确保约束生效

4. **周期性检查** (每 5 章):
   - 三轴混搭是否保持？
   - 反套路是否生效？
   - 镜像对抗是否深化？
   - 是否有设定漂移？

## 二、反套路触发器

### 核心要求

每项目必须预设**至少 3 条反常规规则**，并在关键剧情节点强制触发。

### 反套路库（精选 50 条）

#### 金手指相关

1. **金手指反向操作**: 金手指有严重副作用/需要付出巨大代价/会反噬宿主
2. **开局即满级**: 主角开局无敌但自我封印/被限制/无法使用全部力量
3. **系统/老爷爷有私心**: 金手指提供者有自己的目的，不是纯工具人
4. **系统任务坑爹**: 系统发布的任务看似简单实则危险，或有隐藏条件
5. **反向金手指**: 别人眼中的废柴能力，实则是隐藏的神技
6. **代价前置**: 先付出惨痛代价，再获得力量，而非先获得再付出

#### 反派设计

7. **反派智商在线**: 反派不降智，有完整计划，多次差点成功
8. **反派更懂正义**: 反派的理念在某些角度比主角更合理
9. **最终 BOSS 是自己**: 最终敌人是主角创造的/是主角的未来身/是主角的另一面
10. **反派有苦衷**: 作恶有深层原因（复仇/保护/被迫），增加立体感
11. **反派洗白不彻底**: 即使合作也有保留，随时可能再次对立

#### 感情线

12. **感情线反后宫**: 不是无脑倒贴，而是"互相利用→试探→真香"或"相爱相杀"
13. **女性角色独立**: 女主/女配有独立目标、能力、成长线，不是花瓶或附庸
14. **感情线虐心**: 有误会、分离、牺牲，不是一帆风顺

#### 剧情结构

15. **世界真相反转**: 世界是虚拟程序/书中书/高等文明实验场/轮回副本
16. **配角高光时刻**: 关键战役由配角完成，主角负责布局或善后
17. **打脸延迟满足**: 被轻视后不立即打脸，而是隐忍布局，最终一击必杀
18. **兄弟情考验**: 兄弟/师徒因理念分歧产生冲突，甚至短暂对立
19. **胜利代价惨重**: 即使赢了也失去重要东西（亲人/朋友/记忆/身体部位）
20. **时间线非线性**: 采用倒叙/插叙/多时间线并行，最后汇聚
21. **力量体系有上限**: 不是无限升级，有天花板，后期转向规则/概念战
22. **资源有限竞争**: 不是遍地机缘，资源稀缺，需要争夺、交易、算计
23. **社会规则复杂**: 不是非黑即白，有灰色地带，各方势力博弈
24. **主角不是天选之子**: 靠努力、智慧、运气、牺牲一步步爬上来
25. **结局非大团圆**: 有遗憾、有牺牲，但符合逻辑和情感

#### 穿越/重生

26. **穿越者本土化**: 穿越者不依赖现代知识碾压，而是融入本地规则
27. **重生蝴蝶效应**: 重生改变过去引发连锁反应，有些变好有些变坏

#### 角色塑造

28. **主角被误解**: 长期被世人误解为魔头/叛徒，默默承受
29. **主角有严重缺陷**: 贪婪/好色/自私/懦弱，但有底线，逐步成长
30. **身份错位**: 主角实际身份与表面身份巨大反差（乞丐实为皇子）
31. **敌我同源**: 主角与反派出自同一师门/同一实验/同一血脉
32. **双重人格内战**: 主角体内有两个人格，互相争夺控制权

#### 叙事技巧

33. **多重视角叙事**: 同一事件通过不同角色视角展现，揭示不同真相
34. **不可靠叙述者**: 主角/叙述者有意无意隐瞒或扭曲事实
35. **信息不对称**: 读者知道真相，主角不知道，制造悬念
36. **meta 元素**: 角色意识到自己在小说中，尝试打破第四面墙
37. **平行世界交汇**: 多个平行世界的主角相遇，产生冲突或合作

#### 世界观

38. **世界观层层揭开**: 不是一次性告知，而是像剥洋葱一样层层深入
39. **时间线收束**: 无论怎么改变过去，关键事件必然发生
40. **因果倒置**: 结果先于原因出现，需逆向推导真相
41. **群体意识**: 反派/正派是一个集体意识，非单个个体
42. **维度战争**: 高维生物操控低维世界，主角逐渐察觉
43. **概念具象化**: 抽象概念（时间/死亡/命运）具象化为角色
44. **规则怪谈融合**: 世界存在不可违反的诡异规则，违者必死
45. **文明升维**: 故事主线是整个文明从低维向高维进化

#### 爽点设计

46. **收获具体化**: 不只是"变强了"，明确写出"从 X 级突破到 Y 级，获得 Z 能力，副作用是 W"
47. **代价交换制**: 力量来自邪神/诅咒/禁忌，使用越多越危险
48. **道德困境**: 无论怎么选都会伤害无辜，考验主角价值观

#### 群像设计

49. **群像剧模式**: 多主角多线索并行，最终汇聚成大事件
50. **时间循环困局**: 主角被困在同一天/同一事件，需找出破局方法

### 触发机制

1. **初始化阶段**: 从库中选择至少 3 条，写入 `.webnovel/idea_bank.json`
2. **大纲规划**: 明确标注反套路触发章节
3. **写作执行**: 自动强化该特征，确保读者感受到"不一样"
4. **周期性回顾**: 每 10 章回顾一次反套路执行情况，防止遗忘

## 三、五维评分体系

### 评分维度

每个创意包需通过五维评分（1-10 分）：

| 维度 | 说明 | 评分标准 |
|------|------|---------|
| **新颖度** | 与市面作品的差异化程度 | 10=前所未有，5=略有新意，1=老套 |
| **可行性** | 在 200 万字篇幅内的可持续性 | 10=可贯穿全书，5=可支撑 1 卷，1=一次性 |
| **爽点潜力** | 转化为爽点的容易程度 | 10=天然爽点，5=需铺垫，1=难转化 |
| **情感共鸣** | 引发读者共情的可能性 | 10=强共鸣，5=一般，1=无感 |
| **商业价值** | 付费转化率预测 | 10=高付费点，5=中等，1=低 |

### 评分示例

**创意包：赛博修真 + 寿命修炼 + 反派是主角未来身**

```
新颖度：9/10
- 赛博修真已有但不泛滥
- 寿命修炼法有新意
- 反派是未来身是经典但有效的设定

可行性：8/10
- 赛博修真可支撑多卷
- 寿命限制可制造持续张力
- 未来身设定需要精细布局

爽点潜力：8/10
- 赛博元素可产生视觉爽点
- 寿命倒计时可制造紧张爽点
- 与未来身对决是天然高潮

情感共鸣：7/10
- 寿命代价可引发思考
- 自我对抗有哲学深度
- 可能过于黑暗影响共鸣

商业价值：8/10
- 赛博修真有固定受众
- 爽点密度有保障
- 话题性强利于传播

总分：40/50 ✅ 通过（≥35 分）
```

### 通过标准

**总分 ≥ 35 分** 的创意包方可进入 `.webnovel/idea_bank.json`。

## 五、约束继承机制

### 全流程贯穿

创意约束必须从总纲→分卷纲→章节纲逐级继承，不得丢失。

### 执行流程

1. **总纲阶段**:
   - 确定三轴混搭
   - 确定反套路清单（至少 3 条）
   - 设计镜像对抗

2. **分卷规划**:
   - 将创意约束分解到各卷
   - 明确每卷的重点反套路
   - 标注约束触发点

3. **章节细纲**:
   - 每章细纲需标注本章涉及的创意约束
   - 示例：`本章触发反套路#3：打脸延迟满足`

4. **周期性检查** (`/webnovel-plan` Phase 7):
   - 三轴混搭是否保持？
   - 反套路是否生效？
   - 镜像对抗是否深化？
   - 是否有设定漂移？

### 约束继承检查清单

```markdown
## 约束继承检查报告
```
