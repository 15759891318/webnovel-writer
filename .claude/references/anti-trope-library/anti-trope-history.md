# 历史题材反套路库 (Anti-Trope History)

> **版本**: v6.0
> **目标**: 为历史题材（含历史脑洞）提供反套路设计参考

---

## 一、历史题材反套路清单（20 条）

### 穿越者类

**1. 现代知识非万能**
- **套路**: 靠现代知识碾压古代
- **反套路**: 现代知识在古代水土不服
- **示例**: 主角想造火药，发现没有硫磺矿；想炼钢，温度不够

**2. 穿越者非唯一**
- **套路**: 只有主角一个穿越者
- **反套路**: 还有其他穿越者，甚至形成组织
- **示例**: 主角发现历史上多个名人都是穿越者

**3. 穿越有代价**
- **套路**: 穿越无代价
- **反套路**: 穿越会失去某些东西/被天道限制
- **示例**: 每次改变历史，主角就会失去一段记忆

**4. 历史不可改**
- **套路**: 历史可以随意改变
- **反套路**: 历史有自我修正能力，关键节点无法改变
- **示例**: 主角多次试图救某人，但每次都以不同方式死亡

**5. 身份非显赫**
- **套路**: 穿越成皇子/将军/世家子弟
- **反套路**: 穿越成平民/奴隶/边缘人物
- **示例**: 主角穿越成乞丐，开局一碗破碗

### 历史人物类

**6. 名人非脸谱**
- **套路**: 历史名人是单薄的脸谱
- **反套路**: 历史名人有血有肉，有优点也有缺点
- **示例**: 秦始皇不只是暴君，也有远见和无奈

**7. 反派非 pure evil**
- **套路**: 历史反派 pure evil
- **反套路**: 历史反派有自己的立场和苦衷
- **示例**: 秦桧不是单纯的奸臣，而是主和派代表

**8. 女性非花瓶**
- **套路**: 古代女性是花瓶或附庸
- **反套路**: 古代女性有智慧有能力
- **示例**: 女主是商行之主，商业头脑超过男主

**9. 帝王非全能**
- **套路**: 皇帝为所欲为
- **反套路**: 皇帝也有掣肘，不能随心所欲
- **示例**: 皇帝想改革，但被世家联手抵制

**10. 英雄非完美**
- **套路**: 历史英雄完美无缺
- **反套路**: 英雄也有阴暗面和私心
- **示例**: 民族英雄私下贪污，但不影响其历史功绩

### 社会结构类

**11. 阶级非固定**
- **套路**: 古代阶级固化无法突破
- **反套路**: 阶级可以跨越，但需要付出巨大代价
- **示例**: 主角靠军功爵位制度，从平民晋升为贵族

**12. 改革非顺利**
- **套路**: 主角改革一路顺风
- **反套路**: 改革阻力重重，多次失败
- **示例**: 主角推行的政策被阳奉阴违，执行走样

**13. 科技非速成**
- **套路**: 现代技术直接搬古代
- **反套路**: 工业体系需要积累，无法一蹴而就
- **示例**: 主角想造枪，发现连合格的螺丝钉都造不出来

**14. 文化非落后**
- **套路**: 古代文化落后
- **反套路**: 古代文化有独特价值
- **示例**: 主角发现中医理论在某些方面超越现代医学

**15. 经济非简单**
- **套路**: 古代经济简单，随便赚钱
- **反套路**: 古代经济有复杂规则
- **示例**: 主角想经商，发现要处理各种人情世故

### 历史观类

**16. 历史非线性**
- **套路**: 历史是线性发展的
- **反套路**: 历史是多线并行的
- **示例**: 主角发现历史有多个分支，自己处于其中一个

**17. 文明非单一**
- **套路**: 只有中原文明
- **反套路**: 同时代存在多个文明
- **示例**: 主角出使西域，发现外面还有更大的世界

**18. 真相非唯一**
- **套路**: 历史真相只有一个
- **反套路**: 历史真相有多个版本
- **示例**: 同一事件，史书记载和民间传说完全不同

**19. 穿越非偶然**
- **套路**: 穿越是偶然事件
- **反套路**: 穿越是被安排的
- **示例**: 主角发现穿越是某个存在的计划，自己是棋子

**20. 回归非结局**
- **套路**: 回归现代是大结局
- **反套路**: 回归后发现时间线已变/无法回归
- **示例**: 主角回到现代，发现历史已被自己改变

## 二、非套路爽点设计（15 种）

### 1. 知识降维爽
- **描述**: 主角用现代知识解决古代问题
- **爽感来源**: 认知差
- **示例**: 主角用数学知识破解古代谜题

### 2. 制度碾压爽
- **描述**: 主角用现代制度碾压古代制度
- **爽感来源**: 制度优势
- **示例**: 主角建立的公司制度，效率远超古代商行

### 3. 文化输出爽
- **描述**: 主角向古代输出文化
- **爽感来源**: 文化自信
- **示例**: 主角写的小说在古代大受欢迎

### 4. 技术突破爽
- **描述**: 主角在古代实现技术突破
- **爽感来源**: 创造成就感
- **示例**: 主角成功炼钢，震惊朝野

### 5. 历史改变爽
- **描述**: 主角改变历史走向
- **爽感来源**: 掌控历史
- **示例**: 主角阻止了某场战争，拯救了千万人

### 6. 名臣折服爽
- **描述**: 历史名臣被主角折服
- **爽感来源**: 能力被认可
- **示例**: 萧何/诸葛亮成为主角的追随者

### 7. 帝王器重爽
- **描述**: 皇帝对主角器重有加
- **爽感来源**: 权力认可
- **示例**: 皇帝称主角为"先生"，言听计从

### 8. 百姓爱戴爽
- **描述**: 主角被百姓爱戴
- **爽感来源**: 民心所向
- **示例**: 主角离任时，百姓十里相送

### 9. 商战碾压爽
- **描述**: 主角用现代商业思维碾压古代商人
- **爽感来源**: 思维代差
- **示例**: 主角的营销手段让古代商人目瞪口呆

### 10. 军事指挥爽
- **描述**: 主角指挥古代军队
- **爽感来源**: 掌控千军万马
- **示例**: 主角用现代战术，以少胜多

### 11. 种田发展爽
- **描述**: 主角把穷乡僻壤发展成繁华都市
- **爽感来源**: 养成成就感
- **示例**: 三年时间，小村庄变成大城市

### 12. 名声传播爽
- **描述**: 主角的名声传遍天下
- **爽感来源**: 被认可
- **示例**: 主角的名字成为传奇，街头巷尾都在传颂

### 13. 改变命运爽
- **描述**: 主角改变自己和他人的命运
- **爽感来源**: 掌控命运
- **示例**: 主角让原本会死的亲友活了下来

### 14. 文明推动爽
- **描述**: 主角推动文明进程
- **爽感来源**: 历史创造者
- **示例**: 主角的贡献被写入史书，流传千古

### 15. 双重身份爽
- **描述**: 主角在古代和现代双重身份
- **爽感来源**: 身份反差
- **示例**: 现代是普通人，古代是当朝宰相

## 四、使用建议

### 选择原则

1. **至少选择 3 条反套路** 作为本书核心约束
2. **考虑历史真实性**：越贴近真实历史，读者越容易代入
3. **注意历史禁忌**：不要触碰敏感历史人物和事件
4. **平衡古今观念**：主角的现代观念要和古代环境产生冲突

### 组合建议

**推荐组合 1: 历史修正流**
- 现代知识非万能 + 历史不可改 + 穿越者非唯一 + 历史改变爽

**推荐组合 2: 种田发展流**
- 科技非速成 + 经济非简单 + 文化非落后 + 种田发展爽

**推荐组合 3: 历史名人流**
- 名人非脸谱 + 反派非 pure evil+ 女性非花瓶 + 名臣折服爽

## 五、历史考据建议

### 常用史料

1. **正史**: 史记、汉书、三国志、资治通鉴等
2. **野史**: 各朝笔记、稗官野史
3. **地方志**: 各地府志、县志
4. **专业研究**: 各朝代专题研究论文

### 考据要点

1. **官制**: 官职名称、权力范围、升迁路径
2. **地理**: 地名、疆域、交通路线
3. **风俗**: 礼仪、婚丧、节庆
4. **物价**: 货币、购买力、物价水平
5. **科技**: 当时技术水平、可用材料

### 常见错误

1. **地名穿越**: 在汉代出现唐代的地名
2. **官职穿越**: 在明代出现清代的官职
3. **物品穿越**: 在宋代出现明代才有的物品
4. **称谓错误**: 对不同身份的人使用错误称谓
5. **礼仪错误**: 不符合当时礼仪规范
