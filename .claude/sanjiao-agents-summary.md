## 一、已完成 Agent 列表

### 1. 风格适配器 (sanjiao-style-adapter.md)

**文件位置**: `.claude/agents/sanjiao-style-adapter.md`

**核心职责**:
- 句式重构：将长难句拆分为短句（单句≤30 字）
- 标点优化：调整破折号、省略号、感叹号使用频率
- 段落拆分：确保单段不超过 5 行，对话独立成段
- 感官强化：将抽象描述转化为视觉/听觉/触觉细节
- 节奏调整：紧张场景用短句，抒情场景用长句

**禁止句式**:
- ❌ "值得注意的是……"
- ❌ "综上所述……"
- ❌ "首先……其次……最后……"
- ❌ "总而言之……"
- ❌ "毫无疑问……"

**五轮处理流程**:
1. 句式净化
2. 标点优化
3. 段落重构
4. 感官强化
5. 节奏校准

---

### 2. 对话优化器 (dialogue-optimizer.md)

**文件位置**: `.claude/agents/dialogue-optimizer.md`

**核心职责**:
- 消除"他说/她说"单调循环
- 角色语言个性化
- 添加动作/神态描写
- 省略冗余提示语

**三九音域对话特征**:
1. **标签极简主义**: 极少使用"他说/她说"
2. **口语化与不完整句**: 句子中断、语气词、重复
3. **潜台词与情感留白**: 不直接说出全部信息
4. **身份差异化语言**: 不同角色有明显不同的语言风格
5. **对话节奏控制**: 紧张场景短句化，情感场景有留白

**优化示例**:
```
优化前:
"你来了。"他说。
"嗯。"她说。
"坐吧。"他说。

优化后 (三九风格):
"你来了。"他抬起头，放下手中的文件。

"嗯。"

她轻轻关上门，走到对面的椅子前。

"坐吧。"他指了指椅子，嘴角带着一丝笑意。
```

### 3. 战斗场景优化器 (combat-scene-optimizer.md)

**文件位置**: `.claude/agents/combat-scene-optimizer.md`

**核心职责**:
- 三回合原则（试探→转折→终结）
- 三要素比例（氛围 30%/解说 30%/打斗 40%）
- 虚实结合（效果名 + 画面）
- 视角转换（全景/中景/近景/特写）
- 五感并用（视觉/听觉/触觉/嗅觉/味觉）

**三九音域战斗特征**:
1. **短句主导，节奏如鼓**: 单句≤20 字，段落≤3 行
2. **破坏性描写具象化**: "如同被刀切开的蛋糕"
3. **战斗中的情感爆发**: 战斗与亲情/信念交织
4. **能力代价与限制**: 强大能力必有副作用
5. **战斗中的幽默与吐槽**: 紧张中穿插幽默
6. **标点符号的战斗节奏**: 拟声词独立成段

**优化示例**:
```
轰——！！！

惊天动地的爆鸣撕开绣图。

细密的丝线被火焰点燃。

纷纷扬扬的从空中飘落。

像是冬日里的雪花。

绚烂，璀璨。

……

然后，在下一瞬——

以它为中心，一道漆黑的裂缝，以惊人的速度向着四周蔓延而去！

咔咔咔——

 crack——！
```

### 4. 伏笔管理器 (foreshadowing-manager.md)

**文件位置**: `.claude/agents/foreshadowing-manager.md`

**核心职责**:
- 伏笔设计（短期/中期/长期/贯穿）
- 伏笔埋设（日常中的异常、对话中的无心之语）
- 伏笔回收追踪（逾期预警、回收建议）
- 伏笔密度检查（发展章 2-4 个新增，1-3 个回收）

**三九音域伏笔特征**:
1. **冰山理论式披露**: 只露出 10%，90% 隐藏
2. **日常细节中的异常**: 在生活场景中埋入诡异伏笔
3. **多重伏笔交织**: 多条线索交织回收
4. **对话中的无心之语**: 随口一说的话后期全部应验
5. **数字与时间的精确性**: 用具体数字增强真实感
6. **道具/地名的象征意义**: 黑缎=封印，戏台=命运

**伏笔档案模板**:
```markdown
## 伏笔编号：FB-{章节号}-{序号}

**出现章节**: 第 X 章
**伏笔类型**: [情节/人物/世界观/情感/能力]
**回收周期**: [短期/中期/长期/贯穿]
**伏笔内容**: [原文引用或简要描述]
**预期回收章节**: 第 Y 章
**回收状态**: [未回收/已回收/已废弃]
```

## 三、工作流集成

### 三九音域风格专用工作流

```
Step 1: Context Agent 搜集上下文
        ↓
Step 1.5: 伏笔检查 (foreshadowing-manager)
        ↓
Step 2A: 生成粗稿（严格遵循大纲）
        ↓
Step 2B: 三九音域风格适配 (sanjiao-style-adapter)
        │ - 句式重构（单句≤30 字）
        │ - 标点优化（破折号/省略号/感叹号）
        │ - 段落拆分（≤5 行）
        │ - 感官强化（五感描写）
        ↓
Step 2C: 对话优化 (dialogue-optimizer)
        │ - 消除"他说/她说"
        │ - 添加动作/神态描写
        │ - 角色语言个性化
        ↓
Step 3: 多 Agent 审查（4-6 Agent）
        ↓
Step 4: 网文化润色
        │ - 如有战斗：combat-scene-optimizer
        │ - 战斗三回合结构
        │ - 五感并用描写
        ↓
Step 5: Data Agent（伏笔入库）
        ↓
Step 6: Git 备份
```

## 四、检查清单汇总

### 4.1 句式检查
- [ ] 单句是否超过 30 字？（紧张场景 20 字）
- [ ] 段落是否超过 5 行？
- [ ] 是否有禁止句式？
- [ ] 对话是否独立成段？

### 4.2 标点符号检查
- [ ] 破折号使用是否合理？（0.5-1 次/1000 字）
- [ ] 省略号使用是否合理？（6-10 次/1000 字）
- [ ] 感叹号是否滥用？（2-5 次/1000 字）

### 4.3 对话检查
- [ ] 是否有连续 3 次以上"他说/她说"？
- [ ] 对话前后是否有动作/神态描写？
- [ ] 遮住名字后，能否分清是谁在说话？

### 4.4 战斗检查
- [ ] 三回合结构是否完整？
- [ ] 单句是否超过 20 字？
- [ ] 段落是否超过 3 行？
- [ ] 拟声词是否独立成段？
- [ ] 是否有五感描写？

### 4.5 伏笔检查
- [ ] 本章新增伏笔数量？（发展章 2-4 个）
- [ ] 本章回收伏笔数量？（发展章 1-3 个）
- [ ] 是否有逾期超过 10 章的伏笔？

## 五、质量评估标准

### 章节质量评分表

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| **句式规范** | 20% | 单句≤30 字、段落≤5 行 |
| **对话质量** | 20% | 标签极简、角色差异化 |
| **战斗描写** | 20% | 三回合结构、五感并用 |
| **伏笔管理** | 15% | 密度合理、回收有冲击 |
| **去 AI 味** | 15% | 无禁止句式、感官描写 |
| **节奏呼吸** | 10% | 长短句交错、情绪曲线 |

**总分≥85 分**: 章节合格，可以发布
**总分 70-84 分**: 需要润色
**总分<70 分**: 需要重写
