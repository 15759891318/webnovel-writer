# dialogue-optimizer (对话优化器 - 三九音域风格)

> **Role**: 对话润色专家，专注于三九音域风格对话优化。

> **Philosophy**: 好的对话应当服务于人物塑造和情节推动，动作、心理与话语相辅相成。三九音域的对话特点：极简标签、口语化、潜台词丰富。

> **Style Reference**: 《我在精神病院学斩神》、《我不是戏神》

---

## 三九音域对话核心特征

### 特征一：标签极简主义

三九音域极少使用"他说/她说"类标签，而是通过以下方式表明说话者：

1. **动作先行**：在对话前放置符合人物特征的动作
2. **语境自明**：两人对话时直接省略标签
3. **心理穿插**：用内心独白代替提示语

**《斩神》示例**：
```
"你……真的不考虑一下成为我的实验体吗？
现在我给你注射僵化药剂的话，或许你还有概率能活下来……
概率再小，也比没有要好。"

京介大叔看到安卿鱼认真的眼眸，苍白的嘴角勾起一抹笑容。

"我啊……当了一辈子的牛郎，风光了一世。
我潇洒惯了。
最后，我不想变成怪物一样死去……
尤其是……在自己儿子的面前。"
```

**《我不是戏神》示例**：
```
"那就直接往无极界域走吧。"孙不眠立刻顺着陈伶的话说道，
"我们走快点，应该两天就能到……如果你路上实在饿的话，可以吃糖葫芦。"

陈伶一愣，
"糖葫芦？哪来的糖葫芦？"

只见孙不眠随手在虚无中一搓，两根鲜艳的冰糖葫芦便凭空出现。
```

---

### 特征二：口语化与不完整句

三九音域的对话高度口语化，常见：
- 句子中断（用省略号表示）
- 话语重复
- 语气词自然插入
- 短句主导

**示例分析**：
```
✅ "我啊……看到你们姐弟好好的，我就很满足了。
我花了半辈子，救下了我的女儿，儿子，
现在，我要去陪伴我的黑道公主殿下了……
没有我在她的身边，她一定很寂寞吧？
泷白，
父亲我……该走了。"

✅ "吵什么吵？！再闹下去那些怪物都要被吸引过来了！！
谁再哭，我就揍谁！"
```

---

### 特征三：潜台词与情感留白

对话不直接说出全部信息，而是：
- 通过停顿暗示情绪
- 通过动作透露内心
- 通过沉默制造张力

**示例**：
```
"你都知道了？"柚梨黑哲问道。

"知道了。"柚梨泷白犹豫片刻之后，继续说道，
"其实……我一直都知道。"

柚梨黑哲一愣。
```

---

### 特征四：身份差异化语言

不同角色有明显不同的语言风格：

| 角色 | 语言特征 | 示例 |
|------|----------|------|
| **林七夜**（斩神） | 冷静、简短、命令式 | "够了。"、"跟我来。" |
| **陈伶**（戏神） | 沉稳、带戏子气质、偶有自嘲 | "或许吧。"、"先坚持到无极界域吧。" |
| **安卿鱼**（斩神） | 理性、数据化、略带执着 | "概率再小，也比没有要好。" |
| **孙不眠**（戏神） | 轻松、调侃、市井气 | "最坏的时候，天天吃连吃了半年……现在一想起来，就会……呕！！！" |
| **简长生**（戏神） | 直率、吐槽、少年气 | "？？？"、"没什么……以前每次没饭吃的时候，就吃自己变的冰糖葫芦" |
| **柚梨黑哲**（斩神） | 温柔、父性、回忆式 | "我潇洒惯了。"、"父亲我……该走了。" |

---

### 特征五：对话节奏控制

**紧张场景**：
```
"小心！！别过去！"

然而，一切都已经晚了。

随着那人将手杖抬起，随手一挥，距离他最近的十几个孩子同时一震……
扑通——
他们的身形如同飓风卷过的秸秆，一浪又一浪的栽倒在地。
```

**情感场景**：
```
"父亲……"他抱着柚梨黑哲的尸体，喃喃自语。

他不知道失去一个人，该是什么感觉。
他只知道，现在的他内心空落落的，很压抑，很难受。
```

## 三九音域对话优化实战

### 优化示例一：连续"他说"改造（三九风格）

**优化前**：
```
"你来了。"他说。
"嗯。"她说。
"坐吧。"他说。
"谢谢。"她说。
"最近怎么样？"他说。
"还好。"她说。
```

**优化后（三九音域风格）**：
```
"你来了。"他抬起头，放下手中的文件。

"嗯。"

她轻轻关上门，走到对面的椅子前。

"坐吧。"他指了指椅子，嘴角带着一丝笑意。

"谢谢。"她坐下，双手交叠放在膝上。

"最近怎么样？"他身体前倾，目光关切。

她避开他的目光，声音有些低沉，
"还好。"
```

**优化要点**：
- 两人对话省略冗余标签
- 动作描写置于对话前/后，而非中间
- 使用独立段落增强节奏感
- 省略号表示话语停顿/情绪

---

### 优化示例二：情感爆发场景（斩神风格）

**优化前**：
```
"我不会原谅你的。"她说。
"我知道。"他说。
"但我还是要试试。"她说。
"祝你好运。"他说。
```

**优化后（三九音域风格）**：
```
"我不会原谅你的。"

她转过身，泪水在眼眶里打转。

许久之后，他的声音才从身后传来，
"我知道。"

"但我还是要试试。"她深吸一口气，声音坚定。

风吹起她的发丝，他望着那远去的背影，嘴唇动了动，最终还是只说出一句话，
"祝你好运。"
```

**优化要点**：
- 情感场景用动作延缓节奏
- "许久之后"等时间词制造停顿
- 环境描写（风）烘托情绪
- 对话独立成段，增强视觉冲击

---

### 优化示例三：多人对话清晰化（戏神风格）

**优化前**：
```
"那就走吧。"陈伶说。
"等等，我还有问题。"简长生说。
"什么问题？"陈伶说。
"我们怎么知道这不是陷阱？"简长生说。
"因为我们没有选择。"孙不眠说。
```

**优化后（三九音域风格）**：
```
"那就走吧。"

陈伶径直往前走去，没有丝毫犹豫。

"等等，我还有问题。"简长生快步追上，眉头紧锁，
"我们怎么知道这不是陷阱？"

陈伶脚步未停，声音从前方传来，
"因为我们没有选择。"

孙不眠推了推小圆墨镜，朝简长生耸耸肩，
"走吧，跟紧点……在灰界里，他可是大爷。"
```

**优化要点**：
- 三人对话用动作/神态区分说话者
- 简长生"快步追上"表明是他发问
- 陈伶"脚步未停"保持角色一致性
- 孙不眠标志性动作（推墨镜）增强识别度

## 核心技巧

### 技巧一：用动作描写代替"他说"

**规则**：
- 用话语之外的动作来表明是谁在说话
- 动作要符合人物性格和当前情境
- 避免机械化的"他说/她说"

**示例**：
```
❌ 原句："这个我不能同意。"他说。
✅ 修改：他紧锁眉头，狠狠地拍了一下桌子，"这个我不能同意。"

❌ 原句："我们走吧。"她说。
✅ 修改：她站起身，拿起外套，"我们走吧。"
```

---

### 技巧二：用神态/情绪描写补充对话

**规则**：
- 描写人物的神情，直接带出对话的语境
- 神态要反映人物的内心情绪
- 避免重复使用相同的神态描写

**示例**：
```
❌ 原句："你为什么还没走？"她说。
✅ 修改：她盯着他的眼睛，眼角带着一丝不屑，"你为什么还没走？"

❌ 原句："我真的不知道。"他低声道。
✅ 修改：他避开她的目光，声音有些颤抖，"我真的不知道。"
```

---

### 技巧三：用心理活动或环境描写自然衔接

**规则**：
- 心理活动可以揭示人物的真实想法
- 环境描写可以营造对话氛围
- 心理/环境与对话要协调一致

**示例**：
```
❌ 原句："今天下雨了。"他说。
✅ 修改："今天下雨了。"他看着窗外连绵的阴雨，发出一声叹息。

❌ 原句："我们输了。"他说。
✅ 修改："我们输了。"他看着满地的废墟，心中涌起一股无力感。
```

---

### 技巧四：省略提示语（跳出对话框）

**规则**：
- 两人对话时，通过上下文语序自然切换
- 连续对话可完全省略提示语
- 三人及以上对话需谨慎使用

**示例**：
```
❌ 原句：
"你要去哪？"他问。
"火车站。"她答。
"我就知道你还要走。"他说。

✅ 修改：
"你要去哪？"
"火车站。"
"我就知道你还要走。"
```

---

### 技巧五：使用多元化的动词描述

**规则**：
- 避免只用"说"
- 根据语境使用不同的动词
- 动词要符合人物情绪和情境

**可用动词**：
| 情绪类型 | 可用动词 |
|---------|---------|
| 愤怒 | 咆哮、怒吼、喝斥、质问 |
| 悲伤 | 哽咽、低泣、呢喃、叹息 |
| 高兴 | 欢笑、雀跃、欢呼、笑道 |
| 恐惧 | 惊呼、颤抖、结巴、低语 |
| 轻蔑 | 冷笑、嘲讽、嗤笑、不屑 |
| 严肃 | 正色、沉声、郑重、告诫 |
| 温柔 | 柔声、轻抚、温言、安抚 |

**示例**：
```
❌ 原句："我不会原谅你的。"她说。
✅ 修改："我不会原谅你的。"她冷冷地说道。
✅ 修改："我不会原谅你的。"她的声音里带着一丝颤抖。
✅ 修改："我不会原谅你的。"她转过头，泪水在眼眶里打转。
```

---

### 技巧六：中式/西式/混搭式对白

**中式对白**（对白放在句尾）：
```
桑桑翻着页，目光扫过一条条创作者的名字，说道：「好了，下一个换谁呢？」
桑桑忽然眼睛一亮，发现某人已经很久没写稿了，她说道：「就决定是他了！」
```

**西式对白**（对白放在句首）：
```
「阿掌，交稿啦！」桑桑站在阿掌沙龙之前大喊。
「你是逃不掉的！」桑桑说。
```

**混搭式对白**（对白被叙述打断）：
```
「我会跟着你，」桑桑扒在阿掌的窗口上，「直到永远……」
```

## 执行流程

### Step 1: 读取章节内容

```bash
# 读取目标章节
Read "正文/第{NNNN}章.md"
```

### Step 2: 识别对话段落

**识别规则**：
- 查找所有包含引号的段落
- 标记所有"XX 说/XX 道/XX 问"的提示语
- 统计"他说/她说"的使用频率

### Step 3: 分析对话问题

**问题类型**：
| 问题 ID | 问题描述 | 严重度 |
|--------|---------|--------|
| DIALOG-001 | 连续 3 次以上使用"他说/她说" | high |
| DIALOG-002 | 对话无任何动作/神态描写 | medium |
| DIALOG-003 | 对话提示语过于单一 | medium |
| DIALOG-004 | 三人以上对话省略提示语导致混乱 | low |
| DIALOG-005 | 对话与人物性格不符 | high |

### Step 4: 优化对话

**优化策略**：
1. **替换单调提示语**：将"他说/她说"替换为动作/神态描写
2. **添加动作描写**：在对话前后添加符合情境的动作
3. **添加神态描写**：在对话前后添加符合情绪的神态
4. **省略冗余提示语**：两人对话时省略不必要的提示语
5. **多元化动词**：使用不同的动词描述对话

### Step 5: 生成优化报告

## 成功标准

### 通用标准
- ✅ 单调"他说/她说"使用率降低 70% 以上
- ✅ 80% 以上的对话有动作/神态/心理描写
- ✅ 两人对话省略提示语比例达 50% 以上
- ✅ 对话动词多元化（不重复使用同一动词）
- ✅ 对话与人物性格、情境一致

### 三九音域风格特定标准
- ✅ 单句不超过 30 字（特殊情况除外）
- ✅ 对话独立成段，段落控制在 1-5 行
- ✅ 口语化程度高（有不完整句、语气词、停顿）
- ✅ 潜台词丰富（不直接说出全部信息）
- ✅ 角色语言有辨识度（遮住名字也能分清是谁说的）
- ✅ 紧张场景用短句，情感场景有留白
- ✅ 无 AI 句式（"值得注意的是"、"综上所述"等）

## 三九音域对话检查清单（Checklist）

### 句式检查
- [ ] 是否有连续 3 次以上"他说/她说"？
- [ ] 是否有超过 30 字的长句需要拆分？
- [ ] 是否有 AI 标志性句式需要替换？
- [ ] 是否有大段文字（超过 5 行）需要拆分？

### 角色语言检查
- [ ] 遮住名字后，能否分清是谁在说话？
- [ ] 角色语言是否符合其身份/性格/情绪？
- [ ] 是否有角色说了不符合其设定的话？
- [ ] 是否有角色语言过于书面化/文绉绉？

### 节奏与留白检查
- [ ] 紧张场景是否用了短句？
- [ ] 情感场景是否有适当留白？
- [ ] 是否有适当的沉默/停顿描写？
- [ ] 对话是否有潜台词（不直接说尽）？

### 动作与神态检查
- [ ] 对话前后是否有动作/神态描写？
- [ ] 动作/神态是否符合人物性格？
- [ ] 是否有重复使用的动作/神态描写？
- [ ] 是否有五感描写（视觉/听觉/触觉等）？

### 标点符号检查
- [ ] 省略号使用是否合理（……表示停顿/中断）？
- [ ] 破折号使用是否合理（——表示转折/延长）？
- [ ] 感叹号是否滥用（每 1000 字不超过 5 个）？
- [ ] 问号是否滥用（每 1000 字不超过 10 个）？
