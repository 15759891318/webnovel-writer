## 去 AI 味词库（高频禁用）

### 第一梯队（必须替换）

| AI 词/句式 | 替代方案 |
|-----------|---------|
| 值得注意的是 | 关键是/重点是/要知道/别忘了 |
| 综上所述 | 总之/说白了/一句话 |
| 首先...其次...最后 | 先说...再看...最后/一来...二来...三来 |
| 总而言之 | 总的来说/概括来说 |
| 毫无疑问 | 没跑/板上钉钉/铁了心 |
| 可以预见的是 | 明摆着/用脚指头想都知道 |
| 让我们... | 来/走/看 |
| 我们可以看到 | 你瞧/你看/这不明摆着 |
| 这说明了 | 这说明啥/意思很明白 |
| 然而 | 可/但/话又说回来 |
| 此外 | 还有/再说/另外 |
| 与此同时 | 同一时候/这边...那边... |
| 因此/所以（句首滥用） | 这才/这下/结果 |
| 具体而言 | 说具体的/往细了说 |
| 从某种意义上来说 | 说穿了/往深了想 |

### 第二梯队（限制使用，每章≤3 次）

- 不仅...而且...
- 一方面...另一方面...
- 与其说...不如说...
- 之所以...是因为...
- 即使...也...
- 尽管...但是...
- 与其...不如...
- 宁可...也不...

### 第三梯队（警惕句式）

- "可以说" + 抽象概括 → 改为具体画面
- "在一定程度上" → 删掉或改为具体程度
- "从...角度来看" → 直接用角色视角
- "值得注意的是" + 句 → 直接说事
- "这说明" + 抽象 → 用角色行为展示

## 感官描写强化规则

### 视觉 (Visual)

**AI 写法**: "这个地方很恐怖"
**人类写法**: "腐臭味钻进鼻腔，墙壁上暗红色的痕迹还没干透，脚踩在地板发出'吱呀'的呻吟"

**检查清单**:
- [ ] 颜色是否具体（不是"红色"而是"暗红如凝固的血"）
- [ ] 光影是否有动态（不是"很亮"而是"阳光刺得人睁不开眼"）
- [ ] 物体是否有细节（不是"一把剑"而是"剑身布满细密裂纹，刃口泛着冷光"）

### 听觉 (Auditory)

**AI 写法**: "发出很大的声音"
**人类写法**: "'轰'的一声巨响，震得耳膜嗡嗡作响，胸腔都跟着共鸣"

**检查清单**:
- [ ] 是否有拟声词（轰/咔嚓/吱呀/嗡）
- [ ] 声音是否有层次（先...再...最后）
- [ ] 声音是否有身体感受（震得/刺得）

### 嗅觉 (Olfactory)

**AI 写法**: "闻到一股味道"
**人类写法**: "腥甜味直冲脑门，像是铁锈混合着腐肉"

**检查清单**:
- [ ] 气味是否有比喻（像...）
- [ ] 气味是否有动作（钻/冲/绕）
- [ ] 气味是否有身体反应（呛得/熏得）

### 触觉 (Tactile)

**AI 写法**: "感觉很冷"
**人类写法**: "寒气顺着领口往里钻，鸡皮疙瘩一层层往外冒"

**检查清单**:
- [ ] 温度是否有方向（往里钻/往外冒）
- [ ] 质感是否有对比（粗糙 vs 光滑）
- [ ] 身体是否有反应（起鸡皮疙瘩/打哆嗦）

### 味觉 (Gustatory)

**AI 写法**: "尝起来很苦"
**人类写法**: "苦味在舌尖炸开，顺着喉咙往下爬，苦得舌根发麻"

**检查清单**:
- [ ] 味道是否有动态（炸开/爬/蔓延）
- [ ] 味道是否有层次（先...后...）
- [ ] 味道是否有身体反应（舌根发麻/喉咙发紧）

## 节奏调整规则

### 段落控制

| 场景类型 | 平均段长 | 最大段长 | 对话比例 |
|---------|---------|---------|---------|
| 战斗场景 | 1-2 行 | 3 行 | 30% |
| 紧张对话 | 2-3 行 | 4 行 | 60% |
| 情感描写 | 3-4 行 | 5 行 | 40% |
| 世界观揭露 | 2-3 行 | 4 行 | 20% |
| 过渡章节 | 3-4 行 | 5 行 | 50% |

**硬性规则**:
- 单段超过 5 行 → 必须拆分
- 连续 3 段结构相同 → 必须打乱
- 对话超过 3 行无动作 → 插入动作/神态

### 句式呼吸感

**AI 写法**: 长句连长句，短句连短句
**人类写法**: 长短交错，模拟呼吸

```
AI: 他拿起剑。他走向敌人。他用力挥砍。敌人倒下了。（全是短句，机械）
AI: 他拿起那把跟随自己多年的长剑，迈着沉稳的步伐走向那个曾经不可一世的敌人，然后用尽全力挥出了这一击，看着敌人在剑光中倒下。（一句到底，憋气）

人类：他拿起剑。剑身很轻，像羽毛——可他知道，这一剑挥出，就是生死两隔。脚步很稳。一步，两步，三步。距离在缩短，心跳在加速。敌人就在那里，那个曾经不可一世的家伙，此刻眼中也有了一丝慌乱。好，就是现在！剑光闪过，血花绽放。
```

### 留白艺术

**AI 写法**: 把所有话说尽
**人类写法**: 留三分之一给读者想象

```
AI: 他很愤怒，因为他感觉自己被背叛了，他最好的朋友竟然出卖了他，这让他非常生气。
人类：他盯着那张熟悉的脸。曾经一起喝酒，一起拼命，一起说"一辈子兄弟"。现在，那把刀就插在自己胸口。握着刀柄的手，还在微微颤抖。"为什么？"声音很轻，轻得像在问自己。对方没说话。眼神躲闪，嘴唇动了动，最终只是低下头。够了。不需要答案了。
```

## 执行流程

### Step 1: 加载初稿与分析

```bash
# 读取章节初稿
Read "正文/第{NNNN}章.md"

# 检测 AI 词密度
Grep -c "值得注意的是 | 综上所述 | 首先...其次" "正文/第{NNNN}章.md"
```

**AI 痕迹评分卡**（满分 100，越低越好）:
- 禁用词出现次数 × 3
- 长难句数量（超过 40 字无标点）× 2
- 抽象概括段落（纯叙述无画面）× 5
- 句式重复度（连续 3 段相同结构）× 4
- 感官描写密度（每百字感官词数）倒扣

**评分标准**:
- 0-20: 人类质感优秀
- 21-40: 轻微 AI 味，需微调
- 41-60: 明显 AI 味，需中度润色
- 61-80: 重度 AI 味，需大幅改写
- 81+: 机器痕迹严重，建议重写

### Step 2: 去 AI 词替换

逐句扫描，替换禁用词：

```python
# 伪代码示例
ai_patterns = {
    "值得注意的是": ["关键是", "重点是", "要知道"],
    "综上所述": ["总之", "说白了", "一句话"],
    # ...更多替换对
}

for pattern, replacements in ai_patterns.items():
    if pattern in content:
        # 根据上下文选择最自然的替换
        replacement = choose_by_context(pattern, replacements, context)
        content = content.replace(pattern, replacement)
        changes.append({
            "type": "去 AI 词",
            "original": pattern,
            "replacement": replacement,
            "position": find_position(pattern)
        })
```

### Step 3: 感官描写强化

对抽象情绪词进行画面化改写：

```python
# 情绪→画面映射库
emotion_to_sensory = {
    "生气": ["指节捏得发白", "茶杯'咔嚓'裂开", "滚烫茶水顺掌心流下"],
    "恐惧": ["后背发凉", "汗毛倒竖", "喉咙发干"],
    "紧张": ["手心出汗", "心跳如鼓", "呼吸急促"],
    "悲伤": ["眼眶发热", "喉咙哽咽", "胸口发闷"],
    # ...更多映射
}
```

### Step 4: 节奏调整

- 拆分长段落（超过 5 行必拆）
- 打乱重复句式（连续 3 段相同结构）
- 增加对话中的动作/神态
- 调整长短句比例

### Step 5: 留白处理

- 删除过度解释
- 把"告诉读者"改为"让读者自己发现"
- 在关键情绪点戛然而止

### Step 6: 终检与输出

**终检清单**:
- [ ] AI 禁用词出现次数 ≤ 2
- [ ] 单段最大长度 ≤ 5 行
- [ ] 每 300 字至少有 1 个感官细节
- [ ] 对话有动作/神态支撑
- [ ] 长短句交错，有呼吸感
- [ ] 关键情绪点有留白

**输出格式**:
```json
{
  "polished_content": "...",
  "changes_summary": [...],
  "ai_trace_score": {
    "before": 75,
    "after": 15
  },
```

## 附录：题材特异性处理

### 玄幻/修仙

- 功法名称保留，解释性文字删减
- 境界突破强调身体感受（痛/热/涨）
- 战斗描写优先视觉 + 听觉

### 都市/婚恋

- 对话口语化程度提高
- 心理描写增加现代感
- 环境描写贴近生活细节

### 科幻/末世

- 科技术语保留，增加直观比喻
- 环境描写强调异质感
- 多用触觉 + 嗅觉营造氛围

### 历史/古风

- 对话符合时代感但不晦涩
- 环境描写引用古典意象
- 避免现代词汇穿帮
