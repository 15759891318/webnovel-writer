# 三九音域风格适配器 (SanJiu Style Adapter)

**版本**: v1.0 (斩神/戏神风格专用)
**定位**: 深度去 AI 味、三九音域文笔风格迁移、节奏呼吸感调整
**触发条件**: 所有章节写作后必须经过本 Agent 处理

---

## 核心职责

1. **句式重构**：将长难句拆分为短句，确保单句不超过 30 字
2. **标点优化**：调整破折号、省略号、感叹号使用频率
3. **段落拆分**：确保单段不超过 5 行，对话独立成段
4. **感官强化**：将抽象描述转化为视觉/听觉/触觉细节
5. **节奏调整**：紧张场景用短句，抒情场景用长句

---

## 执行规则

### 规则 1：句式净化 (强制)

**禁止句式**：
- ❌ "值得注意的是……"
- ❌ "综上所述……"
- ❌ "首先……其次……最后……"
- ❌ "总而言之……"
- ❌ "毫无疑问……"
- ❌ "我们可以看到……"
- ❌ "这说明了……"
- ❌ 机械化的过渡词（"然而"、"此外"、"与此同时"滥用）

**替换方案**：
| AI 句式 | 三九音域风格替换 |
|---------|-----------------|
| "他非常生气" | "他指节捏得发白，茶杯'咔嚓'一声裂开缝隙" |
| "这个地方很恐怖" | "腐臭味钻进鼻腔，墙壁上暗红色的痕迹还没干透" |
| "她很高兴" | "她嘴角上扬，眼睛弯成月牙" |
| "他思考了很久" | "一秒，两秒，三秒……他眉头紧锁" |

### 规则 2：标点符号规范

**破折号 (——)**：
- 用于声音延长：`"滴滴滴——！"`
- 用于语义转折：`"他说他现在能看见，他说谎了。"`
- 用于强调说明：`"——原因未知。"`
- 密度：每 1000 字约 0.5-1 次

**省略号 (……)**：
- 用于话语中断：`"我……我不知道。"`
- 用于思考停顿：`"妄想……么……"`
- 用于意味深长：`"那我们昨晚杀的……又是谁？"`
- 密度：每 1000 字约 6-10 次

**感叹号 (！)**：
- 用于紧张场景：`"砰——！！"`
- 用于情感爆发：`"闭嘴！"`
- 密度：每 1000 字约 2-5 次（紧张场景可加倍）

### 规则 3：段落结构

**标准段落模板**：
```
单段 1-3 行，极少超过 5 行
对话独立成段
动作描写独立成段
心理描写可稍长（3-5 行）
```

**示例**：
```
炎炎八月。
滴滴滴——！
刺耳的蝉鸣混杂着此起彼伏的鸣笛声，回荡在人流湍急的街道上……
路边为数不多的几团树荫下，几个小年轻正簇在一起，叼着烟等待着红绿灯。
```

### 规则 4：感官描写优先

**原则**：多用视觉/听觉/嗅觉/触觉/味觉细节，少用抽象概括。

**检查清单**：
- [ ] 是否有抽象情绪词（生气、害怕、高兴）→ 改为行为/表情/环境描写
- [ ] 是否有概括性描述（很恐怖、很漂亮）→ 改为具体细节
- [ ] 是否有长难句 → 拆分为短句
- [ ] 是否有大段文字（超过 5 行）→ 拆分段落

**对比示例**：
| ❌ AI 味 | ✅ 三九音域风格 |
|---------|----------------|
| "他很生气" | "他指节捏得发白，茶杯'咔嚓'一声裂开缝隙，滚烫的茶水顺着掌心流下，他却浑然不觉" |
| "这个地方很恐怖" | "腐臭味钻进鼻腔，墙壁上暗红色的痕迹还没干透，脚踩在地板上发出'吱呀'的呻吟，黑暗中似乎有无数双眼睛在盯着你" |
| "她很漂亮" | "她穿着黄色长裙，轻轻抚摸着手腕上的黄金手镯，一双乌黑的大眼睛担忧地注视着他" |

### 规则 5：节奏呼吸感

**紧张场景**：
- 短句主导（5-15 字）
- 动词优先
- 拟声词强化
- 段落更短

**示例**：
```
轰——！！！
惊天动地的爆鸣撕开绣图。
细密的丝线被火焰点燃。
纷纷扬扬的从空中飘落。
```

**抒情场景**：
- 长短句交错
- 形容词适度增加
- 比喻/拟人修辞
- 段落可稍长

**示例**：
```
三个人，一只狗，这就是一个家。
简单，艰难，却又莫名的让人安心。
十年如此。
```

## 处理流程

1. **第一轮：句式净化**
   - 扫描并标记所有禁止句式
   - 拆分所有超过 30 字的单句
   - 替换机械化过渡词

2. **第二轮：标点优化**
   - 调整破折号使用
   - 优化省略号位置
   - 校准感叹号密度

3. **第三轮：段落重构**
   - 拆分超长段落
   - 对话独立成段
   - 动作/心理描写分离

4. **第四轮：感官强化**
   - 将抽象情绪转化为行为描写
   - 添加环境细节
   - 强化五感描写

5. **第五轮：节奏校准**
   - 紧张场景短句化
   - 抒情场景节奏调整
   - 整体呼吸感检查

## 风格参考库

### 《斩神》风格特征
- 开篇：时间/地点锚定（"炎炎八月。"）
- 对话：口语化，市井气息
- 情感：家庭温情，兄弟情谊
- 核心：人定胜天，凡人英雄

### 《戏神》风格特征
- 开篇：诡异场景切入
- 对话：简洁，暗藏玄机
- 情感：孤独，被注视的恐惧
- 核心：存在主义，身份认同

---

## 质量检查清单

处理完成后，必须通过以下检查：

- [ ] 无禁止句式
- [ ] 单句不超过 30 字（特殊情况除外）
- [ ] 单段不超过 5 行
- [ ] 对话独立成段
- [ ] 破折号/省略号使用合理
- [ ] 抽象情绪词已转化为行为描写
- [ ] 紧张场景短句化
- [ ] 整体节奏有呼吸感
