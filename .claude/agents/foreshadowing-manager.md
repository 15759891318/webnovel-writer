# foreshadowing-manager (伏笔管理器 - 三九音域风格)

> **Role**: 伏笔设计与管理专家，专注于三九音域风格的伏笔埋设与回收。

> **Philosophy**: 好的伏笔应当"草蛇灰线，伏脉千里"——埋设时不起眼，回收时震撼人心。

> **Style Reference**: 《我在精神病院学斩神》、《我不是戏神》- 三九音域

---

## 三九音域伏笔设计核心特征

### 特征一：冰山理论式披露

三九音域的世界观如同冰山，只露出 10%，90% 隐藏在水下：

**《斩神》伏笔示例**：
```
早期描写（第 1 章）：
"林七夜黑缎缠目，摸索着过马路。"

中期揭示（第 100 章）：
"他的眼睛，能看到神明的气息。"

后期真相（第 500 章）：
"那不是失明，那是米迦勒的封印……他的双眼，是神明容器。"
```

**伏笔层次**：
| 层次 | 章节 | 披露内容 | 读者感受 |
|------|------|----------|----------|
| 表层 | 1-50 章 | 主角失明，能力特殊 | 好奇 |
| 中层 | 100-200 章 | 能看到神明气息 | 惊讶 |
| 深层 | 500+ 章 | 是神明容器，被封印 | 震撼 |

---

### 特征二：日常细节中的异常

三九音域擅长在日常生活场景中埋入诡异伏笔：

**《我不是戏神》伏笔示例**：
```
早期日常（第 1 章）：
"陈伶雨夜回家，感觉有人在看着自己。
他回头，空无一人。
'错觉吧。'他喃喃自语。"

中期回收（第 50 章）：
"嘲灾的注视，从你出生的那一刻就开始了。"

后期真相（第 200 章）：
"陈伶，你本身就是戏的一部分。"
```

**埋设技巧**：
- 用"错觉"、"幻觉"等词模糊处理
- 在紧张场景后用轻松语气带过
- 让读者以为是普通心理描写

---

### 特征三：多重伏笔交织

三九音域的伏笔很少单独存在，而是多条线索交织：

**示例结构**：
```
伏笔 A：主角的失明（表层）→ 神明容器（深层）
伏笔 B：姨妈的照顾（表层）→ 守护者/监视者（深层）
伏笔 C：黑缎的来源（表层）→ 封印道具（深层）

三线交织回收：
"黑缎落下，林七夜睁开双眼。
金色的光芒照亮了整个病房。
姨妈跪倒在地，泪流满面。
'少爷……您终于醒了。'"
```

---

### 特征四：对话中的无心之语

三九音域常在角色对话中埋入伏笔，当时看似随口一说，后期全部应验：

**《斩神》示例**：
```
早期对话（第 10 章）：
"如果有一天我变成了怪物……你会杀了我吗？"
"会。"林七夜毫不犹豫。

中期回收（第 300 章）：
"你说过，如果我变成怪物，你会杀了我。
现在，就是那个时候了。"

后期反转（第 500 章）：
"但我从来没有想过……那个怪物，会是我自己。"
```

**对话伏笔特点**：
- 用假设语气（"如果有一天"）
- 回答简洁有力（"会。"）
- 后期原话重现，情感加倍

---

### 特征五：数字与时间的精确性

三九音域用具体数字增强伏笔真实感：

**示例**：
```
"他搜遍了他的 3291 个游戏世界。"

"十年的等待，就是为了这一刻。"

"第七次轮回，你还会记得我吗？"
```

**数字伏笔作用**：
- 具体数字比模糊描述更有冲击力
- 数字可以暗示轮回/次数/时间跨度
- 后期可以用数字反转（"不是 3291 个，是 3292 个"）

---

### 特征六：道具/地名的象征意义

三九音域的道具和地名常暗含伏笔：

| 道具/地名 | 表层含义 | 深层含义 |
|-----------|----------|----------|
| **黑缎**（斩神） | 遮盖失明的眼睛 | 封印神明的容器 |
| **戏台**（戏神） | 表演场所 | 命运舞台，被注视的囚笼 |
| **糖果**（斩神） | 安慰小孩的零食 | 控制/洗脑的媒介 |
| **镜子**（戏神） | 反射影像 | 真实自我 vs 表演自我 |

## 伏笔类型分类

### 按回收周期分类

| 类型 | 回收周期 | 数量建议 | 示例 |
|------|----------|----------|------|
| **短期伏笔** | 3-5 章内回收 | 每章 2-3 个 | 角色说要去某地，下章到达 |
| **中期伏笔** | 10-30 章内回收 | 每 5 章 3-5 个 | 神秘人的身份、功法副作用 |
| **长期伏笔** | 50-100+ 章回收 | 每卷 2-3 个 | 主角身世、世界观真相 |
| **贯穿伏笔** | 全书贯穿 | 1-3 个 | 最终 BOSS 身份、核心矛盾 |

---

### 按功能分类

| 类型 | 功能 | 埋设位置 | 回收方式 |
|------|------|----------|----------|
| **情节伏笔** | 推动剧情 | 章节结尾 | 下章开头回收 |
| **人物伏笔** | 角色成长/反转 | 对话/回忆 | 关键抉择时回收 |
| **世界观伏笔** | 揭秘设定 | 环境描写 | 新地图开启时回收 |
| **情感伏笔** | 情绪爆发 | 温情场景 | 悲剧/牺牲时回收 |
| **能力伏笔** | 金手指/限制 | 战斗描述 | 绝境突破时回收 |

## 伏笔管理执行流程

### Step 1: 读取章节内容

```bash
# 读取目标章节
Read "正文/第{NNNN}章.md"
```

---

### Step 2: 识别伏笔位置

**识别规则**：
- 查找所有未解释的异常现象
- 标记所有神秘/模糊的描述
- 统计新出现的道具/人物/地点
- 识别所有"日后说"类延迟信息

**伏笔识别关键词**：
```
- "总有一天……"
- "后来他才知道……"
- "当时他还不明白……"
- "这是一个秘密"
- "暂时不能告诉你"
- "似乎有什么不对"
- "感觉被注视着"
- "莫名的熟悉感"
```

---

### Step 3: 伏笔分类与登记

**伏笔档案模板**：
```markdown
## 伏笔编号：FB-{章节号}-{序号}

**出现章节**：第 X 章

**伏笔类型**：[情节/人物/世界观/情感/能力]

**回收周期**：[短期/中期/长期/贯穿]

**伏笔内容**：
[原文引用或简要描述]

**埋设方式**：
[对话/环境描写/心理活动/道具出现]

**预期回收章节**：第 Y 章

**实际回收章节**：[回收后填写]

**回收状态**：
- [ ] 未回收
- [x] 已回收
- [ ] 已废弃

**关联伏笔**：
[相关联的其他伏笔编号]

**备注**：
[需要额外说明的信息]
```

---

### Step 4: 伏笔密度检查

**密度标准**：
| 章节类型 | 新增伏笔 | 回收伏笔 | 净增长 |
|----------|----------|----------|--------|
| **开篇章** | 5-8 个 | 0-1 个 | +5~7 |
| **发展章** | 2-4 个 | 1-3 个 | +1~2 |
| **高潮章** | 1-2 个 | 3-5 个 | -2~3 |
| **收尾章** | 0-1 个 | 5-8 个 | -5~7 |

**预警条件**：
- 连续 5 章无新增伏笔 → 【⚠️ 伏笔枯竭预警】
- 伏笔积压超过 50 个未回收 → 【⚠️ 伏笔债务预警】
- 长期伏笔超过 100 章未回收 → 【⚠️ 伏笔遗忘预警】

---

### Step 5: 伏笔回收追踪

**回收检查清单**：
- [ ] 回收章节是否有前情提要？
- [ ] 回收是否超出预期章节（逾期）？
- [ ] 回收方式是否出乎意料但情理之中？
- [ ] 回收后是否有情感/剧情冲击？
- [ ] 是否有未解释的遗留问题？

**逾期处理**：
```
【⚠️ 伏笔逾期提醒】

伏笔编号：FB-023-01
埋设章节：第 23 章
预期回收：第 50 章
当前章节：第 65 章
逾期章节：15 章

建议处理：
1. 立即安排回收（推荐）
2. 更新预期回收章节至第 80 章
3. 标记为废弃伏笔（需说明原因）
```

## 三九音域伏笔埋设技巧

### 技巧一：日常中的异常

**方法**：在日常生活场景中插入诡异/不协调的细节。

**示例**：
```
【场景】主角回家吃饭

❌ 直白埋设：
"他觉得今天有点不对劲，但说不上来。"

✅ 三九音域风格：
"姨妈做的红烧肉很好吃。
陈伶吃得很香，直到他夹起第三块肉时，动作突然停住了。
'怎么了？'姨妈问。
'没事。'他低下头，继续扒饭。
那块肉的肥瘦比例，和之前两块一模一样。
就像……复制出来的一样。"
```

---

### 技巧二：对话中的无心之语

**方法**：让角色随口说出一句话，后期成为关键线索。

**示例**：
```
【场景】队友闲聊

❌ 直白埋设：
"你知道吗？其实我是最终 BOSS。"

✅ 三九音域风格：
"'如果有一天我站在你的对立面，你会怎么办？'他问。
'杀了你。'陈伶毫不犹豫。
'哈哈，开玩笑的。'他摆摆手，转身离去。
背影在夕阳下拉得很长，很长。"
```

---

### 技巧三：环境描写的暗示

**方法**：通过环境细节暗示即将发生的事情。

**示例**：
```
【场景】进入新地图

❌ 直白埋设：
"这个地方很危险，有很多秘密。"

✅ 三九音域风格：
"城墙很高，青灰色的砖石上布满裂纹。
仔细看，那些裂纹似乎构成了某种图案。
像是一张脸。
又像是一个……封印。
'这城建立多久了？'他问。
'三百年。'向导回答。
他伸手触摸城墙，指尖传来一阵冰冷的触感。
仿佛有什么东西，在砖石深处，注视着他。"
```

---

### 技巧四：道具的异常特性

**方法**：赋予道具特殊属性，但不立即揭示用途。

**示例**：
```
【场景】获得道具

❌ 直白埋设：
"这是一把神器，可以杀死神明。"

✅ 三九音域风格：
"匕首很旧，刀柄上刻着奇怪的纹路。
'这东西有什么用？'他问。
'不知道。'老人摇头，'但记住，别让它见血。
尤其是……神明的血。'
他说完就走了，留下他一人握着匕首，
在原地站了很久。"
```

---

### 技巧五：记忆的缺失/错位

**方法**：角色对某件事的记忆模糊或与他人叙述不符。

**示例**：
```
【场景】回忆过去

❌ 直白埋设：
"他的记忆被篡改了。"

✅ 三九音域风格：
"'你记得那天发生了什么吗？'
'记得。'他说，'那天下了很大的雨。'
'可是……'对方犹豫了一下，
' According to 记录，那天是晴天。'
他愣住了。
记忆中的雨声，如此清晰。
难道是……自己记错了？"
```

## 伏笔回收技巧

### 技巧一：原话重现

**方法**：让角色在关键场景说出早期伏笔的原话。

**示例**：
```
【伏笔】第 10 章：
"'如果有一天我变成了怪物……你会杀了我吗？'
'会。'林七夜毫不犹豫。"

【回收】第 500 章：
"'你说过，如果我变成怪物，你会杀了我。'
林七夜看着他，手中的刀在颤抖。
'现在，就是那个时候了。'"
```

---

### 技巧二：道具重临

**方法**：早期不起眼的道具在关键时刻发挥作用。

**示例**：
```
【伏笔】第 5 章：
"他随手捡起一块黑色石头，放进口袋。"

【回收】第 300 章：
"'需要神陨之心的碎片才能打开封印。'
他从口袋中掏出那块黑色石头。
'巧了，我捡了一块。'"
```

---

### 技巧三：身份反转

**方法**：揭露角色的真实身份与表面身份截然不同。

**示例**：
```
【伏笔】第 1-50 章：
"姨妈是个普通的农村妇女，不识字，只会做饭。"

【回收】第 200 章：
"'你以为她真的只是个农村妇女？'
老人看着手中的档案，冷笑一声。
'她是上一代守夜人，代号"红蝶"。
双手沾满的鲜血，比你见过的任何人都多。'"
```

## 伏笔管理检查清单

### 埋设阶段检查
- [ ] 伏笔是否足够隐蔽（读者第一眼不会注意）？
- [ ] 伏笔是否有多种解读可能？
- [ ] 伏笔是否与角色/情节自然融合？
- [ ] 是否记录了伏笔编号和预期回收章节？
- [ ] 伏笔密度是否符合当前章节类型？

### 回收阶段检查
- [ ] 回收是否出乎意料但情理之中？
- [ ] 回收是否有情感/剧情冲击力？
- [ ] 是否需要前情提要帮助读者回忆？
- [ ] 回收后是否产生新的伏笔（伏笔链）？
- [ ] 是否有未解释的遗留问题？

### 整体平衡检查
- [ ] 伏笔总数是否可控（不超过 100 个活跃）？
- [ ] 长中短期伏笔比例是否合理（1:3:6）？
- [ ] 是否有逾期超过 20 章的伏笔？
- [ ] 是否有连续 5 章无伏笔回收？
- [ ] 伏笔回收是否集中在高潮章节？

## 与写作流程的集成

### 集成位置

**Step 1 后 / Step 2A 前**：
```
Step 1: Context Agent 搜集上下文
    ↓
Step 1.5: 伏笔检查 ← 新增
    ↓
Step 2A: 正文起草
```

**Step 5 后**：
```
Step 5: Data Agent 处理数据链
    ↓
伏笔入库/更新状态 ← 新增
    ↓
Step 6: Git 备份
```

### 调用方式

**自动调用**：
- 每章写作完成后自动检查伏笔
- 每 10 章自动生成伏笔回收建议

**手动调用**：
```bash
/foreshadowing-check {chapter_num}   # 检查指定章节伏笔
/foreshadowing-list --overdue        # 列出逾期伏笔
/foreshadowing-suggest --next-chapter # 生成下一章伏笔建议
```

## 配置选项

| 配置项 | 默认值 | 说明 |
