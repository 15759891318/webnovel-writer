# 都市题材模板 (Urban Template)

> **版本**: v6.0
> **适用**: 都市异能、都市商业、都市情感、都市脑洞等

---

## 一、题材核心要素

### 世界观基础

| 要素 | 说明 | 示例 |
|------|------|------|
| **背景设定** | 现代都市/平行世界/灵气复苏 | 2026 年蓝星/龙国魔都 |
| **力量体系** | 异能/古武/修仙/系统 | 异能觉醒 S/A/B/C/D 级 |
| **社会结构** | 普通人/超凡者/官方组织 | 特殊事件调查局/异能者协会 |
| **经济体系** | 货币/资源/产业 | 灵石/晶核/普通货币 |
| **暗线设定** |  Hidden world/里世界 | 都市表象下的超凡世界 |

### 核心爽点

1. **身份反差**: 表面普通人，实际是大佬
2. **能力碾压**: 用超凡能力碾压普通人
3. **财富自由**: 赚钱如呼吸，买买买不眨眼
4. **美女青睐**: 优秀女性主动接近
5. **打脸嘲讽**: 被看不起后实力打脸
6. **守护成功**: 保护家人朋友不受伤害
7. **名声传播**: 在圈子里成为传奇

## 二、标准结构模板

### 开局模式（5 选 1）

**模式 A: 系统觉醒**
```
- 主角 status: 普通社畜/大学生
- 金手指觉醒: 系统突然激活
- 第一章爽点: 完成新手任务，获得第一笔奖励
- 短期目标: 系统发布的第一个主线任务
```

**模式 B: 重生归来**
```
- 主角 status: 重生回十年前
- 金手指：前世记忆/经验
- 第一章爽点: 用先知先觉赚第一桶金
- 短期目标: 弥补前世遗憾
```

**模式 C: 异能觉醒**
```
- 主角 status: 普通人突然觉醒
- 金手指：S 级异能/特殊能力
- 第一章爽点: 展示异能威力
- 短期目标: 加入官方组织/隐藏身份
```

**模式 D: 传承获得**
```
- 主角 status: 普通人
- 金手指：获得修仙/古武传承
- 第一章爽点: 第一次使用传承能力
- 短期目标: 消化传承，提升实力
```

**模式 E: 身份揭露**
```
- 主角 status: 表面普通人，实际隐藏大佬
- 金手指：真实身份/实力
- 第一章爽点: 小试牛刀，震惊旁人
- 短期目标: 处理身份暴露危机
```

### 中期发展模式

**商业流**:
```
小公司→行业新星→行业巨头→商业帝国
```

**异能流**:
```
觉醒者→小队成员→队长→区域负责人→最强者
```

**修仙流**:
```
练气→筑基→金丹→元婴→都市无敌
```

**幕后流**:
```
建立组织→招募手下→操控局势→幕后黑手
```

| 轴向 | 默认 | 推荐非默认选项 |

## 四、角色设计模板

### 主角卡

```markdown
## 主角：[姓名]

### 基础信息
- **年龄**: [22-30 岁]
- **职业**: [社畜/学生/自由职业]
- **金手指**: [系统/异能/传承/重生记忆]
- **金手指限制**: [代价/冷却/使用条件]
- **核心欲望**: [赚钱/变强/守护家人/探寻真相]

### 性格特征
- **核心特质**: [谨慎/激进/中庸]
- **优点**: [重情义/有底线/聪明]
- **缺点**: [有时候太狠/过于谨慎]
- **禁区**: [绝对不能触碰的底线]

### 成长路线
- **短期目标**: [赚第一个 100 万/觉醒异能]
- **中期目标**: [建立商业帝国/成为最强]
- **长期目标**: [守护城市/探索世界真相]

### 说话风格
- [简洁/幽默/严肃/随意]
```

### 反派卡

```markdown
## 反派：[姓名]

### 基础信息
- **身份**: [商业对手/异能组织/古武世家]
- **能力**: [与主角相当或略强]
- **核心欲望**: [和主角的冲突点]

### 与主角的镜像对抗
- **共同点**: [都为了保护某人]
- **分歧点**: [实现路径不同]

### 智商设定
- [ ] 不降智，有完整计划
- [ ] 多次差点成功
- [ ] 有自己的底线
```

### 女主/女配卡

- **独立目标**: [不是依附主角]

- **初遇**: [如何相识]

## 五、情节节拍器

### 单章节拍（2000-2500 字）

```
开场 (0-300 字): 钩子/承接上章
发展 (300-1500 字): 核心事件推进
高潮 (1500-2000 字): 冲突爆发/爽点释放
收尾 (2000-2500 字): 收获总结/章末钩子
```

### 十章节拍

```
第 1 章：开启新事件/新地图
第 2-3 章：铺垫/遇阻
第 4-5 章：小高潮/小收获
第 6-8 章：更大阻力/陷入危机
第 9 章：大高潮/突破
第 10 章：大收获/伏笔埋设
```

### 百章节拍（一卷）

```
第 1-10 章：卷首铺垫，引入核心冲突
第 11-30 章：多线发展，积累矛盾
第 31-50 章：矛盾爆发，第一次高潮
第 51-70 章：高潮余波，新的危机浮现
第 71-90 章：最终决战准备
第 91-100 章：卷末大高潮，收尾
```

## 八、避坑指南

### 常见毒点

1. **圣母心**: 对敌人仁慈，放过必杀之人
2. **送女**: 把女性角色送给其他男人
3. **憋屈**: 主角被欺压超过 3 章不反击
4. **降智**: 反派无脑送经验
5. **注水**: 无意义日常超过 5 章
6. **设定前后矛盾**: 能力/规则前后不一致
7. **后宫失衡**: 女性角色全是花瓶
8. **赚钱太假**: 赚钱过程没有逻辑
9. **能力崩坏**: 后期能力体系崩溃

### 审核红线

1. 不要涉及真实政治
2. 不要涉及敏感社会事件
3. 不要过于血腥暴力
4. 不要涉黄
5. 不要宣扬犯罪
6. 不要抹黑政府形象
