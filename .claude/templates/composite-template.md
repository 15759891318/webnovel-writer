# 复合题材模板 (Composite Template)

> **版本**: v6.0
> **适用**: 多题材融合创新作品（赛博修真/克苏鲁历史/无限流职场等）

---

## 一、复合题材核心原则

### 融合逻辑

**1+1>2 原则**: 两个题材融合后，应该产生新的爽点和可能性，而不是简单的元素堆砌。

**兼容性检查**:
- [ ] 两个题材的核心爽点是否冲突？
- [ ] 世界观能否自洽？
- [ ] 读者群体是否有重叠？
- [ ] 能否产生新的化学反应？

### 融合模式

**模式 A: 主 + 辅**
```
主题材：80% 内容
辅题材：20% 内容（用于增加新意）
示例：修仙 (主) + 系统 (辅) = 系统修仙流
```

**模式 B: 平等融合**
```
题材 A：50% 内容
题材 B：50% 内容
示例：赛博修真 = 赛博朋克×修仙
```

**模式 C: 多层融合**
```
核心题材：60%
次要题材：30%
点缀元素：10%
示例：克苏鲁历史修仙
```

## 二、热门复合题材配方

### 配方 1: 赛博修真

**融合公式**: 赛博朋克 + 修仙

| 修仙元素 | 赛博化改造 |
|---------|-----------|
| 灵气 | 纳米机器人/能量网络 |
| 功法 | 程序/代码 |
| 丹田 | 服务器/能量核心 |
| 渡劫 | 系统升级/防火墙突破 |
| 法宝 | 智能武器/黑客工具 |
| 宗门 | 企业/财团 |
| 修炼 | 下载数据/升级硬件 |

**核心爽点**:
- 用黑客技术破解功法
- 用程序修炼，一天顶别人一年
- 用企业战争模式呈现宗门斗争

**参考设定**:
```
修炼等级:
- 炼气期：接入网络
- 筑基期：建立个人服务器
- 金丹期：数据核心固化
- 元婴期：意识数字化
- 化神期：网络无处不在
```

### 配方 2: 克苏鲁历史

**融合公式**: 克苏鲁神话 + 古代中国

| 克苏鲁元素 | 历史化改造 |
|-----------|-----------|
| 旧日支配者 | 上古魔神/邪神 |
| san 值 | 道心/心智 |
| 禁忌知识 | 邪法/魔功 |
| 调查员 | 道士/钦天监 |
| 咒语 | 符箓/咒术 |
| 仪式 | 祭祀/阵法 |

**核心爽点**:
- 用道术对抗不可名状的存在
- 在 san 值狂掉的情况下保持理智
- 揭开历史背后的恐怖真相

**参考设定**:
```
修炼风险:
- 每学一门邪法，san 值 -10
- san 值低于 50，出现幻觉
- san 值低于 20，被邪神污染
- san 值归零，变成怪物
```

### 配方 3: 无限流职场

**融合公式**: 无限流 + 职场

| 职场元素 | 无限流化改造 |
|---------|-----------|
| KPI 考核 | 副本任务 |
| 升职 | 解锁新副本 |
| 加班 | 额外副本 |
| 年终奖 | 通关奖励 |
| 裁员 | 淘汰抹杀 |
| 部门斗争 | 团队竞争 |

**核心爽点**:
- 用职场技能在副本中获胜
- 把副本当项目做
- 职场老油条的无限流生存之道

**参考设定**:
```
员工等级:
- 实习生：E 级员工，只能进简单副本
- 正式员工：C 级员工，可进普通副本
- 主管：B 级员工，可带队
- 经理：A 级员工，可自主选择副本
- 总监：S 级员工，几乎无敌
```

### 配方 4: 末世种田

**融合公式**: 末世 + 种田

| 末世元素 | 种田化改造 |
|---------|-----------|
| 丧尸/变异兽 | 需要清除的威胁 |
| 资源匮乏 | 需要收集/生产 |
| 幸存者营地 | 农场/基地 |
| 异能 | 生产辅助工具 |
| 废土 | 待开垦土地 |

**核心爽点**:
- 在末世建起世外桃源
- 看着基地/农场一点点壮大
- 别人末世求生，主角末世享福

**参考设定**:
```
基地发展:
- 阶段 1：小型避难所（10 人）
- 阶段 2：中型营地（50 人）
- 阶段 3：大型基地（500 人）
- 阶段 4：废土城市（5000 人）
- 阶段 5：新文明曙光（50000 人）
```

| 轴向 | 选项 |

| **题材基础轴** | 赛博修真/克苏鲁历史/无限流职场/末世种田/灵气复苏/星际武侠/数据化末日/神话复苏 |

## 七、避坑指南

### 常见毒点

1. **元素堆砌**: 只是简单堆砌两个题材的元素，没有融合
2. **顾此失彼**: 过于偏重一个题材，另一个题材变成摆设
3. **设定冲突**: 两个题材的设定互相矛盾
4. **读者割裂**: 题材 A 读者和题材 B 读者都觉得自己是局外人
5. **融合生硬**: 融合点不自然，强行缝合
6. **注水**: 过多设定说明，剧情停滞

### 融合检查清单

在开书前，必须确认：

- [ ] 两个题材的核心爽点是否都保留了？
- [ ] 融合后是否产生了新的爽点？
- [ ] 世界观能否自洽？
- [ ] 力量体系是否平衡？
- [ ] 读者能否接受这种融合？
- [ ] 是否有参考作品证明这种融合可行？

## 八、参考作品

### 成功融合案例

- 《诡秘之主》：克苏鲁 + 蒸汽朋克 + 序列进化
- 《修真聊天群》：现代都市 + 修仙 + 聊天群
- 《大王饶命》：灵气复苏 + 系统 + 搞笑
- 《全球高武》：高武 + 系统 + 学院流
- 《间客》：赛博朋克 + 古武 + 权谋

### 融合思路分析

**《诡秘之主》融合思路**:
```
克苏鲁的恐怖感 + 蒸汽朋克的科技感 + 序列进化的爽感
= 独特的诡秘世界观
```

**《修真聊天群》融合思路**:
```
传统修仙 + 现代生活 + 社交网络
= 轻松搞笑的修仙日常
```
