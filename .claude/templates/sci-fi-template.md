# 科幻题材模板 (Sci-Fi Template)

> **版本**: v6.0
> **适用**: 硬科幻、软科幻、赛博朋克、太空歌剧、末世科幻等

---

## 一、题材核心要素

### 世界观基础

| 要素 | 说明 | 示例 |
|------|------|------|
| **时代背景** | 近未来/远未来/平行世界 | 2150 年/银河纪元 3000 年 |
| **科技水平** | 科技树设定 | 可控核聚变/曲率引擎/意识上传 |
| **力量体系** | 异能/基因改造/机械改造 | 基因锁 1-9 阶/改造等级 |
| **社会结构** | 国家/星际联邦/财团 | 地球联邦/银河议会 |
| **宇宙格局** | 星系/文明等级 | 太阳系/猎户座/银河系 |

### 核心爽点

1. **科技碾压**: 用先进科技碾压落后文明
2. **探索发现**: 发现新星球/新物种/新文明
3. **文明晋升**: 带领文明从低级向高级进化
4. **舰队指挥**: 指挥庞大舰队进行星际战争
5. **技术突破**: 突破科技瓶颈，引领时代
6. **星际贸易**: 利用资源差做星际倒爷
7. **拯救文明**: 在文明灭亡之际力挽狂澜

## 二、标准结构模板

### 开局模式（4 选 1）

**模式 A: 末世求生**
```
- 主角 status: 末世幸存者
- 金手指：系统/空间/避难所
- 第一章爽点: 激活金手指，获得生存优势
- 短期目标: 建立安全据点
```

**模式 B: 星际殖民**
```
- 主角 status: 殖民船成员/舰长
- 金手指：AI 助手/先进技术
- 第一章爽点: 发现宜居星球/展示技术优势
- 短期目标: 建立殖民地
```

**模式 C: 意识上传**
```
- 主角 status: 数字化意识
- 金手指：虚拟世界权限/黑客能力
- 第一章爽点: 在虚拟世界展示能力
- 短期目标: 寻找回到现实的方法
```

**模式 D: 外星接触**
```
- 主角 status: 地球人/外交官/士兵
- 金手指：外星科技/翻译器
- 第一章爽点: 第一次与外星人交流
- 短期目标: 建立外交关系/抵御入侵
```

### 中期发展模式

**科技流**:
```
实验室研究→技术突破→产业应用→科技霸权
```

**军事流**:
```
单兵→小队指挥官→舰队指挥官→统帅
```

**贸易流**:
```
小商人→星际贸易商→垄断巨头→经济霸主
```

**殖民流**:
```
单个殖民地→多个殖民地→星际帝国
```

### 后期飞升模式

```
地球无敌→太阳系霸主→银河系强者→宇宙级存在
```

## 三、创意约束配置

### 三轴混搭建议

| 轴向 | 默认 | 推荐非默认选项 |
|------|------|---------------|
| **题材基础轴** | 太空歌剧 | 赛博朋克/硬科幻/末世/无限流 |
| **规则限制轴** | 无限制升级 | 技术有代价/资源有限/熵增限制 |
| **角色矛盾轴** | 正义 vs 邪恶 | 主角非人类/AI 有情感/文明升维 |

### 反套路推荐（科幻向）

从以下选择至少 3 条：

- [ ] 技术有代价
- [ ] AI 有情感
- [ ] 外星非敌对
- [ ] 星际非大航海
- [ ] 科技不万能
- [ ] 进化有分歧
- [ ] 异能非天赋
- [ ] 意识可上传
- [ ] 人类非唯一
- [ ] 时间可改变
- [ ] 乌托邦非理想
- [ ] 废土非绝望
- [ ] 阶级非固定
- [ ] 政府非无能
- [ ] 企业非纯恶
- [ ] 宇宙非空旷
- [ ] 维度非固定
- [ ] 现实非真实
- [ ] 文明可升维
- [ ] 熵增可逆转

### 五维评分目标

```
新颖度：≥ 8/10
可行性：≥ 7/10
爽点潜力：≥ 8/10
情感共鸣：≥ 7/10
商业价值：≥ 7/10
总分：≥ 35/50
```

## 五、情节节拍器

### 单章节拍（2000-2500 字）

```
开场 (0-300 字): 钩子/承接上章
发展 (300-1500 字): 核心事件推进
高潮 (1500-2000 字): 冲突爆发/爽点释放
收尾 (2000-2500 字): 收获总结/章末钩子
```

### 十章节拍

```
第 1 章：开启新事件/新星球
第 2-3 章：探索/遇阻
第 4-5 章：小高潮/小收获
第 6-8 章：更大阻力/陷入危机
第 9 章：大高潮/突破
第 10 章：大收获/伏笔埋设
```

### 百章节拍（一卷）

```
第 1-10 章：卷首铺垫，引入核心冲突
第 11-30 章：多线发展，积累矛盾
第 31-50 章：矛盾爆发，第一次高潮
第 51-70 章：高潮余波，新的危机浮现
第 71-90 章：最终决战准备
第 91-100 章：卷末大高潮，收尾
```

## 八、避坑指南

### 常见毒点

1. **科学错误**: 出现明显科学常识错误
2. **设定崩坏**: 后期科技体系崩溃
3. **注水**: 过多技术说明，剧情停滞
4. **降智**: 反派无脑送经验
5. **憋屈**: 主角被欺压超过 3 章不反击
6. **文明歧视**: 对某些文明刻板印象
7. **逻辑漏洞**: 时间旅行/平行世界设定矛盾

### 审核红线

1. 不要涉及真实政治
2. 不要涉及敏感国际关系
3. 不要过于血腥暴力
4. 不要涉黄
5. 不要宣扬反人类思想
6. 不要泄露国家机密
