# 历史题材模板 (History Template)

> **版本**: v6.0
> **适用**: 历史穿越、历史脑洞、古代言情、历史权谋等

---

## 一、题材核心要素

### 世界观基础

| 要素 | 说明 | 示例 |
|------|------|------|
| **时代背景** | 真实历史/架空历史 | 唐朝/明朝/平行世界大乾王朝 |
| **社会结构** | 皇权/世家/科举 | 皇帝 - 官员 - 士族 - 平民 - 奴隶 |
| **经济体系** | 农业/商业/手工业 | 铜钱/银两/粮食布匹 |
| **力量体系** | 武力/权势/财富 | 武将品阶/官职等级/家产 |
| **文化背景** | 儒家/道家/百家 | 科举考试内容/社会价值观 |

### 核心爽点

1. **知识碾压**: 用现代知识碾压古代人
2. **改变历史**: 改变历史走向，拯救遗憾
3. **名臣折服**: 历史名臣成为主角追随者
4. **帝王器重**: 皇帝对主角信任有加
5. **种田发展**: 把穷乡僻壤发展成繁华都市
6. **商战碾压**: 用现代商业思维碾压古代商人
7. **文化输出**: 诗词歌赋震惊古人

## 二、标准结构模板

### 开局模式（4 选 1）

**模式 A: 穿越成皇子**
```
- 主角 status: 不受宠皇子/废太子
- 金手指：现代知识/系统
- 第一章爽点: 展示才能，震惊众人
- 短期目标: 获得皇帝重视/摆脱困境
```

**模式 B: 穿越成平民**
```
- 主角 status: 农家子/寒门子弟
- 金手指：现代知识/空间
- 第一章爽点: 赚第一桶金/改善生活
- 短期目标: 科举/经商/从军
```

**模式 C: 穿越成世家子**
```
- 主角 status: 世家嫡子
- 金手指：家族资源/现代知识
- 第一章爽点: 解决家族危机
- 短期目标: 振兴家族/科举入仕
```

**模式 D: 穿越成女性**
```
- 主角 status: 庶女/弃妃/农女
- 金手指：医术/商业头脑/空间
- 第一章爽点: 打脸欺负的人
- 短期目标: 改变命运/独立自强
```

### 中期发展模式

**科举流**:
```
童生→秀才→举人→进士→状元→入朝为官
```

**经商流**:
```
小贩→商行老板→行业巨头→富可敌国
```

**军事流**:
```
小兵→百夫长→将军→统帅→王爷
```

**权谋流**:
```
小官→中层官员→朝廷重臣→权倾朝野
```

**种田流**:
```
贫困农家→小地主→大地主→一方豪强
```

### 后期发展模式

```
权倾朝野→改革变法→强国富民→青史留名
```

## 三、创意约束配置

### 三轴混搭建议

| 轴向 | 默认 | 推荐非默认选项 |
|------|------|---------------|
| **题材基础轴** | 历史穿越 | 历史脑洞/历史权谋/历史种田 |
| **规则限制轴** | 现代知识万能 | 现代知识非万能/历史不可改/穿越有代价 |
| **角色矛盾轴** | 正义主角 vs 邪恶反派 | 名人非脸谱/反派有苦衷/女性独立 |

### 反套路推荐（历史向）

从以下选择至少 3 条：

- [ ] 现代知识非万能
- [ ] 穿越者非唯一
- [ ] 穿越有代价
- [ ] 历史不可改
- [ ] 身份非显赫
- [ ] 名人非脸谱
- [ ] 反派非 pure evil
- [ ] 女性非花瓶
- [ ] 帝王非全能
- [ ] 英雄非完美
- [ ] 阶级非固定
- [ ] 改革非顺利
- [ ] 科技非速成
- [ ] 文化非落后
- [ ] 经济非简单
- [ ] 历史非线性
- [ ] 文明非单一
- [ ] 真相非唯一
- [ ] 穿越非偶然
- [ ] 回归非结局

## 五、情节节拍器

### 单章节拍（2000-2500 字）

```
开场 (0-300 字): 钩子/承接上章
发展 (300-1500 字): 核心事件推进
高潮 (1500-2000 字): 冲突爆发/爽点释放
收尾 (2000-2500 字): 收获总结/章末钩子
```

### 十章节拍

```
第 1 章：开启新事件
第 2-3 章：铺垫/遇阻
第 4-5 章：小高潮/小收获
第 6-8 章：更大阻力/陷入危机
第 9 章：大高潮/突破
第 10 章：大收获/伏笔埋设
```

### 百章节拍（一卷）

```
第 1-10 章：卷首铺垫，引入核心冲突
第 11-30 章：多线发展，积累矛盾
第 31-50 章：矛盾爆发，第一次高潮
第 51-70 章：高潮余波，新的危机浮现
第 71-90 章：最终决战准备
第 91-100 章：卷末大高潮，收尾
```

## 八、避坑指南

### 常见毒点

1. **历史错误**: 出现明显历史常识错误
2. **设定崩坏**: 官职/地理前后矛盾
3. **注水**: 过多历史说明，剧情停滞
4. **降智**: 古人被写成傻子
5. **憋屈**: 主角被欺压超过 3 章不反击
6. **圣母心**: 对敌人仁慈
7. **现代梗滥用**: 过多现代词汇穿帮
8. **文化歧视**: 对某些朝代/民族刻板印象

### 审核红线

1. 不要涉及敏感历史人物
2. 不要涉及民族问题
3. 不要过于血腥暴力
4. 不要涉黄
5. 不要歪曲历史
6. 不要泄露国家机密

## 九、历史考据建议

### 常用史料

1. **正史**: 史记、汉书、三国志、资治通鉴等
2. **野史**: 各朝笔记、稗官野史
3. **地方志**: 各地府志、县志
4. **专业研究**: 各朝代专题研究论文

### 考据要点

1. **官制**: 官职名称、权力范围、升迁路径
2. **地理**: 地名、疆域、交通路线
3. **风俗**: 礼仪、婚丧、节庆
4. **物价**: 货币、购买力、物价水平
5. **科技**: 当时技术水平、可用材料

### 常见错误

1. **地名穿越**: 在汉代出现唐代的地名
2. **官职穿越**: 在明代出现清代的官职
3. **物品穿越**: 在宋代出现明代才有的物品
4. **称谓错误**: 对不同身份的人使用错误称谓
5. **礼仪错误**: 不符合当时礼仪规范
