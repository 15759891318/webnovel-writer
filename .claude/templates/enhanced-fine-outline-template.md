## 创意约束检查点（v2.0 新增）

**本章主导约束**: 反套路 #3 (反派智商在线)
**约束强度**: 🔴 强 - 反派计划应该显得可怕且周密

### 约束激活方案
**方式**: 反派首次正面出现，通过对话或独白展现其长期计划
**关键点**:
  - 反派应该算过主角的所有逃脱方案，一一予以反制
  - 反派的"陷阱"不是临时想到的，而是早已布置好的
  - 给读者"坏事将至"的感觉

### 三轴混搭检查（本章应体现）
- **赛博修真轴**: 修炼室被黑客入侵 / 或主角进入虚拟意识空间突破
- **寿命修炼轴**: 突破时献祭 20 年记忆，可表现为"咳血"、"短暂失忆"
- **反派未来身轴**: 反派说的话是否有"保护"的隐含意思？（伏笔，不需要揭真相）

### 约束激活的具体位置建议
| 进度 | 约束表现 | 方式 |
|-----|--------|------|
| 开场 0-15% | 反派出现及作派 | 对白/氛围 |
| 中段 30-60% | 反派计划细节 | 主角发现的线索 |
| 高潮 60-80% | 反派陷阱即将得手 | 紧张的对抗 |
| 结尾 80-100% | 反派的"保护"动机暗示 | 一句台词or举动 |

## 追读力设计（v2.0 新增）

**本章钩子类型**: 危机钩  
**强度标准**: 🔴 强 (70-100 分)

### 钩子设计细则
**钩子内容**: 反派已经按住了主角，还有 0.3 秒主角就会被擒住  
**钩子触发点**: 最后 200 字  
**钩子收尾方式**: 镜头定格在危急一刻（不要立即写主角如何逃脱）

### 微兑现计划
| 位置 | 兑现点 | 内容 |
|-----|------|------|
| 30% | 小胜利 | 主角成功躲过反派的第一波攻击 |
| 60% | 转折点 | 主角放弃逃跑，决定主动迎战 |
| 80% | 代价引入 | 献祭开始，主角感受到寿命流逝 |
| 100% | 悬念保留 | 反派即将得手，钩子悬起 |

### 钩子强度自检清单
- [ ] 最后 200 字中是否每句都在加强紧张感？
- [ ] 结尾最后一句是否足够有力？(应该是疑问句或感叹句，不是陈述句)
- [ ] 是否避免了"圆满结束"的感觉？(应该留悬念)

示例弱钩子（避免）：
```
"等等，"主角突然说，"我明白了。"
（太平和，读者不会着急看下一章）
```

示例强钩子（目标）：
```
反派的手掌贴上了主角的胸口。
冰冷的触感穿透衣物，直达心脏。
"下一秒，你就属于我了。"
```

## 剧情节拍

### 1. 逃脱与追杀（0%-20%，约 450-600 字）

**内容**:
- 场景: 地下修炼室走廊，枪声还在响
- 主角行为: 冲出修炼室，开始逃亡
- 反派行为: 从容追击（暗示有备而来）
- 约束体现: 建立"反派不是蛮干，而是算计好的"的感觉

**关键点**:
- 不要让反派显得"追不上"，而是"胸有成竹地追"
- 主角的逃脱路线应该显得"已被算到"，增加紧张感

**视角**: 吴越

**字数占比**: 约 20%

**约束检查**:
- [ ] 反派的追杀方式是否透露出"计划周密"?
- [ ] 赛博修真元素是否体现? (如:黑客切断电路、意识空间入侵)

---

### 2. 陷阱显露与绝望（20%-50%，约 1150-1500 字）

**内容**:
- 场景: 修炼室→ 虚拟意识空间(或逃脱地点)
- 转折: 主角发现"自己的逃脱路线早已被堵死"
- 反派出现: 通过对话/出现展现其计划的完，给出"你没有选择"的感觉
- 主角心态: 从"还有希望"→ "绝望"

**关键点**:
- 反派的第一次正式对话应该是有分量的——他说的话应该让主角（和读者）意识到"对方不是莽夫"
- 可以安排反派说出1-2个 "我早就算到你会……" 的台词，展现智商压制

**视角**: 吴越（主体），可插入反派的短暂POV或独白

**字数占比**: 约 35%

**约束检查**:
- [ ] 反派出场是否足够有气势?
- [ ] 反派说的话是否暗示"这一切都在计划中"?
- [ ] 是否为"反派保护主角"的未来身设定埋伏笔? (例：反派有一刻停顿/犹豫，暗示内心矛盾)

---

### 3. 突破抉择（50%-75%，约 1150-1500 字）

**内容**:
- 转折: 主角决定"不再逃跑，主动迎战"
- 过程: 准备突破、献祭记忆、进入虚拟意识空间决战
- 代价: 首次明显体现"寿命修炼的代价"(咳血/衰老/意识模糊)
- 反派反应: 反派意外于主角的"放弃逃脱"，但仍有应对之策

**关键点**:
- 这是第2个重要的"驱动力转折"点，必须花笔墨写主角的心理斗争
- 献祭的过程应该是"痛苦的、具体的"，不是抽象描写
- 反派即使面对突变也能应对，再次展现"计划周密"

**视角**: 主要吴越，可插入反派的短暂观察

**字数占比**: 约 35%

**约束检查**:
- [ ] "放弃逃跑"的心理转折是否充分? (应该不是"没办法"，而是"主动选择")
- [ ] 献祭记忆是否具体描写? (身体反应、心理缺失感)
- [ ] 赛博修真的突破方式是否体现了"科技+修真"的混合?

---

### 4. 激战与献祭（75%-95%，约 575-750 字）

**内容**:
- 场景: 虚拟意识空间内的战斗(具体形式待细节)
- 行为: 主角与反派的激烈对抗
- 献祭进行: 主角在战斗中继续献祭，体力/意识逐渐下降
- 局面: 反派逐渐占上风，主角深陷绝境

**关键点**:
- 这是"战斗高潮"，应该有清晰的"三回合"(试探→转折→终结)结构
- 献祭不是一次性的，而是"战斗中持续进行"，制造时间压力
- 反派在这个环节应该显得"可怕但有底线"(不是无情杀戮，而是有目的的压制)

**视角**: 吴越

**字数占比**: 约 25%

**战斗场景检查** (由 combat-scene-optimizer 负责):
- [ ] 三回合结构是否清晰?
- [ ] 五感是否并用? (视觉:光影/听觉:碰撞音/触觉:能量冲击/嗅觉:焦糊味)
- [ ] 短句是否主导? (紧张场景单句≤20字)

### 5. 悬念收尾（95%-100%，约 200-300 字）

**内容**:
- 反派即将得手，主角生死一线
- 钩子: 设置强力的危机钩，让读者迫不及待想看下一章

**关键点**:
- 不要"完全结束"，也不要太快救主角；应该在危急一刻"戛然而止"
- 最后一句话中不要有"说明"，应该有"悬念和张力"

**视角**: 吴越

**字数占比**: 约 5%

**钩子检查**:
- [ ] 钩子是"危机钩"吗? (是"绝境"而非"疑问"或"渴望")
- [ ] 强度是否达到 🔴? (读者应该感觉"非看下一章不可")
- [ ] 最后一句话中是否包含"未知数"? (例：反派突然的举动，而不是必然的逻辑)

**示例强钩子**:
```
反派的手掌贴上了吴越的胸口。
冰冷的触感穿透衣物，直达心脏。

"下一秒，你就属于我了。"

但反派的眼里，却闪过了一丝……柔软的什么。
```

## 风格指导（v2.0 新增）

**本章目标风格**: 三九音域 (短句、感官、节奏、去 AI 味)
**参考作品**: 《斩神》战斗章 + 《我不是戏神》绝望场景
**关键要点**: 
- 紧张场景用短句 (≤20 字)，制造"鼓点感"
- 感官优先于说明：用画面说话，少用"心想"
- 对话要有"潜台词"，反派的话暗示其动机/智谋

**禁止**:
- ❌ "他意识到……"，"理性告诉他……"
- ❌ 连续 3 句相同结构的句子 (机械感)
- ❌ "某种"、"好像"、"好似" 等模糊词
- ❌ 对话标签: "他说"、"她问道" 频率 >2 次/千字
