# 修仙题材模板 (Xianxia Template)

> **版本**: v6.0
> **适用**: 传统修仙、玄幻修仙、都市修仙等

---

## 一、题材核心要素

### 世界观基础

| 要素 | 说明 | 示例 |
|------|------|------|
| **修炼体系** | 境界划分、升级方式 | 炼气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫 |
| **力量来源** | 灵力/元气/灵气 | 天地灵气、灵石、丹药 |
| **地理格局** | 下界/灵界/仙界 | 人界→灵界→仙界的飞升体系 |
| **势力分布** | 宗门/家族/散修 | 正派/魔教/中立势力 |
| **资源体系** | 功法/丹药/法宝/符箓 | 天/地/玄/黄四阶 |

### 核心爽点

1. **境界突破**: 从低境界突破到高境界的快感
2. **越级挑战**: 以弱胜强，打破常规
3. **宝物认主**: 神器/秘境主动选择主角
4. **功法碾压**: 用高级功法碾压低级功法
5. **炼丹/炼器**: 制作出极品道具的成就感
6. **宗门崛起**: 带领宗门从弱小走向巅峰
7. **名声传播**: 事迹被传颂，成为传奇

## 二、标准结构模板

### 开局模式（3 选 1）

**模式 A: 废柴逆袭**
```
- 主角 status: 家族弃子/无法修炼/被退婚
- 金手指觉醒: 老爷爷/系统/特殊体质
- 第一章爽点: 展示金手指威力/打脸嘲讽者
- 短期目标: 三个月后的家族大比/宗门考核
```

**模式 B: 重生仙帝**
```
- 主角 status: 仙帝重生，回到少年时代
- 金手指：前世记忆/经验/功法
- 第一章爽点: 用前世知识碾压今生天才
- 短期目标: 弥补前世遗憾/复仇
```

**模式 C: 穿越系统**
```
- 主角 status: 现代人穿越，获得系统
- 金手指：系统面板/任务奖励
- 第一章爽点: 完成新手任务，获得第一桶金
- 短期目标: 系统发布的第一个主线任务
```

### 中期发展模式（可组合）

**宗门流**:
```
外门弟子→内门弟子→真传弟子→长老→宗主
```

**散修流**:
```
独行侠→加入小队→建立势力→一方霸主
```

**家族流**:
```
旁系子弟→核心子弟→家主→家族老祖
```

**王朝流**:
```
平民→官员→王爷→皇帝→国师
```

### 后期飞升模式

```
下界无敌→飞升灵界→从头开始→飞升仙界→成就道祖
```

## 三、创意约束配置

### 三轴混搭建议

| 轴向 | 默认 | 推荐非默认选项 |
|------|------|---------------|
| **题材基础轴** | 传统修仙 | 赛博修真/克苏鲁修仙/家族修仙/末世修仙 |
| **规则限制轴** | 无限制升级 | 寿命修炼法/代价交换制/资源枯竭 |
| **角色矛盾轴** | 正义 vs 邪恶 | 反派是未来身/全员恶人/主角有道德缺陷 |

### 反套路推荐（修仙向）

从以下选择至少 3 条：

- [ ] 金手指反向操作（有副作用）
- [ ] 开局即满级（自我封印）
- [ ] 系统/老爷爷有私心
- [ ] 力量体系有上限
- [ ] 代价交换制
- [ ] 资源有限竞争
- [ ] 主角有严重缺陷
- [ ] 主角不是天选之子
- [ ] 女性角色独立
- [ ] 反派智商在线
- [ ] 胜利代价惨重
- [ ] 世界真相反转

### 五维评分目标

```
新颖度：≥ 7/10
可行性：≥ 8/10
爽点潜力：≥ 8/10
情感共鸣：≥ 6/10
商业价值：≥ 7/10
总分：≥ 35/50
```

## 四、角色设计模板

### 主角卡

```markdown
## 主角：[姓名]

### 基础信息
- **出身**: [家族/宗门/散修]
- **初始境界**: [炼气 X 层]
- **金手指**: [类型 + 限制]
- **核心欲望**: [复仇/长生/保护家人/探寻真相]

### 性格特征
- **核心特质**: [坚毅/谨慎/疯狂]
- **优点**: [重情义/有底线]
- **缺点**: [过于谨慎/有时候太狠]
- **禁区**: [绝对不能触碰的底线]

### 成长路线
- **短期目标**: [突破到筑基]
- **中期目标**: [成为宗门第一]
- **长期目标**: [成就仙帝]

### 说话风格
- [简洁/啰嗦/文雅/粗俗]
```

### 反派卡

```markdown
## 反派：[姓名]

### 基础信息
- **身份**: [敌对宗门圣子/世家公子]
- **境界**: [比主角高 X 级]
- **核心欲望**: [和主角的冲突点]

### 与主角的镜像对抗
- **共同点**: [都为了守护某人]
- **分歧点**: [实现路径不同]

### 智商设定
- [ ] 不降智，有完整计划
- [ ] 多次差点成功
- [ ] 有自己的底线
```

### 女主/女配卡

```markdown
## 女性角色：[姓名]

### 基础信息
- **身份**: [宗门圣女/世家小姐/散修]
- **境界**: [与主角相当或略高]
- **独立目标**: [不是依附主角]

### 与主角关系
- **初遇**: [如何相识]
- **发展**: [关系变化节点]
- **定位**: [伴侣/盟友/对手]

### 独立性检查
- [ ] 有独立目标
- [ ] 有独立能力
- [ ] 有独立成长线
```

## 五、情节节拍器

### 单章节拍（2000-2500 字）

```
开场 (0-300 字): 钩子/承接上章
发展 (300-1500 字): 核心事件推进
高潮 (1500-2000 字): 冲突爆发/爽点释放
收尾 (2000-2500 字): 收获总结/章末钩子
```

### 十章节拍

```
第 1 章：开启新事件/新地图
第 2-3 章：铺垫/遇阻
第 4-5 章：小高潮/小收获
第 6-8 章：更大阻力/陷入危机
第 9 章：大高潮/突破
第 10 章：大收获/伏笔埋设
```

### 百章节拍（一卷）

```
第 1-10 章：卷首铺垫，引入核心冲突
第 11-30 章：多线发展，积累矛盾
第 31-50 章：矛盾爆发，第一次高潮
第 51-70 章：高潮余波，新的危机浮现
第 71-90 章：最终决战准备
第 91-100 章：卷末大高潮，收尾
```

## 八、避坑指南

### 常见毒点

1. **圣母心**: 对敌人仁慈，放过必杀之人
2. **送女**: 把女性角色送给其他男人
3. **憋屈**: 主角被欺压超过 3 章不反击
4. **降智**: 反派无脑送经验
5. **注水**: 无意义日常超过 5 章
6. **设定前后矛盾**: 境界/规则前后不一致
7. **后宫失衡**: 女性角色全是花瓶
8. **修炼停滞**: 超过 50 章不突破

### 审核红线

1. 不要涉及真实宗教
2. 不要涉及敏感政治
3. 不要过于血腥暴力
4. 不要涉黄
5. 不要宣扬封建迷信
